# 投资检查清单创建（金色账本风）

本技能的样式**忠实提取**自 `books/《巴菲特致股东的信》 附录：投资检查清单_Qwen.html`：金色调色板（`--gold:#a07828`）、奶油纸纹背景（`#f5f2ec`）、Noto Serif SC 衬线字体、证书式刊头、左侧粘性导航、账本表格打勾（金色表头 / 否决红章）、名言滚动行情带——与本项目阅读页设计令牌一脉相承。

**完整样式模板在 `assets/template.html`（CSS + 页面骨架 + 渲染引擎）。创建清单必须以它为基础，禁止另写通用模板（如蓝色卡片风）。**

## 使用步骤

1. **读取清单源内容**（通常是 `books/` 下的 `.md` 检查清单）
2. **复制** `assets/template.html` 到目标路径（如 `books/<清单名>.html`）
3. **把内容编码为 `SECTIONS` 数据**（块类型见下表），填入模板中 `const SECTIONS=[]`
4. **填写所有【占位】**：标题、刊头、印章、执行顺序、凡例、名言 `QUOTES`（10~14 条）、页脚最后一问
5. **设置唯一的 localStorage 键**：替换两处 `__STORAGE_KEY__`（如 `"brk-checklist"`、`"hshndcf-checklist"`）。**每份清单键必须不同**，否则勾选进度互相覆盖
6. 浏览器打开验证：节数、核查/否决计数、搜索、点击行打勾

## 数据结构 SECTIONS

每节一个对象：`{"id":"s1","t":"节标题","q":"核心一问","src":"出处标签","b":[块,...]}`

`b` 数组支持以下块类型（依序渲染）：

| 块 | 写法 | 说明 |
|---|---|---|
| 小节标题 | `["h","1.1","标题"]` | 金色菱形 + 编号徽章 |
| 引导段落 | `["p","正文"]` | 灰色引言段 |
| 引用 | `["q","引言","出处",1]` | 第 4 参数传 1 为加大号 |
| 公式卡 | `["f","<b>公式</b> ＝ … <span class=\"fc\">红色注记</span><span class=\"fn\">灰色脚注</span>"]` | 金底反白公式卡 |
| 提示卡 | `["co","warn\|tip\|note","标题","正文","出处?"]` | 红 / 金 / 蓝 三色 |
| 卡片组 | `["cd",2\|3\|4,[["编号","标题","描述"],…]]` | 2~4 列卡片 |
| 准则列表 | `["rl",[["标题","描述"],…]]` | 编号 01、02… 列表 |
| 账本表格 | `["t",{"m":"check","c":["列头",…],"r":[["单元格",…],…]}]` | 见下 |

### 账本表格 `t` 的三种模式

- `m:"check"` — **核查表**：多一列"核"，点击行 = 已核查（金色 ✓、行变绿底）。列头 `c` 只写数据列，首列是检查事项
- `m:"veto"` — **否决表**：多一列"否决"，点击行 = 触发（红色 ✕ + 「触发 · 放弃」印章）。**否决条件必须写成"信号 / 条件"**（如"审计意见非标准无保留"），不能写成待办（如"核对审计意见"）
- 不带 `m` — 纯展示对比表

## 注意事项

- `CN` 汉字数字数组最多支持 16 节（壹~拾陆），节编号自动渲染
- 表格行数即核查/否决计数，侧栏与工具条进度**自动统计**，无需手写总数；刊头 `#mTotal` 留空即可
- `SECTIONS` 写成**合法 JSON**（键与字符串均用双引号），便于用脚本校验行数与源 md 条目数一致
- 内容中的 `<` 写成 `&lt;`（渲染走 innerHTML）
- 模板 CSS 与源文件逐字一致（仅两处标注 `[模板修正]`：补齐源文件遗漏的 `--bg2/--text2` 变量、公式卡水印去书名化），**勿改动样式**
- 与阅读页章节 HTML 不同，本清单是独立单页，不接 `assets/style.css` 与阅读位置系统
