### 第三章 买入什么股票——寻找优良普通股的十五个原则

> **核心问题**：如果投资者想找到一只股票，并通过投资这只股票在几年内获得数倍的利润，或者在更长的时间内获得更多的利润，那么他应该懂得哪些事情？换句话说，一家公司应该具备哪些特质，才最有可能为它的股东创造出巨大的投资回报？

#### 0.1 十五个原则的使用方式

- 一家公司若能满足其中**大部分原则**，它就有可能是很好的投资目标。
- 若在这些原则中**无法达到的原则很多**，则它将不值得投资。

这十五个原则可以从两个维度来理解：

| 维度 | 分类 | 说明 |
| :--- | :--- | :--- |
| **考察内容** | 公司战略 | 公司选择做什么、往哪个方向走 |
| | 战略执行 | 既定战略能否得到有效执行 |
| **信息来源** | 公司外部信息 | 运用从公司外部获得的信息研究、确定 |
| | 公司内部人士 | 最好直接询问公司内部人士来确定 |

#### 0.2 十五个原则总览

| 编号 | 原则 | 考察核心 |
| :--- | :--- | :--- |
| **1** | 产品或服务是否具备良好的市场潜力，使销售额至少在几年内大幅成长 | 现有产品的成长事实 |
| **2** | 现有最佳产品潜力挖掘殆尽时，管理层是否有决心开发新产品、新工艺 | 管理层的成长态度 |
| **3** | 考虑到公司规模，研究发展方面的努力取得了多大效果 | 研发投入产出比 |
| **4** | 是否有高于行业平均水平的销售团队 | 销售与分销效率 |
| **5** | 是否有足够高的利润率 | 每一美元销售额含多少利润 |
| **6** | 做了哪些举措以维持或提高利润率 | 未来（而非过去）的利润率 |
| **7** | 是否具备良好的劳动人事关系 | 基层员工关系 |
| **8** | 高级管理者之间关系是否很好 | 高管团队氛围 |
| **9** | 公司管理是否很有层次 | 管理梯队与权力下放 |
| **10** | 成本分析和会计记录做得如何 | 财务控制与成本分析 |
| **11** | 在业务的其他方面是否具备相对竞争优势 | 行业特有能力（不动产、信贷、保险、专利等） |
| **12** | 对利润有没有短期或长期的展望 | 经营眼光的长短 |
| **13** | 可预见的将来是否会大量发行股票而摊薄现有股东利益 | 融资能力与股权稀释 |
| **14** | 管理层是不是向投资者报喜不报忧 | 信息披露的坦诚度 |
| **15** | 管理层是否具备毋庸置疑的诚信、正直态度 | 品格底线 |

> ⚠️ **重要提示**：前十四个原则中，某一条不达标而其他各条评价很高的公司，仍不失为值得考虑的投资对象。但**原则15是唯一的"一票否决"项**——管理层若对股东没有强烈的责任感，无论其他方面评价多高，都绝对不要考虑。

### 一、原则1：产品或服务是否具备良好的市场潜力，使销售额至少在几年内大幅成长？

#### 1.1 哪些"高利润"不值得长期投资者关注

| 情形 | 表现 | 为何吸引不了长期投资者 |
| :--- | :--- | :--- |
| **销售额停滞或下滑型** | 销售额曲线静止不动甚至大幅下降，仅靠成本控制得法带来净利润增长，推动股价上升 | 只是**一次性大幅增长**，是投机者和逢低承接者渴望的机会；对希望资金收益最大化的投资者而言不算好机会 |
| **一次性环境改变型** | 商业环境显著改变，使销售额在短短几年大幅提高，之后停止增长 | 销售额曲线止涨趋缓后，股票吸引力随之归于平淡 |

**典型案例：电视机商业化进程中的无线设备制造商**

许多无线设备制造商在电视机商业化进程中明显出现了第二种情况：短短几年内销售额大幅增长，但时至今日有电力可用的美国家庭中大约**90%**都已经有了电视机，销售额曲线再度呈现颓势。就该行业大多数公司而言，很早买进的投资者赚到了很高的利润，但之后吸引力便消失了。

#### 1.2 衡量成长要以"几年"为单位

即使是最出色的成长型公司，也不能指望它每年的销售额都比前一年有所增长。原因在于：

- **商业研究的错综复杂性**与**新产品营销方面的问题**，往往使销售额趋势出现不规则的起起落落，而不是每年平稳增长。
- **反复无常的经济周期循环**也会对每天的情况产生较大影响。

💡 **结论**：不应该以年为单位衡量销售额成长，而应以**几年为一个单位**来考虑。有些公司不只在未来几年内成长可以高于行业平均水平，在更长的时间段内也有望达到这种水平。

#### 1.3 两类长期高成长公司

那些数十年来始终保持惊人成长速度的公司，大体可分为两类：

| 类型 | 内涵 | 代表公司 |
| :--- | :--- | :--- |
| **"幸运而且能干"** | 行业技术发展和经济周期的**受益者**，而非开创者；管理层能力使其得以持续利用这些外部因素 | 美国铝业公司 |
| **"因为能干所以幸运"** | 凭自身的商业、金融判断力与技术能力，**主动开创**新的成长空间 | 杜邦、道氏化学、通用美国运输公司 |

⚠️ 对这两类公司而言，**管理层的非凡能力都是必须的**。没有一家公司仅仅因为运气不错就能保持长期高增长——它必须持续拥有杰出的经营管理才能，否则将无法掌控好运气，也无法保持优势地位不受竞争对手威胁。

#### 1.4 案例一：美国铝业公司——"幸运而且能干"

- **前瞻性眼光**：创始人正确预见了新产品的重要商业用途，但他们和其他任何人当年都没有预见到后面**70年**铝制品市场的巨大规模。
- **受益者定位**：公司是行业技术发展和经济周期的受益者而非开创者，这两条是推动它经营成功的主要因素。
- **管理层作用**：高超才能使公司能持续充分利用这两个因素实现发展。即使经营环境发生改变（例如对空中禁运的严格限制），其影响也没能完全限制住美国铝业开拓广阔新市场的能力，公司非常顽强地保持增长态势，只是速度稍微慢了一些。
- **股东回报**：许多早期股东因长期持有赚到很多钱，后来才买入的一些人也赚了不少。撰写本书第一版时，其股价比 1956 年历史最高点低了约 **40%**；但即便是这个"低"价，也比 10 年前（1947 年）的平均股价高约 **500%**——达到这个涨幅仅用了 10 年。

#### 1.5 案例二：杜邦公司——"因为能干所以幸运"

| 阶段 | 业务与成长情况 |
| :--- | :--- |
| **早期** | 多年以来只生产**炸药**；和平时期成长速度大概和采矿业相似 |
| **过渡期** | 铁路建设加快带来一些额外营业收入，成长率略高于以往；但如今这部分业务只占当前销售额的很小一部分 |
| **成熟期** | 凭商业和金融方面优异的判断力，加上出色的技术能力，年销售额超过 **20 亿美元** |

杜邦运用原有的炸药业务学得新的技术和知识，不断推出新产品（尼龙、玻璃纸、透明合成树脂、氯丁橡胶、合成纤维、聚酯薄膜等），并在市场上取得一个又一个成功，从而成为美国工业史上最伟大、最成功的传奇企业之一。

⚠️ **警惕因果倒置**：投资新手刚接触化工行业时，可能认为"投资回报率最高的公司同时也正是生产许多吸引人的成长型产品的公司"是一种幸运的巧合。这样的投资者**混淆了原因和结果**——就像一个单纯的年轻女子第一次从欧洲旅行回来告诉朋友：宽阔的河流总是流经那么多大城市的中心地带，这可真巧啊！仔细研究杜邦、道氏化学、联合碳业等企业的历史，就能很清楚地发现它们为什么属于"因为能干所以幸运"一类。

#### 1.6 案例三：通用美国运输公司——行业衰退中的自我救赎

| 时间 | 行业环境 | 公司应对 |
| :--- | :--- | :--- |
| **50 多年前（成立时）** | 铁路设备业似乎是成长空间非常宽广的行业 | — |
| **最近几年** | 时过境迁，已经很难找到什么行业的持续成长潜力比它更差 | 管理层凭过人的创新能力和足智多谋，使收益稳定增长 |
| **进一步** | 铁路运输的增长潜力让位于货车运输行业 | 运用从原有业务学到的才能和知识，涉足其他不相关的生产领域，获得进一步成长潜力 |

💡 **关键启示**：不管公司属于"幸运而且能干"还是"因为能干所以幸运"，投资者都必须留意审视**管理层是不是在目前以及未来一直都很能干**。如果不是，公司销售额将无法继续增长。

#### 1.7 避免肤浅判断：以电子行业转型为例

正确判断一家公司的长期销售额曲线极为重要，**肤浅的判断会导致错误的结论**。

以收音机、电视机行业为例：因美国家庭对电视机的需求趋于饱和，这类股票的股价只出现过暂时性爆发，而没有呈现持续上升趋势。**但近年来出现了新趋势**：

- 很多收音机、电视机生产公司运用自己在电子行业的技能，进入**通信、自动化设备**等其他电子领域，建立起规模庞大的事业。
- 这些**工业电子产品**以及一些**军事电子产品**，有望保持很多年的稳定增长。
- 在摩托罗拉（Motorola）之类的公司，这些新业务的重要性已超过了电视机。
- 一些新技术的发展也可能使现有电视机机型到 20 世纪 60 年代初显得非常难看而过时，就像原来挂在墙壁上通过曲杠操作的手摇式电话机现在已经过时一样。

**彩色电视机这一潜在机会**：它一直为大众所期待，是**晶体管开发和集成电路发展**所带来的直接结果。它将是一种荧幕式电视机，大小形状跟我们现在挂在墙上的大型书画作品类似，现在那些外壳笨重而硕大的电视机将成为历史。一旦这些技术得以商业化，现有电视机生产者中一些技术能力占优势的公司销售额就能再次大幅增长，**增幅和持续时间甚至能高于它们几年前所经历的那段时间**。这些公司将会发现，除了工业和军事电子产品业务的稳定增长以外，这方面业务销售额的大幅增长也会让整体销售额如虎添翼。

#### 1.8 选择出色投资对象应考虑的第一步

提到这个例子，不只是用于分析那些**必定要发生的事**，更重要的是用于分析那些**很可能发生的事情**。分析一家公司未来的销售额增长曲线时，有一个因素应该时刻牢记于心：

> 如果一家公司的管理层非常优秀，而且整个行业将在技术上发生重大变革，公司的技术研发也在稳步进行，那么精明的投资者就应该提高警惕，留意公司管理层有没有能力妥善把握这些机会，为公司创造出理想中的销售额增长曲线。**这是选择出色投资对象应考虑的第一步。**

#### 1.9 摩托罗拉：从"很可能发生"到"已经发生"

在第一版写下这些话时，对摩托罗拉而言，这些情况已不是"注定会发生"或"很可能发生"，而是**已经发生了**。在 20 世纪 60 年代即将来临时——也就是最接近"有可能发明出新的电视机机型、淘汰 50 年代旧机型"的时候——对全行业而言这种情况还没发生，近期内也不大可能发生。然而，此时正可以看看这家公司明智的管理层是如何掌握技术上的重大变革，从而创造出节节攀升的销售额曲线的。

| 业务领域 | 发展情况 |
| :--- | :--- |
| **双向电子通信** | 已成为该领域**独占鳌头的领导者**，现在似乎有无穷无尽的增长势头。器材最初是警车和出租汽车的专用产品，后来客户范围扩展到各个行业，包括货运公司、各类送货车队经营者、公用事业公司、大型建筑工程以及管道运输项目等 |
| **晶体管半导体** | 经过耗时几年且花费不菲的开发建设，建立起能够盈利的半导体业务部，在这个迅猛增长的行业中占据一席之地 |
| **立体音响唱机** | 在这一新涉足的行业中成为重要角色，带来的收入已成为销售收入的一个重要来源 |
| **高端电视机** | 通过和全国家具制造行业的市场领导者德瑞希尔（Drexel）公司达成合作，销售额突飞猛进 |
| **助听器材** | 以很低的价格并购一家公司进入该领域，并可能借此契机开发其他新型专用器材 |

简单来说，下一个 10 年的某一时候，重大的刺激因素可能会使公司原来的收音机、电视机业务再次出现大幅增长。这种情况尚未发生，也不可能在短期内发生，但**管理层已经在充分运用组织内部的资源和技术，为公司未来的增长做好充分准备**。

📈 **股票市场的反应**：本书第一版写完时，摩托罗拉股价是 **45.50 美元**，而如今是 **122 美元**。

#### 1.10 潜在利润有多大：康宁玻璃案例

1947 年，作者一位在华尔街的朋友对当时正处于萌芽中的电视机行业做过一项调查，研究了 **12 家**最主要的电视机制造商。

**调查结论**：

1. 这个行业的竞争态势将趋于激烈；
2. 一些业内主要公司的地位将大幅变动；
3. 该行业中的一些股票具有投机的机会。

**调查中的意外发现**：

- 制造显像管使用的**玻璃真空管**是缺货最严重的零部件。
- 这一细分行业最成功的制造商是**康宁玻璃公司**。
- 深入研究其技术能力和研发实力后可以清楚发现，这家公司非常有能力为电视机行业生产出合格的玻璃真空管。
- 对潜在市场规模评估后发现，这块业务将成为康宁全新的主要业务来源。

**投资结果**：

| 项目 | 数据 |
| :--- | :--- |
| 建议买入时价格 | 约 **20 美元** |
| 除权比例 | **2.5 : 1** |
| 10 年后股价 | 每股 **100 美元以上** |
| 折算为除权前 | 每股 **250 美元以上** |

由于对该公司其他业务线也都非常看好，这位分析师建议散户和机构投资者买进这家公司的股票。

### 二、原则2：现有最佳产品潜力挖掘殆尽时，管理层是否有决心开发新产品或新工艺？

> **完整表述**：当公司现有的最佳产品的增长潜力已经被挖掘得差不多时，管理层是不是有决心继续开发新产品或新工艺，以便进一步提高总销售额，制造出新的利润增长点？

#### 2.1 只有现有需求，没有开发政策，利润只是暂时的

一部分公司因目前产品有新需求，未来几年成长预期非常好，但公司**并没有进一步对产品进行开发的政策或计划**。这样，公司良好的利润情况可能只是暂时的——它们没能在 10 年或 25 年内沿着公司财务成功最稳当的方法（**依靠产品的持续升级**）为公司赚得源源不断的利润。

💡 也只有采用这样的方法，才能把**科学研究和技术发展**纳入企业蓝图，靠这条道路才能改良固有产品并开发新产品。公司管理层如果不想让公司的成长变成昙花一现，而希望公司日新月异地成长，通常也会采取这个方法。

#### 2.2 "树干与树枝"：相关多元化优于不相关多元化

公司如果能把技术和研究在很大程度上投入到**当前业务范畴内**的产品当中，投资者的收获通常会达到最大。

| 模式 | 描述 | 效果 |
| :--- | :--- | :--- |
| **相关多元化（推荐）** | 所有研究计划围绕**同一个最主要的业务部门**开展；如同每棵树都有各自的树干，再从主干上长出很多树枝 | 成果通常好得多 |
| **不相关多元化** | 从事许多互不相干的产品生产；往往在新产品研发成功后立即开展一些与现有业务无关的新业务 | 明显较差 |

⚠️ 这个意思不是说理想的公司**不可能**有很多产品线和各不相同的业务部门，而是强调研究计划应围绕主干展开。

#### 2.3 原则2 与原则1 的区别

| 对比项 | 原则1 | 原则2 |
| :--- | :--- | :--- |
| **关注对象** | 关于**事实**的问题 | 公司管理层的**态度** |
| **具体内容** | 对公司现有产品目前存在的销售额增长潜力做出评价 | 公司是否意识到增长规模总有一天会达到目前市场潜力的极限，届时若想继续成长，必须在未来某个时候再开发一片新的市场 |

💡 **两者必须兼备**：一家公司必须既如原则1 要求的那样具备良好的增长率，同时又按原则2 的要求，管理层有着正面积极的业务态度。投资者只有投资这样的公司才能获得最大的利益。

### 三、原则3：考虑到公司的规模，研究发展方面的努力取得了多大效果？

#### 3.1 常用的量化指标及其局限

**通用算法**：对绝大多数股票公开上市的公司来说，知道其每年花在研究发展经费上的金额并不困难。基本上每家公司都会报告年度总销售额，只要用最简单的算术——**研究费用 ÷ 总销售额**——就能得知研究开发费用在总销售额中的占比。

**专业分析师的常见做法**：

- 把一家公司的研究支出和同行业内其他公司的情况做比较。
- 和业界平均水平对比（把许多同行业公司的研发支出加总后取平均值）。

**这个数字能看出**：

1. 公司在研究开发方面所做的努力，相对于竞争对手是更多还是更少；
2. 投资者买入一家公司股票时，**每股所包含的研究支出金额**有多少。

⚠️ **局限性**：这样的数字只能当作一个**粗略的衡量标准和线索**，用来判断研究支出是高得异常还是根本不够。除非进一步结合更多资料，否则很可能造成误导。

#### 3.2 误导的根源：会计口径差异极大

哪些项目应被视为研究开发费用，各公司之间的算法差异极大：

| 情形 | 公司的处理 | 他方的看法 |
| :--- | :--- | :--- |
| **工程费用** | 一家公司可能把某种工程费用视为研究开发支出 | 一些来自政府的管理者认为，该公司不过是把现有产品稍作修改以符合某份订单的要求，只能算作**销售工程费用** |
| **新产品试验费用** | 有些公司可能把某种全新产品的试验费用作为**生产成本**，而不是研究支出 | 大部分专家会将其看作**纯正的研究费用**，因为它直接关系到如何生产一种新的产品 |

💡 如果所有公司都以类似的会计基础来报告研究开发支出，则各大知名公司相对的研发开支数据，看起来会和金融界常用的数据有很大不同。

#### 3.3 研发投入产出比的巨大差异

在企业各项主要业务行为中，**以研究开发方面投入产出比的差异最为明显**：

| 比较范围 | 差异幅度 |
| :--- | :--- |
| 即便是那些管理最为优良的公司之间 | 可高达 **2 : 1**——即经营优良的公司花在研究上的每一份投入，最终带来的效益是其他公司的 **2 倍有余** |
| 若把经营状况普通的公司也纳入比较 | 差别会**更大** |

**原因分析**：新产品和新工艺的迅猛增长，不再是只靠某一位天才就能完成的事，而必须让受过合格训练的工作团队里的每一个人各展其长。团队里可能包括：

- 化学家
- 固态物理学家
- 冶金学家
- 数学家

每一位专家的技能只是所产生的优秀结果的**一个组成部分**。团队里当然也需要一位**领导人**，在这些不同背景、不同能力类型的研究者中发挥协调作用，使他们为共同目标努力。

⚠️ 因此，即便一家公司研究人员数量很多且声望卓越，如果**缺乏好的研发领导人**，那么其团队运作的效果和别的优秀公司比起来，可能会相形见绌。

#### 3.4 研究成果最大化所需的三层协调

| 层级 | 协调对象 | 目的与要求 |
| :--- | :--- | :--- |
| **第一层** | 研究人员之间 | 协调技术、能力各有所长的研究人员，形成有向心力的团队，激励每一位专家发挥最大生产力 |
| **第二层** | 研究人员 ↔ 生产销售人员 | 对每个开发项目而言，研究人员和熟悉生产销售问题的人员之间做出**紧密、详尽**的协调 |
| **第三层** | 与高级管理人员 | 高级管理人员应该了解**商业研究的基本特质** |

⚠️ **第二层协调失败的后果**：让研究、生产和销售人员建立起紧密沟通并不容易。如果不能有效沟通，最后形成的新产品往往**不是生产成本不够低廉，就是在设计时没有抓住最重要的营销诉求**，这样研发出来的产品往往禁不起更有效率的竞争对手的冲击。

#### 3.5 高级管理层最容易犯的错误

**（1）随经济周期大起大落地调整研发规模**

研究开发项目在经济景气的年头没办法扩大规模，经济景气差的年头则被大幅削减——因为公司往往不肯为了达成应有的目标而突然提高总成本。

**（2）滥用"加急"计划**

| 项目 | 内容 |
| :--- | :--- |
| **定义** | 将一些重要的研究人员突然从他们一直从事的工作中抽出来，集中完成一些当时看起来更加重要，但通常不值得如此兴师动众的项目 |
| **评价** | 某些时候可能有其必要性，但**往往代价过于昂贵** |

💡 **成功商业研究的精髓**：只选择那些**投资回报有希望达到研究成本好几倍**的项目。不过，一旦某个研究项目开始着手，基于预算上的考虑和研究项目本身以外的其他原因而对项目进行放缓或加速，难免会使研发总成本相对于预期收益而言有所上升。

#### 3.6 两个现实中的警示案例

**案例一：小型电子公司为何不惧行业巨头**

作者曾见过一些成功的小型电子公司高级主管，对于来自一家行业领军企业的竞争不以为然，这种态度着实令人惊讶。他们不担心规模比自己大得多的公司能生产出富于竞争力的产品，**并非**因为：

- 不尊重大公司研究人员的个人能力；
- 不知道大公司不惜耗费巨资的研究发展可能获得什么样的市场成果。

**相反**，他们知道大公司经常会叫停正常的研究项目，插入一些加急计划，以完成管理层出于自身考虑而订立的暂时性目标。

**案例二：某石油公司的"半途而废"文化**

几年前，作者听说一位出色的负责技术的同事私下劝告广大毕业生不要到某家石油公司找工作。原因非常明显，但他不希望有人到处张扬此事：

- 那家公司的高级管理人员喜欢雇用一些技术熟练的人，来做正常情况下需要 **5 年**才能完成的项目。
- 到了大约**第 3 年**，公司就会对这个项目失去兴趣，将项目束之高阁。
- 结果：不但浪费公司的经费，也使员工无法通过工作上的成就取得在专业技术上的声誉。

#### 3.7 国防合同相关研究的评估难题

**难题所在**：很多国防相关研究通常不是由执行研究工作的公司承担费用，而是由**联邦政府**承担。有些国防领域的转包商也为那些作为他们客户的承包商做了很多有意义的研究。评价这些研究时，投资者是不是应该将其看得跟公司自行支出的研究项目一样重要？如果不是，又如何进行比较？

⚠️ 和投资领域中许多其他问题一样，这些问题**没办法用数学公式来回答，每一种情形都各不相同**。

**国防合同的两个固有特点**：

1. **利润率低于**跟非政府客户合作的商业活动的利润率；
2. 新式武器的合同容易遭遇政府规划下的**竞争性出价**。

这就表明：政府主办的研究项目所研发的产品，通常**不能带来稳定、多次购买的业务**；但私人的研究项目却能做到这一点，因为**专利权和顾客满意度**能为公司带来持续的收入。

由于这些原因，从投资者的角度来说，政府主办的各种研究项目虽然对国防事业的重要性大致相当，但**所产生的经济价值却有着巨大差别**。

#### 3.8 三个理论示例：同为国防研究，价值天差地别

| 示例 | 项目特征 | 对投资者的价值 |
| :--- | :--- | :--- |
| **示例一** | 研制一种重要新式武器，**不具军事以外用途**；专利权完全由政府拥有；研制过程非常简单，公司投标生产合同时无法显现相对于其他公司的竞争优势 | **没有一点儿价值** |
| **示例二** | 生产同样的武器，但**制造工艺极为复杂**，没有参与最初开发工作的公司将很难承担生产工作 | **具有一定价值**——能从政府那里持续不断接到业务，只是利润率不会太高 |
| **示例三** | 担任武器研发工作，从中学到重要原理和全新技术，并**直接运用到利润较高的日常商业产品**生产中 | **可以带来很可观的价值** |

**示例三的现实印证**：近年来有很多非常成功的公司都属于这一类。它们有一种非常过人的能力——善于从政府花钱主导的复杂、技术极强的军事项目中，提炼出一定的技术知识，并将其合理、合法地运用到利润较高的、与公司现有业务有关的非军事领域之中。这些公司把政府国防部门所需的研究成果呈交给官方，同时以**很低的成本或者不需要任何成本**取得项目中的非国防研究利益，而这些利益原本必须通过花自己的钱才能取得。

| 公司 | 上市情况 | 投资回报 |
| :--- | :--- | :--- |
| **德州仪器** | 1953 年在纽约证券交易所首次挂牌，发行价 **5.25 美元** | 4 年内涨幅达 **500%** |
| **安培斯公司（Ampex）** | 同年首次公开发行 | 同期投资升值幅度达 **700%**，涨幅甚至高于德州仪器 |

💡 这个因素很可能就是投资德州仪器股票能获得极高收益的一个重要原因，安培斯的表现也可能是这个原因导致的。

#### 3.9 容易被忽略的一环：市场调查

判断企业研究机构的相对投资价值时，还有一类活动必须加以评估——**市场调查**。它在正常情况下一般不被看作开发研究，似乎与开发研究毫不沾边，但实际上：

> **市场调查是连接开发研究和销售的桥梁。**

⚠️ **高级管理人员必须提高警惕，绝对不能花大钱去调研**：

- 一些**华而不实**的产品；
- 一些的确有市场存在，但**市场规模太小而难以产生足够利润**的产品。

所谓"市场规模太小而难以产生足够利润"，指的是这样的市场中销售额太小，**根本无法收回研究成本**，更别说让投资者分得相应的利益了。

💡 **市场调查的正向价值**：公司的市场调查研究机构如果能把公司的重大研究项目，从"即便技术上成功也难以回收成本"的局面，扭转为将产品应用于更广阔的市场，从而获得相当于原先 **3 倍**的收入，则可以大幅提高持股者所能享受到的价值。

#### 3.10 如何最终判断研究机构的优劣

如果说"每年研究经费总额"以及"拥有工科学位的员工人数"这两个指标只是粗略依据，那么投资者可以采用以下两种方法：

**方法一："闲聊"法**

"闲聊"法在此问题上同样有着神奇的效果。广大普通投资者除非亲自尝试过，否则绝不会相信：仅仅通过向各处的研究人员就某家公司的研究活动提出一些**巧妙的问题**，就能让这家公司所属研究机构的全面情况呈现在自己眼前。

这些研究人员可能来自：

- 公司内部
- 竞争对手
- 大学
- 政府里相关领域的专业人士

**方法二：回溯历史贡献**

一个比较简单但通常有效的方法，就是仔细研究过去一段时间内（比如过去 **10 年**），公司所属研究机构的研究成果对这家公司的**销售额或净利润**产生了多大的贡献。

💡 这样，考虑到公司的业务规模，如果研究机构能不断推出高利润的新型产品，那么只要根据同样的常规经营方法继续运营公司业务，将来可能能够产生与此相同的生产效力。

### 四、原则4：这家公司有没有高于行业平均水平的销售团队？

#### 4.1 销售是最基本的业务行为

在这个竞争异常激烈的年代，即便某些公司的产品或服务极为优秀，但如果**营销方面有所欠缺，就无法发挥出最大的市场潜能**。

- 在任何生意中，最基本的业务行为就是**销售**，离开了销售，企业不可能生存。
- 公司基于**顾客满意度**而获得重复性的业务收入，这是公司经营成功与否的**第一个判断标准**。

⚠️ 奇怪的是，大部分投资者对公司的销售、广告以及分销渠道组织的相对效率，重视程度远不如对生产、研究、财务等其他业务部门——**就算是最小心谨慎的投资者也不例外**。

#### 4.2 为什么销售能力被普遍忽视

| 业务领域 | 能否构造简单的数学比率 | 投资者的重视程度 |
| :--- | :--- | :--- |
| 生产成本、研究项目、财务结构 | 相对容易 | 高 |
| **销售和分销效率** | **困难得多** | **低** |

对于研究项目，前文已经探讨过：这种简单的比率过于粗略，只能作为一个线索，告诉我们应该注意些什么（对生产和财务结构的价值稍后讨论）。然而，不管这种比率是否真的如金融界人士普遍认为的那样有价值，**广大投资者的确喜欢使用这些比率**。

💡 由于销售方面的行为没那么容易量化，很多投资者并未对其形成重视。可是在判断一家企业是否真的具备投资价值时，**它是一个基本的考虑因素**。

#### 4.3 解决方法："闲聊"法

面对这一难题，同样可以运用"闲聊"的方法解决：

- 在公司业务的所有方面，**没有什么比从公司外部的消息来源掌握公司销售组织的相对效率更容易的了**。
- **竞争对手和顾客都知道真实情况**。
- 同样重要的是，他们往往在表达自己看法的时候**十分踊跃**。

💡 小心谨慎的投资者如果肯在调查这个问题上花足够多的时间，通常可以获得满意的回报。

#### 4.4 企业成功的三大支柱

相对于探讨公司研究能力的部分，作者在探讨销售能力时用了更少的篇幅，但这**并不代表这部分内容不太重要**。

> 在今天这个激烈竞争的商业世界，很多重要的事情都关乎企业经营的成功，但是**优秀的产品与服务、销售、研究**或可称为企业成功的三大支柱。说其中一个比另外一个更重要，就好比说心、肺、消化道这几个器官中哪一个是维持人体正常运转最重要的器官——对于人的生存而言，所有器官都不可或缺，而且只有所有器官都保持健康，人的身体才会强壮。

💡 不妨看一下周围那些事后被证明是良好投资对象的公司，它们**一定都具备积极进取的销售态度和不断提升的销售团队**。

#### 4.5 案例：陶氏化学——销售人员的甄选与训练如同科研

陶氏化学公司多年以来为股东创造出极高的投资回报，成为一个完美的保守型长线投资的例子。一提到这家公司，在大众心目中浮现的形象是那些卓尔不凡的**科研成果**；但不为大众所熟知的是，**这家公司甄选和训练销售人员时如同处理化学研究和实验一样，一丝不苟**。

年轻的大学毕业生在正式成为陶氏化学销售人员之前的流程：

1. **多次考察**：可能会受到邀请数次前往美国中部地带，以尽可能确信他是否具备加入陶氏销售团队的**能力和性格**。
2. **专项培训**：在见到第一位潜在顾客之前，必须接受特定培训。培训时间**可能只有几周，也可能超过 1 年**，以帮助他准备好面对更为复杂的销售工作。
3. **持续考验**：而这仅仅是整个培训过程的开始。公司对他最大的考验，是要求他努力寻求和发现**更有效的方式**来把公司的优质服务传递给广大顾客。

#### 4.6 案例：IBM——销售人员 1/3 的时间在培训学校

陶氏化学十分重视销售和分销工作，其他行业的杰出公司在这方面是否有所不同？**答案是没什么不同。**

在一个与化学行业迥异的行业中，国际商业机器公司（International Business Machines，即 IBM）是一家长期以来给予股票持有人优厚回报的公司。IBM 一位高级管理人员告诉作者：

> 公司一般销售人员有 **1/3 的工作时间**是在公司举办的培训学校里边学习！

**培训占比如此之高的原因**：公司希望销售人员能够跟上一日千里的最新技术的发展。

#### 4.7 结论

这又是一个能够说明这个道理的证据：那些经营最成功的公司，**一定要非常重视不断提升销售人员的素质**。

| 情形 | 结果 |
| :--- | :--- |
| 缺乏强大销售组织，仅依靠强大的生产制造能力或研究能力 | 也许可以形成若干赚钱的业务，取得**一时的高利润**，但这样的利润**相当脆弱** |
| 想要长期稳定地成长 | **一支强大的销售团队是不可或缺的** |

---

### 五、原则5：这家公司有没有足够高的利润率？

#### 5.1 销售额必须转化为利润

我们现在终于谈到这件重要的东西——**数学分析**，许多金融界人士认为数学分析是形成可靠投资决策的最重要方法。

> 从投资者的角度出发，销售额**只有在能够导致利润增加的情况下才有价值**。世界上的任何投资，如果多年来利润都没有出现相应的增加，则销售额再怎么成长也不能算是一笔正确的投资。

**审视公司利润的第一步**：研究公司的**利润率**，也就是看看每一美元的销售额中含有多少美分的利润。

把这个数字算出来，马上就可以看出不同公司之间利润率的巨大差别，**即便是同一行业的公司之间也有很大差异**。

⚠️ 投资者不应该只关注于**一年**的利润率，应该着眼于**连续几年**的利润率。

#### 5.2 经济周期中大小公司的利润率表现

当企业所处的行业整体处于蓬勃发展的趋势之中时，几乎所有公司都有很高的利润率以及利润总额。但不同类型公司的表现有明显区别：

| 公司类型 | 经济上升期 | 经济转弱时 |
| :--- | :--- | :--- |
| **边缘型公司**（业界利润率较低的小公司） | 利润率增长的幅度基本上总是**远高于**以低成本为竞争优势的大公司；行业内处于弱势地位的公司利润成长率往往高于较强大的公司 | 利润会**骤然下降** |
| **低成本优势的大公司** | 利润率也会有所提高，只是**提高的幅度不会像小公司那么大** | 相对稳健 |

#### 5.3 结论：投资边缘型公司无法获得最高的长期利润

基于以上考虑，作者认为投资于边缘型公司是**绝对无法获得最高的长期利润**的。

**唯一的例外**：如果想要在一家利润率极低的公司上做长期投资，唯一的理由应该是——有强烈的迹象预示着该公司的经营情况正发生着**根本性的变化**。

| 要点 | 说明 |
| :--- | :--- |
| **合格的信号** | 公司的利润率正出现改善，且这种改善**不是业务量的暂时扩张**所带来的 |
| **核心逻辑** | 这家公司已经不能算是边缘型公司；购买其股票的核心原因在于**经营效率增强，或开发出了新产品**，使它脱离了边缘型公司的行列 |
| **附加条件** | 内部出现了这样的变化，而且**其他方面也符合长期投资的标准**，那么它可能就是个非常理想的投资对象 |

#### 5.4 大公司的规律与"故意压低利润率"的例外

**一般规律**：那些历史悠久且规模较大的公司中，真正能让投资者通过持股赚到高额回报的，**大部分都具备相对较高的利润率**，通常它们有着在各自所处行业内最高的利润率。

**例外情形**：很多初创的公司，有时也包括一些老公司，情况会跟上述规律有明显不同。它们往往会选择将**所有本来可以放进口袋的利润，或是其中相当一大部分**，用在更多的研究项目或更多的促销活动上，试图加速公司的成长。

💡 如果这是公司利润率下降或无利润的真正原因，那么最重要的是**确认公司真的是把这笔利润用在**：

- 进一步的研究工作
- 推动促销活动
- 或其他任何为了赢得更美好的未来而动用当下资金的活动

#### 5.5 投资者最需要小心的地方

导致利润率下降的诸多行为，不仅是那些为取得规模扩张所需的行为，实际上还包括进一步的研究、促销活动等等。

| 情形 | 判断 |
| :--- | :--- |
| 真的因为**研究、促销等原因**导致利润率不尽人意 | **反而可能是非常好的投资对象** |
| 蓄意拉低利润率而**非**进一步的规模扩张 | ⚠️ 希望在未来几年取得最大投资回报的投资者，最好**远离**这样的低利润率公司或边缘型公司 |

### 六、原则6：这家公司做了哪些举措以维持或提高利润率？

#### 6.1 关键在于"将来"而非"过去"

> 在股票投资中能不能赚到钱，**不在于**买入这家公司股票时这家公司发生了哪些**广为人知**的事情。相反，能不能赚到钱，主要依赖于**买进股票之后所能知道的事情**。

💡 因此，对投资者而言，最重要的是**将来的利润率**，而不是过去的利润率。

#### 6.2 利润率面临的接连威胁

在我们生活的这个年代，公司利润率似乎面临着接连不断的威胁：

| 威胁来源 | 具体表现 |
| :--- | :--- |
| **人员工资等成本** | 逐年上涨；许多公司现在都订有长期劳动合同，使得未来几年的薪资都会有所上涨 |
| **原材料和进货价格** | 劳动成本的上涨也会导致原材料和进货价格相应上涨 |
| **税率** | 似乎有逐步攀升的趋势，特别是**不动产和地方税率** |

在这样的背景下，不同公司的利润率也将有不同的结果。

#### 6.3 下策：靠简单提价维持利润率

有些公司似乎处于非常幸运的地位，只要**简单地提高价格**就能维持利润率。它们所处的行业通常具备以下条件之一：

- 有很旺盛的产品需求；
- 一些与其有竞争关系的产品售价涨幅比它们更高。

⚠️ **但这种方式往往只能保持极其短暂的时间**，其失效链条如下：

1. 竞争对手很快会制造出能够与之相抗衡的产品；
2. 这些新产品足以抵消价格上涨所增加的利润；
3. 随着时间推移，成本增幅再也不能转嫁到销售价格上；
4. 随之而来的就是**利润率的下滑**。

#### 6.4 三个行业的实证：靠提价的危险性

| 行业 | 时间 | 事件与后果 |
| :--- | :--- | :--- |
| **铝** | 1956 年秋 | 铝市场在短短几个星期内就从**供不应求**转为**各个厂商竞相抛售**。此前铝价一直随成本上升而上涨。除非产品需求增长比产能增加更快，否则价格涨幅无法保持之前那么快速的增长 |
| **钢铁** | 同期 | 在"所有的市场都将看跌"的观点盛行的背景下，一些最大规模的钢铁生产商在市场持续低迷不振的情况下提高了某些**稀缺钢铁产品**的价格。这可能在部分程度上让人们感觉到，这种高利润只是暂时性的，只是生产商把成本涨幅转嫁到了价格上 |
| **冶炼铜** | 1956 年下半年 | 最能说明这种做法从长期角度的危险性（详见下文） |

**冶炼铜行业的完整链条**（最具说明性的案例）：

1. 这些公司对自身相当谨慎，一直将价格压低在**全球平均水准之下**，以防止价格涨得过高；
2. 尽管如此，铜价还是上涨到了相当高的水平；
3. 高价**抑制了需求**，并**吸引新的生产厂商加入**；
4. **苏伊士运河的关闭**，使西欧供需情势失衡的局面雪上加霜；
5. 如果 1956 年的利润率不能算好，那么 **1957 年的利润率则更是不尽人意**。

💡 **结论**：当一个行业的利润率因为价格持续上涨而升高时，这对长线投资者而言**并不是什么好事**。

#### 6.5 上策：用创意方法提升利润率

相比之下，包括铜行业几家企业在内的其他一些公司，不是靠提高价格，而是借助**更有创意的方法**提升了利润率：

| 举措 | 具体做法与效果 |
| :--- | :--- |
| **产品更新与研发部门** | 依靠这些部门保持资本的高效利用并取得成功。它们唯一的作用是**设计出能够降低成本的新设备**，以此抵消或部分抵消逐渐攀升的人力成本 |
| **改善作业程序和方法** | 很多公司不断改善作业程序和方法，研究从哪些地方着手可以提高公司的经济效益。⚠️ 对这种活动而言，一定要妥善处理好**具体举措和相应的会计记录**，这样才能看出其效果 |
| **降低运输成本** | 运输成本的涨幅往往高于其他大多数种类的成本，因为和制造业相比，运输所使用的**劳动力成本所占比例更大**。一些聪明的公司使用**新型的仓储箱**，采用**以前从未尝试过的运输方法**，或是**把货物存放于分公司**以防止造成交互送货的偏差，从而降低了成本 |

#### 6.6 投资者应如何考察

所有这些事情都不是一日之功，它们都需要**事前详细的研究和业务规划**。

- 投资者想要对某家企业进行投资，应密切留意企业所采取的降低成本和提升利润率的新方法**是不是富于创新意义**。
- 在这方面**"闲聊"法可能会是有效的，但远不如直接咨询公司内部人士**——好在大部分企业高管都乐于详细地谈论这方面的事情。

💡 这方面做得最成功的公司，很有可能都建立起了一套**专门的研发创新组织**，使它们在未来能够保持长久的创新能力。这样的公司极有可能为持股人创造最高的长期回报。

### 七、原则7：这家公司是否具备良好的劳动人事关系？

#### 7.1 被低估的利润因素

大部分投资者可能没有充分意识到良好的劳动人事关系对于利润的重要性。然而，**没人不知道恶劣的劳动人事关系会造成不良的影响**——任何人只要稍微看一下财务报表，就能明白持续而又悬而未决的罢工对公司生产经营造成的重大伤害。

⚠️ **但需要强调的是**：人事关系良好的公司和人事关系不良的公司相比，二者的**利润差额要比罢工所造成的直接成本大得多**。

| 良好人事关系带来的收益 | 说明 |
| :--- | :--- |
| **高效的工作环境** | 如果员工觉得雇主是在公平地对待自己，就形成了一个高效的工作环境。在这种环境中，高效率的管理层可以**大幅提高每个员工的生产力** |
| **节省训练成本** | 对所有新员工进行训练需要相当高的成本。人员流动过于频繁的公司得负担这方面**不必要的成本**，而管理良好的公司不需为此烦恼 |

#### 7.2 判断方法：没有通用标准，只能拼凑复合画面

投资者如何判断一家公司的劳动人事关系够不够好？**这个问题没有简单的答案，我们找不到一套适用于所有情况的通用标准。**

💡 我们能做的就是**观察多种因素，然后将所有因素拼凑起来形成一个复合画面**并据此判断。

#### 7.3 工会与罢工：不能简单化解读

| 表面现象 | 常见误读 | 正确理解 |
| :--- | :--- | :--- |
| **没有工会，或只有内部工会** | — | 在当今工会十分普遍的背景下，这类公司可能具备**高于平均水平**的劳动人事关系。因为如果公司内部没有工会，全国性的工会也会在很久之前把员工组织起来 |
| **企业内部有工会组织** | 劳资关系不好 | ⚠️ **绝不是**劳资关系不好的信号。很多劳资关系非常好的公司是**完全工会化**的，因为劳资双方已经学会和睦相处，达成了相当程度的互相尊重和信赖 |
| **完全没有罢工** | 劳资关系良好 | ⚠️ **不见得**能证明劳资关系本质上没有问题。有些时候没有发生罢工的公司就像是个**怕老婆的男人**——没有冲突不代表婚姻生活幸福美满，只是因为当事人害怕冲突而已 |
| **接连不断且悬而未决的罢工** | — | 确实是劳资关系恶劣的体现 |

**正面案例**：像地处芝加哥这种高度工会化城市的**摩托罗拉**，以及位于达拉斯这种正处于工会化进程中的**德州仪器**，这些公司至少都会把劳动力作为公司的一个重要组成部分，并且能够很好地对待员工。

💡 如果一家公司没和国际性工会挂钩而又经营得十分成功，**唯一的解释是公司具备非常成功的人事政策**。

#### 7.4 观察"结果"而非"原因"：两个关键量化指标

为什么员工对某些雇主表现出异常的忠诚，而对其他一些雇主则极为痛恨？这个问题的答案往往错综复杂，很难理清头绪。**投资者最好观察一些能够显示出员工总体感觉的资料，而不必注意导致这种感觉出现的具体背景。**

一系列数字能够说明公司基本员工素质和人事政策的好坏，其中两个重要因素是：

| 指标 | 比较方式 | 含义 |
| :--- | :--- | :--- |
| **员工流动率** | 一家公司相对于**同一地区**的另一家**同类**公司的高低 | 流动率越低越好 |
| **应聘人数** | 一家公司的应聘人数相对于同一地区另一家公司的多少 | 在一个**从未出现过劳动力供过于求**的地区，如果有很多应聘者都希望到某家公司工作，那么这家公司从劳动人事关系良好的角度通常是**值得投资**的 |

#### 7.5 需要留意的特殊细节

除了这些普遍的数据之外，投资者还应注意一些特殊细节：

**（1）化解员工不满情绪的机制**

- 劳动人事关系良好的公司往往会**尽一切努力化解员工的不满情绪**。
- ⚠️ 管理层如果**不重视员工的小抱怨**，而且**拖很久才处理**，那么这种不满就会慢慢蔓延，最终导致出现严重的大问题。

**（2）公司的工资等级**

| 情形 | 判断 |
| :--- | :--- |
| 公司支付的工资在其所处地区**高于**行业平均水平，**且**公司利润也高于平均水平 | 这家公司的劳动关系**可能不错** |
| 公司净利润中很大一部分都来自它所支付的工资**低于**所处地区平均水平 | ⚠️ 投资者如果买入它的股票，**迟早会蒙受严重的损失** |

#### 7.6 最后：高级管理者对基层员工的态度

投资者应密切留意高级管理者对基层员工所持的态度。有的管理人员**嘴上说得口若悬河，骨子里并不认为自己需对普通员工负起责任，也不关心这些普通员工**。其典型表现包括：

- 他们最关心的就是**不能让营业收入流入普通员工的比例高于工会所争取到的那个标准**；
- 他们根据公司销售收入或净利润预期的**微小变化**任意大批量雇佣或解雇员工——员工的家庭会因此受到严重影响，导致生活困难，但他们不觉得自己应该对此负责任；
- 他们没有让普通员工觉得**公司需要他们、倚重他们**，没能让员工觉得**自己是公司的一部分**，更没有让员工觉得**在公司能体会到荣誉感**。

⚠️ 一家公司的管理层如果抱有这种态度，那么它通常**不会是最理想的投资目标**。

### 八、原则8：这家公司的高级管理者之间关系很好吗？

#### 8.1 为什么高管关系比基层关系更为重要

如果说管理层与低阶层员工保持良好关系很重要，那么**在高级管理者之间保持融洽的人际氛围就更为重要**。

- 这些人的**判断力、创造力和团队协同力**，对公司的运转有着举足轻重的作用，因此**工作压力也会很大**。
- ⚠️ 所以，有些时候高级管理者之间彼此有矛盾，就很可能导致某些高级管理者**离开公司**，或者在工作时**不那么竭尽全力**。

#### 8.2 高管关系融洽的公司具备哪些特征

高级管理者之间关系融洽的公司，往往能给投资者提供最好的投资机会。这样的公司通常具备以下特征：

| 特征 | 具体表现 |
| :--- | :--- |
| **对最高领导有信心** | 高管们对**总裁和董事长**怀有很强的信心 |
| **凭能力晋升** | 公司内部高低各个阶层的员工都能意识到，在公司内晋升靠的是**能力**，而不是靠**办公室政治**。即便是掌握企业控制权的**家族成员**，也不会升迁到比他更有能力的人之上 |
| **主动调薪** | 公司会**定期调整薪水**，使公司在高管们提出涨工资的要求之前就已经满足了他们的需求。公司薪水至少要跟**业界、当地的标准**看齐 |
| **内部提拔优先** | 除了最基层的工作，只有在**组织内部无法找到适合的人选**来填补位置空缺的情况下，管理层才会从公司外部聘用人员 |
| **不容忍拒绝合作者** | 高级管理者必须明白，只要人们在一起工作就难免结党成群或发生一些摩擦，但**绝对不能容忍有人不肯在团队中与他人合作**。这样，人际摩擦造成的损失就会降到最小 |

#### 8.3 投资者的考察方法

💡 只要与公司**不同责任阶层**的高级主管闲聊一下，问上几个问题，投资者往往就能了解到高级主管间的关系是否比较融洽。

⚠️ **企业高管之间的关系越不融洽，这家公司就越不可能成为好的投资目标。**

### 九、原则9：公司管理是否很有层次？

#### 9.1 一人独撑的风险

如果其他因素都配合到位，小公司也能在一位很有才干的领导人的管理下表现出色，使这家公司在多年内都有可能是很好的投资目标。

⚠️ 然而，**一个人的能力毕竟是有限的**。即使是规模较小的公司，投资者也应该提防**重要人物不在其位**所带来的灾难。

💡 如今一些优秀的小公司的投资风险，其实并没有表面上看起来那么大——因为最近的一个趋势是，那些**管理人才云集的大公司时常会买下规模较小的公司**。

#### 9.2 规模瓶颈：1500～4000 万美元的关口

真正值得投资的公司是那些**能够持续成长**的公司。一家公司或早或晚会遇到某种**规模瓶颈**，此时除非它在某种程度上培养出高级管理人才，否则将没有能力实现进一步的发展。

| 项目 | 内容 |
| :--- | :--- |
| **瓶颈出现的时点** | 通常发生在公司**年销售额上升到 1500～4000 万美元**的时候 |
| **个体差异** | 这一点在不同公司之间体现各异，根据它们所处的**行业**以及**最高领导人管理公司的才能**而定 |
| **此时的关键判断** | 正如原则8 所描述的，**高级管理人员之间的关系是否融洽**，对于判断这家公司股票是否值得投资就有非常重要的意义 |

#### 9.3 核心政策：对管理者的授权

要达到原则8 的要求，就必须**深入培养起合适的管理者梯队**。但是，除非实行某些额外的政策，否则就无法培养出这样的管理人才。**其中最重要的是对管理者的授权。**

> 如果从最高级别到基层的管理人员**没有真正执行分配的权力**，那么这些优秀的管理者便如同**生龙活虎的动物被关在牢笼之中**，无法发挥出自己的才能和活力。他们没办法进一步发展自己的能力，因为**根本没有施展的机会**。

#### 9.4 "事必躬亲"型高管的两大问题

一家公司的高级管理者如果**事必躬亲**，试图插手日常的运营业务，则这家公司成为最富吸引力的投资目标的可能性就很小。这样的高管虽然本意是对公司好，但如果**经常跨越自己授予部属的权限**，就会把他们经营的公司排除在优质投资目标的行列之外。

⚠️ 无论一位高管处理具体事务的能力有多强，一旦公司达到一定的规模，他都会在两方面碰到问题：

1. **有太多的琐碎事情需要处理**，令他无暇一一处理；
2. **有能力的人得不到锻炼**，也就无法实现公司接下来的进一步增长。

#### 9.5 另一个值得留意的信号：是否虚心接受批评

在判断一家公司的管理梯队层次是否合适时，还有一件事值得投资者注意：

> 高级管理者是否**乐于倾听并能够虚心接受、考虑员工提出的建议**，即使这些建议有时会很尖锐地批判目前的管理现状。

当今现代企业之间的竞争如此激烈，改善和变革的需求也如此强烈。⚠️ 如果高级管理者**骄傲自满或无动于衷**，没有能够及时采纳那些如同黄金般珍贵的新思想，那么：

- 处于这种氛围的公司就**不应该被投资者所看好**；
- 这样的公司也**不可能培养出一代又一代年轻有为的管理者**。

### 十、原则10：这家公司的成本分析和会计记录做得如何？

#### 10.1 详尽成本记录的必要性

> 如果一家公司**不能够准确和详尽地列出业务运营中每个细节的成本状况**，则这家公司一定无法在长时间内取得经营上的成功。

**详细记录成本的两个直接作用**：

1. 只有详细地记录成本，管理层才能知道**什么事情是最需要注意的**；
2. 也只有这么做，管理层才能看出他们**有没有恰当地解决了每一个需要注意的问题**。

#### 10.2 多产品经营下的严重后果

最成功的公司往往不只生产一种产品，而是生产许多种产品。如果管理层无法明确知晓**每一种产品相对于其他产品的实际成本情况**，那么公司就会处于极其不利的形势之中：

| 后果 | 具体表现 |
| :--- | :--- |
| **无法定价** | 在不允许过度竞争的情况下，想制定出能够确保最大限度地获得利润的**价格策略**几乎是不可能的 |
| **无法配置资源** | 将无法得知**哪种产品值得在推广和促销上做出重大投入** |
| **最糟糕的情况** | ⚠️ 管理层并不知道有些**表面上看起来经营得很成功的活动，其实可能正在赔钱**，使得整体利润逐渐减少而非节节攀升。这种情况下，想做出明智的计划更是不可能的 |

#### 10.3 投资者的能力边界与务实结论

虽然企业的财务控制在选择投资目标时十分重要，但对于小心谨慎的投资者而言，**很少有机会能看清楚他想投资公司的全貌**，以及知晓其财务控制与成本分析及相关活动的真实情况。

**"闲聊"法在此的效果有限**：

- 它有时候能揭露出一家公司真正的**缺陷所在**；
- 但除此之外，"闲聊"法能提供的其他信息并不多。

**直接询问内部员工的情况**：

- 通常能够得到非常真诚的回答和真实的成本数据；
- 他们往往能给出详细的成本资料数据，来证明所说的话是真实的；
- ⚠️ 但**最重要的并不是那些详尽的数据，而是这些数据的准确性**。

💡 **务实的态度**：小心谨慎的投资者最好是**承认财务成本控制的重要性**，同时也要**充分认识到自己在评估财务成本数据真实性方面的能力是比较有限的**，无法给出绝对准确的评估。

**在这些限制之下的大概结论**：

> 在公司高管认识到专门的财务控制和成本分析的重要性的前提下，只要这家公司**经营能力的大多数方面都高于行业平均水平**，那么它在财务控制和成本分析方面的表现**也可能远高于平均水平**。

### 十一、原则11：公司在业务的其他方面是否具备相对于竞争者的显著优势？

> **完整表述**：公司相对于行业内的其他公司而言，在业务的其他方面是否具备竞争力，以便让投资者找出了解该公司相对于竞争者具备何种显著优势的线索？

#### 11.1 一个"包罗万象"的问题

按照定义，这是一个貌似包罗万象的问题。因为每家公司之间的差别必定非常大——**有些事情在某个行业非常重要，而在其他行业则可能不怎么重要，或者根本没有任何意义**。

| 能力 | 高度重要的场景 | 不重要的场景 |
| :--- | :--- | :--- |
| **处理不动产事务的能力**（评估承租物的品质） | **零售业**诸多重要运营业务中，这是一项至关紧要的业务 | 其他很多行业中，这方面能力是否高超并不那么重要 |
| **处理信贷事务的能力** | 对某些公司非常重要 | 对其他一些公司就没那么重要，或者根本无足轻重 |

💡 **考察方法**：在这些情况下，我们的老朋友——**"闲聊"法**，往往能让投资者非常清楚地了解全局情况。如果所研究的问题很重要、值得深入研究，那么所得出的结论往往**可以用数学比率来加以验证**，比如：

- 单位销售额的相对承租成本
- 坏账损失比
- 等等

#### 11.2 保险成本：一个高度综合的能力指示器

很多行业中，**总保险成本在总销售额中占有的比例**非常重要。

| 项目 | 内容 |
| :--- | :--- |
| **量化效果** | 有些时候，如果一家公司的总保险成本比同等规模的竞争对手**低 35%**，那它的**利润率将高出很多** |
| **研究建议** | 对于那些保险对利润有非常大影响的行业，如果仔细研究这些比率，并和信息丰富的**保险业专业人士**进行讨论，那一定会受益良多 |
| **指示意义** | 对于了解某家公司管理层能力是否出色来说，这些资料虽然只是一个辅助，但却**相当具有指示性** |

**为什么保险成本能反映综合管理能力？**

低廉的保险成本**不仅仅**是由于处理保险事务的技能比较高（就像处理保险事务的技能一样，租赁成本也会低于行业平均水平）。它们反映了公司处理以下三方面的**综合能力**：

1. **人事关系**
2. **存货**
3. **固定财产**

从而达到**减少意外发生、物资损耗和浪费**的目的，进而降低保险成本。

💡 **保险成本的高低可以准确地指示出行业中哪家公司经营得更为优秀。**

#### 11.3 专利权：对大公司与小公司意义截然不同

**（1）专利权对大公司的价值**

在不同公司之间，专利权的重要性也有很大差别。对大公司而言，掌握比较多的专利权往往能带来许多在基本竞争优势之外的好处：

| 好处 | 说明 |
| :--- | :--- |
| **阻隔外来竞争** | 专利权多，就可以防止公司某些业务部门的运营遭遇激烈的外来竞争 |
| **提升整体利润水平** | 通常情况下，公司相关业务的生产线将因享有专利权而具备**较高的利润率**，这又能进一步提升公司其他生产线的**平均利润水平** |
| **成本优势** | 具备高壁垒专利权的公司通常能以**最简单、成本最低廉**的方式生产出某种产品，而竞争对手必须付出更多努力才能达到相同效果 |

⚠️ 这样，拥有专利权的公司就占有了明显的竞争优势——**虽然这种优势带来的好处通常不会很大**。

**（2）为什么大公司不应依赖专利权**

在这个专业技术知识普及的年代，大公司在一个受到专利权保护的行业中所能做出的成绩往往是比较有限的。

> 专利权通常只能阻止**一少部分**竞争对手获得同样的经营结果，但是**没办法阻止所有的**竞争对手。

基于这一理由，很多大公司并不寄希望于利用专利权来屏蔽竞争对手的威胁，反而**授权竞争对手使用它们的专利，仅收取很低廉的费用**，同时希望别人也以同样的方法投桃报李，允许它们使用自己的专利。

**保持竞争优势的真正要素**（重要性远大于专利权保护）：

- 制造技术
- 销售和服务组织
- 顾客的口碑
- 对顾客与市场的了解

⚠️ **反向信号**：实际上，如果大公司维持利润率的主要方法是靠专利保护，那这通常是其**投资价值减弱而非增强**的表现。专利无法提供无限期的保护——如果公司主要靠专利来保持竞争优势，那么**当专利保护到期的时候，公司的获利情况可能就会遭到重创**。

**（3）专利权对初创小公司的关键意义**

如果是一家年轻的公司刚开始建立生产、销售和服务组织，而且正处于积累客户的初期阶段，那么情况则**大不相同**：

1. 如果没有专利，这种初创公司的产品就可能被一些**树大根深的大公司所剽窃**；
2. 大公司接下来会运用它们已经形成的**分销渠道和庞大的客户关系网络**；
3. 将这些年轻的竞争对手**打败出局**。

💡 所以，对于那些刚开始营销独特产品或服务的初创型小公司，投资者应密切审视它们的**专利保有状况**，应该得到其**专利权保护范围的准确信息**。

⚠️ **关键区分**：获得某种产品的专利是一回事；**通过阻止别人以相似的方式生产产品，从而在竞争中得到保护，又是另一回事**。

#### 11.4 案例：改良产品胜过静态专利

不过，就如何在竞争当中得到保护而言，**不断地通过提升制作工艺来改善产品，远比静态的专利权有用得多**。

几年前美国西海岸一家初创电子制造商（当时规模比如今小得多）的经历：

| 阶段 | 事件 |
| :--- | :--- |
| **1. 成功** | 制造出一种新产品并在市场上取得成功 |
| **2. 被抄袭** | 行业内一家大型公司将它的产品照猫画虎地抄袭过来，冠以自己的品牌进行销售 |
| **3. 抄袭的缺陷** | 据这家初创公司产品设计师的说法，那家大型竞争对手将小公司在产品研发设计上的**缺点和优点不分好坏一概纳入**自己的产品设计中 |
| **4. 小公司迭代** | 大公司将抄袭来的产品推向市场时，小型制造商**正好消除了原产品的缺点，推出了新型改良产品** |
| **5. 结果** | 小公司的产品自然更受市场欢迎，大公司的产品卖得不好，只得从那个领域**撤退** |

💡 **结论**：这样的例子可以说司空见惯。从中可以看出，保持竞争地位**最有效也是最根本的方式，就是在产品的研发设计方面保持领先地位**，而非仅依靠专利权。

⚠️ 投资者至少应该明白**不能过分强调专利权保护的重要性**——评估某项投资是否理想的时候，专利权保护有些时候是个重要因素，但不应该过分看重。

### 十二、原则12：这家公司对利润有没有短期或长期的展望？

#### 12.1 两种截然不同的经营目标

| 类型 | 目标 | 结果 |
| :--- | :--- | :--- |
| **短期导向** | 业务运营目标是**短期内追求到最大的利润** | 眼前利润最大化 |
| **长期导向** | **刻意抑制近期的利润**，以图建立良好的信誉 | 在更长的时期内获得**较高的总体利润** |

#### 12.2 从对待供应商和客户的态度中识别

通过观察公司对待客户和供应商的态度，我们可以发现很多这样的例子：

| 对象 | 短期导向的做法 | 长期导向的做法 |
| :--- | :--- | :--- |
| **供应商** | 总是以**最严苛的态度**来对待供应商 | 同意向供货商支付**比合约价更高的价格**，以确保原材料来源的可靠，或为了在市场情况改变、需求骤然变大时能够获得**高品质的生产所需零部件** |
| **客户** | — | 在老客户碰到困难时**很乐于向其提供帮助**。这样一来公司在某一笔交易上可能没有利润，但**从长期来看有望得到远高于平常水平的利润** |

#### 12.3 考察方法与结论

💡 通过**"闲聊"法**往往可以很清楚地看出各家公司这种政策上的差别。

> **投资者如果想要获得最高的利润，应该选择在利润方面眼光长远的公司。**

### 十三、原则13：公司是否会大量发行股票，导致现有股东利益大幅受损？

> **完整表述**：在可预见的将来，这家公司是否会通过大量发行股票来获取足够的资金以利公司发展？现有持股人的利益是否因预期中的股份数量增加而蒙受大幅损失？

#### 13.1 为什么财务要点只占 1/15 的篇幅

典型的投资类书籍都会花很大篇幅探讨公司的现金状况、企业组织结构、各种等级的证券占总资本的比例等。很多读者可能会问：为什么这个涉及财务方面的要点在总共十五个原则中所占的篇幅**仅仅是 1/15**？

> **理由正源于本书的基本信念**：有眼光的投资者**不应仅因股价便宜就买股票**，而只有在它**有望为你带来回报**时才考虑购买。

#### 13.2 优秀公司自然具备融资能力

在现实当中只有极少数的公司能够如数满足本章所谈的其他十四个原则，或是满足其中的一大部分。能够达到这些标准的公司：

1. 很容易就能按照**当时适合自身规模的利率水平**得到贷款；
2. 并且达到**本行业所允许的最高信贷额度**。

假设这样一家公司在未来的营业收入成长、利润率、管理层素质、研究发展状况等符合本章讨论的其他各个原则，那么即使它一旦达到了最高的负债上限或接近上限、此时仍然需要更多的资金，它**还能以某种价格发行股票来筹措资金**——因为投资者通常会热衷于投资这种企业。

#### 13.3 判断的核心：现金 + 继续借款能力是否够用

因此，如果投资者只愿意对杰出的公司进行投资，则最要紧的事情是：

> 这家公司的**现金**加上其**继续借款的能力**，是不是满足未来几年的资本需求，从而实现在未来几年内的最好发展。

**如果公司真的满足这样的条件，而且愿意按照最大信贷额度借钱**，那么普通股投资者在很长一段时间内就不用担心了。

💡 **为什么不必担心**：如果投资者已经对当时的情势做出了恰当的评估，那么公司未来几年内可能发生的任何股权融资，都能使股价上升到一个**远高于目前价格**的水平。这是因为：

1. **短期融资会导致利润的增加**；
2. 几年后所需要的继续筹措资金的需求，**会把股价推升到一个比目前股价高出很多的水平**。

#### 13.4 若贷款能力不足：必须仔细核算股权稀释

如果公司目前的贷款能力不甚充足，就有必要通过发行股票来筹措资金。这种情况下，判断投资对象是否具有吸引力时必须仔细核算：

| 正面效应 | 负面效应 | 核心问题 |
| :--- | :--- | :--- |
| 筹措资金后，企业的收益可能会增加，目前的普通股持有人将因此受益 | 发行股票的增加额会导致**股权的稀释**，持股者的利益将蒙受损失 | **股票持有者的利益到底损失了多少？** |

#### 13.5 可转换优先证券的稀释效果如何计算

和发行普通股的股权稀释效果一样，发行**可转换优先证券**所导致的稀释效果在数字上也是**可以计算出来**的。

| 要点 | 说明 |
| :--- | :--- |
| **转换条款特征** | 可转换优先证券通过条款规定，能以**比发行时的市场价格高一些**的价格行使转换的权利，这个价格通常比发行时的市价**高出 10%～20%** 不等 |
| **为什么可以忽略转换价格** | 由于投资者一般不会对 10%～20% 的微小涨幅有兴趣，而是**力图得到几年内十倍或百倍的涨幅**，所以转换价格一般可以不予理会 |
| **正确的计算前提** | 应该在**假设新发行优先证券完全转换**的前提下计算股权稀释效果 |

💡 **换句话说**：在计算真正在外流通的普通股数量时，最好假设——

- 所有的**优先可转换证券**都已经转换完毕；
- 所有的**权证、期权**等也都已经行权完毕。

#### 13.6 如何据此做出取舍

| 情形 | 判断 |
| :--- | :--- |
| 买入普通股之后几年内公司将发行股票募资，且发行新股之后普通股持有者的**每股税后利润增加幅度比较小** | 只能得出一个结论：**公司管理层在财务判断方面做得很差**，所以这家公司的普通股**不值得投资** |
| 公司**财务判断不佳**，但在其他十四个原则上都可以获得很高的评价 | ⚠️ 除非这家公司在财务方面的判断**非常糟糕**，否则投资者**不应该仅仅因为其在财务上的不足而将其放弃**——因为它也有望在未来有出色的表现 |
| 公司**财务面很强或者拥有很多现金**，但**不符合其他十四个原则中的某一个** | 为了在长期获得最大幅度的利润，投资者**也不应该选择这家公司作为投资目标** |

### 十四、原则14：管理层是不是向投资者报喜不报忧？

> **完整表述**：管理层是不是向投资者报喜不报忧？业务顺利时口若悬河，而在出现问题或发生令人失望的事情时三缄其口？

#### 14.1 挫折是成功的必然代价

即使是经营管理最好的公司，有时也会碰到始料未及的困难，诸如：

- 利润的减少
- 市场需求出现萎缩
- 需求转向别的产品
- 等等

另外，如果有些公司**年复一年地致力于技术研究**，一直尝试生产新产品、研发新工艺，那么它就有望给投资者带来很高的利润，投资者应该买进这种公司的股票。但**依据平均数法则**：

| 可能的失败形态 | 后果 |
| :--- | :--- |
| **彻底失败** | 有些新产品或新工艺的研发会在**耗费巨资后遭受惨败** |
| **投产延误** | 还有一些会在投产阶段的**早期出现不可预料的延误**，从而出现令人心痛的额外花费。这些沉重的额外预算成本往往会**持续好几个月**，就算是规划得最谨慎的整体利润预测也会被它打破 |

💡 **正确的态度**：就算是在一些最成功的企业中，这种令人失望的事情也是无法避免的。如果你具备良好的判断力而且愿意坦诚面对这种情况，就会明白**这只是最后成功的代价之一**——这种情况往往是**公司实力强劲的象征，而非弱势的表现**。

#### 14.2 管理层的反应是宝贵线索

公司管理层面对这种事情的态度，是投资者考察公司的宝贵线索。管理层在碰到坏事情时可能出于这样或那样的原因三缄其口，而不像碰到好事时那样侃侃而谈。具体的原因分好几种：

1. 他们可能**提不出解决眼下突如其来的难题的办法**；
2. 管理层可能**已经产生恐慌情绪**；
3. 也可能是他们**不觉得自己需要对持股者负责任**，不认为自己有必要向持股者报告真实的情况。

⚠️ **不管出于什么样的理由，一旦一家公司在设法隐瞒坏消息，那么投资者最好就不要将其纳入选股目标之列。**

### 十五、原则15：管理层是否具备毋庸置疑的诚信、正直态度？

#### 15.1 内部人士的信息与资产优势

> 公司的管理层通常远比一般持股者**更容易接触到公司的资产**。在公司掌握经营最高权力的人们，总是有无数种方法能**在不违反法律的前提下损公肥私**，牺牲一般股东的利益来为自己和亲属谋利。

#### 15.2 四种典型的损公肥私手法

| 手法 | 具体做法 | 备注 |
| :--- | :--- | :--- |
| **1. 超额薪酬** | 给自己或自己的亲属发放**远高于他们实际工作贡献**的工资 | — |
| **2. 高价关联交易（资产）** | 把自己拥有的财产以**高于市场价**的价格出售或租赁给公司 | ⚠️ 在规模较小的公司中，这种做法有时**很难察觉**。因为控制公司经营权的家族或重要高管，有时候买进不动产或向公司提供租赁的目的**并不是为了获取不当利益**，而是真心希望公司有限的运营资金能用在其他的正当目的之上 |
| **3. 中间商抽成** | 要求公司的供货商通过某些**中间商**将产品销售给公司，而这些中间商的股东是这些内部人士自己，或他们的亲戚朋友。这些中间商**并没有提供什么服务**，但向公司收取一定的中介费用 | — |
| **4. 滥用股票期权** ⚠️ | 滥用发行普通股期权的权力。这原本是一种**合法的方法**，目的是奖励那些能干的管理人员，但某些人会滥用这种职权，**给自己发放很多股票**，而奖励的数量从一个公正的立场来看，已经**远超于他们对公司的贡献** | **对投资者造成损失最大**的一种 |

#### 15.3 唯一的自我保护方法

当投资者面对诸多滥用职权的做法，**只有一种方法能保护自己**：

> 就是将自己的资金**只投资于那些管理层对股东怀有强烈责任心和道德感的公司**。

💡 **"闲聊"法对于寻觅这样的公司非常有用。**

#### 15.4 ⚠️ 唯一的"一票否决"原则

关于已经介绍过的全部十五个原则：

| 情形 | 结论 |
| :--- | :--- |
| 公司没能满足**其中某一个**原则，但在其他原则上都得到了很高的评价 | 仍不失为一个**值得考虑**的投资对象 |
| **管理层对股东没有强烈的责任感** | ⚠️ 不论其在别的方面得到多高的评价，那就是一个**很严重的问题**——投资者**绝对不要考虑投资于这样的公司**。 |
