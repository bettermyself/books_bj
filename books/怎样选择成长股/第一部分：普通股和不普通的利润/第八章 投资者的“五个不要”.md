## **第八章 投资者的"五个不要"**

> **核心命题**：投资的成败不仅取决于"做对什么"，也取决于**避开哪些看似合理、实则昂贵的陷阱**。本章列出五条禁令，它们分别对应对象选择、市场场所、信息来源、估值判断与交易执行五个环节。

| # | 禁令 | 要防范的错误直觉 |
| :--- | :--- | :--- |
| 1 | 不要买创业阶段公司的股票 | "上市即占据有利地位" |
| 2 | 不要忽视在"场外市场"交易的好股票 | "没上交易所就没有流通性" |
| 3 | 不要因为喜欢年报的"语调"而买股票 | "文风好=管理层好" |
| 4 | 不要认为高市盈率必然已反映未来成长 | "2 倍市盈率 = 提前吃掉 5 年收益" |
| 5 | 不要计较蝇头小利 | "省下的每一分钱都是赚到的" |

### 一、不要买创业阶段公司的股票

#### 1.1 表面上的吸引力从何而来

有一个比较接近成功投资核心的说法：要在投资中找到**正在开发新的产品与工艺，或者正在开发新市场**的公司。而刚刚成立或即将成立的公司，往往正在尝试做这些事。

| 创业公司的卖点 | 具体表现 |
| :--- | :--- |
| **开发新产品** | 许多这类公司的成立，为的就是开发各种各样的新产品 |
| **进入高成长行业** | 很多公司的创立，是为了到一个成长潜力巨大的行业中去掘金，比如**电子行业** |
| **博取资源类暴利** | 还有很多新公司意图在**矿物开采或其他自然资源**领域有所斩获，一旦成功十分诱人 |

基于以上理由，乍看之下，这些**尚未盈利的初创公司貌似颇具投资价值**。

还有一种说法往往很能提高投资者对此类公司的兴趣：只有在公司股票**首次公开上市时就买入**，才有机会"占据有利地位"。一家经营成功的公司，其股票首次公开上市的市盈率仅有几倍而已，为什么要让别人来把钱赚走呢？我们为什么不使用像寻找优秀老牌公司的办法，通过询问和调查去找出正在推销股票的优秀创业型公司呢？

#### 1.2 老公司与创业公司：可观察性的天壤之别

从投资的观点，我相信那些**业务运营不足两三年、盈利年份不足一年**的公司，根本无法与盈利稳定、根基稳固的老公司相比——**即使这家老公司规模很小，年营业额不超过 100 万美元。**

| 考察维度 | 根基稳固的老公司 | 创业阶段的公司 |
| :--- | :--- | :--- |
| **经营部门运转** | 生产、销售、成本会计核算、管理团队的团队合作、业务运营等**一切问题均在正常运营中，可被观察** | 只能通过**业务规划蓝图**去猜测可能出现什么问题、可能具备什么优点 |
| **第三方意见** | 能了解到其他**有真知灼见的观察者**的意见，因为这些人会定期观察该公司局部或所有的相对优势与劣势 | 缺乏长期跟踪者，无从交叉验证 |
| **判断难度** | 以观察为基础 | 靠猜，**困难得多，做出错误结论的可能性也高很多** |

⚠️ 实际上，无论投资者的技巧多么好，这事做起来都是极为困难的。与以老公司作为判断对象相比，从创业期的公司中挑选出能达到"**安打**"（棒球术语）的优秀公司，成功率极低。

#### 1.3 创业团队的结构性缺口

年轻的创业型公司往往由**一两个在业务经营方面具备高超才能的人**所主导，但难免会欠缺其他一些不可或缺的才能。

| 常见的人才组合 | 缺失的能力 |
| :--- | :--- |
| 卓越的**推销员** | 缺乏其他经营能力 |
| 优秀的**发明家或生产高手** | 完全不知道即使是最好的产品也需要**高超的营销方法**来赢得市场 |

⚠️ 更棘手的是沟通层面的两道墙：

1. 投资者基本上**无法使这些人相信**，他们自身或他们年轻的公司缺乏其他的技能；
2. 投资者更不可能向他们**指出哪里能找到**所需要的人才。

#### 1.4 💡 结论：把创业公司留给能补位的专业机构

不管创业公司第一眼看上去多么吸引人，我认为这些公司应留给**专业机构**去投资。

| 主体 | 能否胜任创业期投资 |
| :--- | :--- |
| **专业机构** | ✅ 具备优秀的管理人才，在创业公司业务开展之初，一旦公司暴露出弱点便能**及时提供支援** |
| **一般投资者** | ❌ 无法提供这种人才，更无法**说服公司管理层**相信有必要利用这种支援 |

如果一定要投资于创业公司，往往会是**一段梦想破灭的经历**。在老公司当中有很多尚好的投资机会，普通投资者应该把"**绝不要买入创业公司**"当作一条原则来遵守，不管这些创业公司看起来多么吸引人。

### 二、不要忽视在"场外市场"交易的好股票

> 本节的落点是**市场流通性**：未上市交易的股票相对于已在证券交易所上市股票的吸引力，与两类股票各自的流通性有极为密切的关系。

#### 2.1 混淆的来源

每个人都应该认识到市场流通性的重要性。通常情况下，绝大多数的买入行为都是针对那些**由于某种原因而卖出**的股票，这个原因可能与金融市场有关，也可能是由于个人因素。

关于哪些股票可以为投资者带来足够的保护、哪些不能，投资者的心中会有一些混乱。对于没有在任何交易所上市交易的股票（通常被称为"**场外交易**"股票）来说，市场对它们的需求反过来又产生了更多的混乱。

#### 2.2 25 年间市场结构的四重变化

出现这种混乱的根本原因在于：25 年来，普通股的买入从根本上发生了变化，这些变化使得 **20 世纪 50 年代**的市场和 **20 年代**那令人难忘的市场有很大的不同。

| 维度 | 20 年代及以前 | 50 年代（当下） |
| :--- | :--- | :--- |
| **客户结构** | 股票经纪人服务的客户都是**有钱人**，而且数量相当少 | 一次性大量买入的买方逐渐减少，**每次少量买入**的买方大量增加 |
| **单笔规模** | 大部分客户买入数量相当大，往往一买就是**几千股** | 小额为主 |
| **行为性质** | 买主的目的通常是以更高的价格卖给另一个人，与其说是投资，**不如说是赌博** | 更适合作为**追求长期增长**的投资标的 |
| **支付方式** | **融资买入**（借钱买股票）为人们所接受 | 大多数买入都是**现金支付** |

驱动这些变化的力量有三类：

**① 财富分布的变化**

- 较高的**所得税和遗产税**；
- 更重要的是美国各个阶层的**收入差距逐渐缩小**——非常富有和非常贫穷的人数量都在逐年减少，**中产阶级人数逐渐增加**。

**② 机构买方的崛起**

投资信托、养老基金和分红信托，甚至某些大银行信托部门，**不再代表少数的大资金买方**；相反，他们是职业经理人，受托处理**无数小规模买方聚集起来的资金**。

**③ 法律与监管的重塑**（与机构变化互为因果）

| 举措 | 目的与效果 |
| :--- | :--- |
| **证券交易委员会**的建立 | 阻止过去发生的一些猖獗行为，比如引发股票市场投机交易的**联合操纵** |
| 现行法律法规 | 相比以前的习惯性做法，**限制了融资买入** |
| 公司自身的演变（最重要） | 如今的企业比以前更适合作为**长期增长**的投资标的，而不是仅作为随时买卖的投机工具 |

#### 2.3 进步的代价：流通性下降

所有这些情况都深刻改变了市场环境。尽管以**牺牲市场流通性**为代价，但毫无疑问，这种改变是一种**市场化的进步**。

| 观察项 | 实际变化 |
| :--- | :--- |
| 大多数股票的流动性 | **降低**了，而不是增加 |
| 纽约股票交易所成交量 | 虽然经济取得了惊人的增长，再加上似乎无休止的**拆股**行为，成交量还是**减少**了 |
| 小规模交易所成交量 | **基本消失** |

⚠️ 一个不容忽视的事实：赌徒、高频交易的投机者，甚至"容易受骗的傻瓜"都试图猜透那些不利于经济发展的联合操纵，但他们**却构成了一个真实的市场**。

#### 2.4 经纪人与销售员：两种截然不同的商业模式

我不想玩弄文字游戏。不过，我们必须知道这些事情会导致**股票经纪人数量日益减少，而股票销售员数量日趋增加**。

| 对比项 | 股票经纪人（broker） | 股票销售员（salesman） |
| :--- | :--- | :--- |
| **工作场所** | 在**竞价市场**中工作 | 主要服务场外交易 |
| **工作内容** | 接受一个**已经决定好**投资行为的买入指令，然后将这张委托单与自己或其他经纪人的卖出委托单**撮合** | 必须花费**较长时间**才能说服客户采取某些投资行为 |
| **耗时** | 这个过程不会花很长时间 | 一天中能够运用的时间就那么多 |
| **收费模式** | 每次交易只收取**很低的手续费**，靠成交量取胜；只要委托单交易量很多，全年下来仍有可观利润 | 必须收取**较高的服务佣金** |
| **客户构成** | 大额委托单更划算 | 在今天的经济环境下，**小客户是大部分销售员的服务对象** |

证券交易所的运营方式主要仍需依赖股票经纪人，而不是股票销售员。他们的佣金比例提高了，但**涨幅只和其他大多数的服务差不多**。

#### 2.5 场外市场的报价机制

相对而言，场外交易市场的运营原理则完全不同。**全国证券商协会**的指定会员们，天天都会在地区性报纸上刊登一长串未上市而又有吸引力的证券行情报价，当地的股票交易者对买卖这些股票很有兴趣。他们和每一种证券的场外交易机构联系都很密切，从而编纂出这些行情报价。

| 报价性质 | 证券交易所 | 场外交易市场 |
| :--- | :--- | :--- |
| **数字含义** | 实际交易的价格范围 | ⚠️ **并非**实际成交价，而是**买价和卖价** |
| **理论定义** | — | 任何有兴趣的金融机构**愿意买入**每种股票的最高价格，以及**愿意卖出**股票的最低价格 |
| **为何如此** | 有集中结算机构 | **缺乏一个可以报告交易价格的集中结算机构**，做不到这一点 |

#### 2.6 买卖价差是怎么构成的

通过仔细的检查几乎总是能够发现，买方或卖方的报价总是**很接近提供报价时股票的实际价格**。卖方的报价比买方报价要高，差价通常是证券交易所中以同样价格所售股票收取手续费的**数倍**。

这个差价的用途被明确设计过：

1. 让场外交易商能够**以买价买入**；
2. 支付给花时间推销证券的销售员一定的**手续费**；
3. 再去除一些**日常费用**后仍能获得**合理的利润**。

⚠️ 但另一面同样重要：如果客户（**特别是大客户**）主动找到同一家金融机构出价买入某只股票，这时就**不需支付销售员的手续费**，通常能以买价加上相当于证券交易所手续费的价格买到股票。

> 一位场外交易商曾这么说过："买入的一边，我们有个市场。卖出的一边，我们有两个市场。我们有**零售和批发市场**，部分取决于买进的数量，部分取决于卖出的数量和包含的服务。"

#### 2.7 这套制度会被滥用吗

如果碰到**厚颜无耻的交易商**，这套制度明显会遭到滥用——其他的制度也是如此。但是，如果投资者挑选场外交易商时，和选择其他任何为他服务的专家一样谨慎，这种制度就会**运营得非常好**。

| 现实约束 | 制度的应对 | 投资者的收获 |
| :--- | :--- | :--- |
| 一般的投资者没有时间，也没有能力为自己挑选证券 | 交易商在**严密的监督**之下，只允许其销售员销售**某些证券种类** | 这种做法实际上等于让销售员扮演了**投资咨询顾问**的角色 |

💡 因此，投资者投入一定的成本是值得的。

#### 2.8 真正的优势在卖出端：流通性

从更加老练投资者的观点来看，这套制度的**真正优势不在于买进股票方面**，而是它能够**提高未上市股票的流动性或市场性**。

这些股票能够给交易商带来足够高的利润，因此其行为模式是：

- 大量的场外交易商会**保有一定库存量**的流通性非常好的股票，他们一点儿也不介意在市场上**多买 500 股或 1000 股**；
- 如果他们喜欢的股票所供销售的数量较大，往往会**开一次销售会议**，多花点儿心思去推动这些股票在市场上流通（正常情况下会要求特别的销售手续费）。

| 条件 | 结果 |
| :--- | :--- |
| 某只场外股票通常有**两家或更多优良的场外交易商**进行买卖 | ✅ 通常会有充足的流通性，以满足大部分投资者的需求 |
| 供售数量较多时 | 交易商可能要求获得**特别的销售手续费**，以便在市场上交易大量的股票 |
| 手续费水平 | 只相当于销售价格的**一个相当低的比率** |

💡 由此，投资者希望卖出的股票**能在不使市场价格下跌的情况下转换成现金**。

#### 2.9 流通性横向对比

与在证券交易所上市的股票相比，场外交易的股票流动性如何？答案主要取决于**哪种股票**以及**在哪家证券交易所**上市。

| 股票所在场所 | 市场流通性评价 |
| :--- | :--- |
| **纽交所**中发行数量较多、交易较活跃的股票 | 即使在今天的环境下，依然存在一个足够大的**竞价市场**，几乎所有股票都能以较低手续费交易而不致压低市场价格 |
| **纽交所**中交投较清淡的股票 | 市场性依然不错，但当**巨量卖出委托单**出现并收取正常手续费时，有时**价格会大跌** |
| **小型交易所**上市的普通股 | ⚠️ 依我之见，市场性问题往往**相当严重** |
| **较好的场外交易股票** | 流动性往往**高于**美国证券交易所和各区域性证券交易所上市的大多数公司股票 |

**交易所的应对措施：**"特别卖出"机制

各大证券交易所已经认识到了这种状况，并采取了相应措施。如今，交易所要是认为上市股票的某笔卖出委托单**数量太大，不能以正常方式交易**时，可能会允许使用"**特别卖出**"机制：

1. 所有的会员都将**知道本笔卖出委托单的报价**；
2. 卖出这些证券可以**收取较高的手续费**。

> 💡 换句话说，如果卖出数量过大、经纪人没办法以**经纪人**的身份处理，便以足够高的手续费以**销售员**的身份来卖出这些股票。

#### 2.10 上市与未上市的界线正在模糊

如今所有这些举措都在一定时间内**拉近了上市和未上市股票市场之间的差距**，比如越来越多的买入是由销售员而不是由只接受交易指令的经纪人处理。

从市场流通的观点来看，这并不表示在纽交所里交易活跃的热门股票比那些较好的场外交易股票更有优势。我想那些与规模较小的证券交易所颇有渊源的人士一定十分不同意我的说法；不过我相信，如果做一次**立场公正的研究**，那么研究结果会证明我的看法是正确的。

这也解释了近年来的一个现象：许多中小规模的公司在经历成长之后，**不愿在小规模的交易所上市**。它们的路径是——

1. 先选择在**场外交易市场**上市；
2. 等公司规模成长到某个适合在"**大盘**"（也就是纽约证券交易所）上市时，再选择上市交易。

#### 2.11 💡 本节结论：两条原则，与上市股票并无不同

简而言之，关于场外交易证券，投资者应遵守的投资原则和对上市证券的投资原则**并没有太大的不同**：

| 顺序 | 原则 |
| :--- | :--- |
| **第一** | 十分肯定选到的是**正确的证券** |
| **第二** | 确定你找到了**能干而恪守职责的经纪人** |

如果投资者把这两件事都做好了，就**无需在乎自己所买的股票是在场外交易，还是在交易所里上市交易**。

### 三、不要因为你喜欢某公司年报的"语调"而去购买该公司的股票

#### 3.1 一种未被察觉的影响

投资者通常都没有仔细分析为什么他们会买进某只股票而不买进另一只。如果仔细分析，可能会惊讶地发现：自己的买入行为通常受到公司**致股东年报**中那些概括性评论的**用词和格式**的影响。

年报的语调是一把双面刃：

| 年报可能反映的东西 | 说明 |
| :--- | :--- |
| **管理层的经营哲学、策略或目标** | 其精确程度不亚于经过审计的财务报表对一段期间公司业绩的反映 |
| ⚠️ **公共关系部门的能力** | 即在大众心目中**营造公司形象**的能力 |

⚠️ 两个无法核实的细节：

- 我们无法判断那些**总裁署名**的文章是真的出于他本人之手，还是公共关系部门的员工代为执笔；
- 那些**具有诱惑力的照片和色彩绚丽的图表**，不一定能反映出管理团队的才能出众、同心协力和激情饱满。

#### 3.2 广告牌的比喻

让年报里的遣词造句和语调影响买入普通股的决策，就如同**因为见到广告牌上的广告很吸引人而去买某种商品**。或许这件商品买回家后，用起来的确像广告中说得那么好，但也有可能并非如此。

| 购买对象 | 凭广告冲动购买的后果 |
| :--- | :--- |
| **低价的商品** | 也许还算说得过去——买了之后才知道买得对不对，即便买错，**损失也不会很大** |
| **普通股** | ⚠️ 很少人可以有钱到**凭一时冲动**而购买股票的地步 |

我们最好记住：如今的公司年报通常都是**经过精心加工**的，以便赢得股东的青睐。所以不能只看外表，重要的是应该**深入探究事实**。其他的销售工具也都倾向于只展示出公司最好的一面，它们**很少平衡而完整地讨论公司经营中的真正问题和困难**，通常总是会过于乐观。

#### 3.3 反过来用行不行？一个重要的例外

那么，如果投资者不想让自己对年报语调的好感过度影响后续的投资行为，**反其道而行之**——让不利的内容影响他，行不行呢？

| 情形 | 判断 | 理由 |
| :--- | :--- | :--- |
| 一般情况下以负面语调作为卖出/回避依据 | ❌ 通常不可以 | 这就好像试图通过**外部的包装**来评价一个盒子里面东西的好坏 |
| ⚠️ **重要的例外** | ✅ 可以作为负面信号 | 当年报**未能针对投资者真正有意义的问题给出合适的信息**，以及**未曾适当揭露**投资者觉得很重要的资讯或问题时 |

💡 这么做的公司，通常**不能够为投资者提供投资成功所需要的必要背景资料**。

### 四、不要认为一家公司的市盈率很高，就必然表示未来的收益成长空间已经反映在了价格上

> 有一种常见的错误投资推理值得我们特别注意，因为它会**使投资者付出惨重的代价**。

#### 4.1 XYZ 公司的假设案例

假设有一家叫作 **XYZ** 的公司，多年来一直十分符合前文所述的**十五个原则**：

| 项目 | 状况 |
| :--- | :--- |
| **历史业绩** | **30 年**来销售额和利润不断增长 |
| **新产品** | 一直都在开发多种多样的新产品，强烈预示着未来也能获得这种成长速度 |
| **市场声誉** | 金融界人士**普遍称赞**这家公司的优异表现 |
| **估值水平** | 股价一直是当期收益的 **20～30 倍**，大约是道琼斯 30 种工业股票价格指数平均市盈率的 **2 倍** |
| **最新指引** | 管理层刚刚公布预测：收益将在**未来 5 年后增长为现在的 2 倍**；从目前已有的证据来看，这个预测看上去是**可信的** |

#### 4.2 ⚠️ 那个流行却错误的推论

得出错误结论的投资者数量非常之多，简直多得令人咋舌。他们的推理链条是：

1. XYZ 公司的市盈率是一般股票的 **2 倍**；
2. 而 XYZ 公司的收益需要 **5 年**时间才会翻倍；
3. 所以 XYZ 公司目前的股价**已经反映了未来的收益**；
4. 结论：他们非常确信**股价已经涨得过高了**。

#### 4.3 错误究竟在哪里

如果一只股票的价格已经反映了 5 年后的收益，那么股价很可能已经被高估，对此**没人能反驳**。但他们这种推理的错误之处在于——

> ⚠️ 他们**假设 5 年后 XYZ 公司的市盈率会和道琼斯指数的平均市盈率一样**。

而事实链条应该是这样的：

| 步骤 | 推理 |
| :--- | :--- |
| ① 历史事实 | 30 年来，这家公司在很多因素的共同作用下经营得非常出色，市盈率**一直是其他股票的 2 倍**，这个记录使那些对它充满信心的投资者获得了利益 |
| ② 若政策不变 | 5 年之后公司管理层会推出**另一组新产品**，然后接下来 10 年的收益成长情况，就会像如今的新产品那样提高公司的收益——也像其他产品在 5 年前、10 年前、15 年前或 20 年前所做的贡献那样 |
| ③ 由此追问 | 如果事实果真如此，为什么这只股票 **5 年后的市盈率不能仍是一般股票的 2 倍**，就像今天和从前那么多年一样？ |
| ④ 数量结果 | 如果所有股票的市盈率都保持在原来的水平，XYZ 公司 5 年后收益翻倍，也会使它 **5 年后的市场价格增长到现在的 2 倍** |
| ⑤ 结论 | 💡 从这个角度看，这只股票**目前的价格完全处在正常的市盈率水平上，根本不能说已经反映了未来的收益** |

这是很明显的，难道不是吗？但是，回头看看你身边的人，有多少貌似精明老练的投资者在运用市盈率来衡量公司未来的成长时**把自己搞得晕头转向**，不知所以。

#### 4.4 更难的变体：ABC 公司与"背景发生变化"

如果赶上**公司的背景发生变化**，情况则更为严重。现在我们抛开 XYZ 公司来谈另一家叫 **ABC** 的公司。

| 对比项 | XYZ 公司 | ABC 公司 |
| :--- | :--- | :--- |
| **基本面** | 优秀 | 各方面情况**基本完全相同** |
| **公司年龄** | 30 年记录 | **要年轻得多** |
| **被认可的时间** | 长期被称赞 | 仅**过去 2 年**金融界人士才认为其基本面非常出色 |
| **当前市盈率** | 道指均值的 2 倍 | 同样是道指均值的 **2 倍** |

⚠️ 许多投资者似乎不太可能意识到：一只股票**过去的市盈率并不高、而现在的市盈率却很高**，这反映出的可能是它的**内在价值**，并且合理地反映了公司未来进一步成长的可能。

#### 4.5 判定标准：增长源是"一次性"还是"可持续"

关于这个问题，最重要的是**彻底了解一家公司的内在特质**，特别是要参考**几年后**可能发生的情况。

| 公司类型 | 内在特质 | 未来市盈率走向 |
| :--- | :--- | :--- |
| **一次性增长型** | 收益的急剧增长只出现了一次，从内在特质上说目前的收益增长**已经完全得到释放**，尚未开发出新的增长来源 | ⚠️ 目前的高速增长结束之后，**股价将发生回撤**，市盈率会下降到与其他普通股一样的水平 |
| **持续再造型** | **谨慎而持续地开发新的获利来源**，而且公司所处行业未来有望保持和现在相近似的成长动力 | ✅ 公司 **5～10 年后的市盈率肯定会远高于一般股票**，就像如今的情形一样 |

> 💡 这类股票的市盈率所反映出的未来收益，往往**远高于大多数投资者所期待的水平**。这也是为什么有些股票乍看之下价格貌似过高，但仔细分析之后，却会发现**它们价格非常便宜**。

### 五、不要计较蝇头小利

> 之前阐述各类问题时用的都是虚拟的例子，这次要用一个**真实的例子**。

#### 5.1 一个 50 美元换来的教训

25 年前，有位在很多方面都展现出了高超投资能力的绅士，他想买入 **100 股**纽约证券交易所上市的某种股票。

| 环节 | 事实 |
| :--- | :--- |
| **决定买入当日收盘** | 买盘 **35 美元**、卖盘 **35.50 美元** |
| **第二天** | 依然如此，但这位绅士**不愿以 35.50 美元买入** |
| **他的动作** | 为了节省 **50 美元**，把买入委托单价格定在 **35 美元**，并且**拒绝提高买价** |
| **此后走势** | ⚠️ 这只股票**此后从未跌到过 35 美元** |
| **25 年后的今天** | 成长前景似乎依然一片大好；如果把**股利和股票拆分**都算入在内，目前的股价已经**超过 500 美元** |

**换算一下这笔账：**

| 项目 | 金额 |
| :--- | :--- |
| 意图节省 | **50 美元** |
| 实际少赚 | **46 500 美元** |
| 倍数关系 | 46 500 ÷ 50 = **930 倍** |

也就是说，这位投资者需要**成功省下 50 美元 930 次**，才能弥补这一次的损失。（不过这位投资者仍然赚得了 46 500 美元，因为他**曾以更低的价格买入过**这家公司的股票。）

> ⚠️ 很明显，在投资上采取这种对自己极为不利的行为是**非常愚蠢的**。

💡 这个例子绝对不是极端情况。我**故意选了一只多年来涨势落后于大盘的股票**，而没有选领先于大盘的股票。如果投资者选择了纽约证券交易所上市的**前 50 只成长股**里面的任意一只，那么为了节省下 50 美元而错失了每股价值 **3500 美元**的股票，损失将比 46 500 美元大得多。

#### 5.2 小额投资者：规则非常简单

对于只想购买**几百股**股票的小额投资者而言：

1. 如果想买的股票看起来是个**正确的选择**，且目前价位处于**很吸引人的水平**，那么**以市价买入即可**；
2. 多花 **1/8、1/4 或 1/2 美元**，与没买到这只股票所错失的利润相比，根本就是微不足道的。

> 💡 一条反向的自检：如果一只股票**没有这种长期增长的潜力**，我认为投资者**一开始就不应该考虑买入它**。

#### 5.3 大额投资者：问题没有这么简单

至于想要买入**数千股**的大额投资者，问题则复杂得多。除了极少数的股票，大部分股票的**供应量是有限的**，即使按当时的市价只买入想买数量的一半，也很可能会引发**市价的大幅上涨**。

⚠️ 价格的突然上涨又反过来产生了两种**使买入更加困难**的连锁反应：

| 连锁反应 | 机制 |
| :--- | :--- |
| **引来竞争买盘** | 价格大幅上涨可能促使别人也对这只股票感兴趣，从而**争相买进** |
| **抽走潜在卖盘** | 可能让一些本来计划卖出的投资者**转向继续持有**，希望涨势持续下去 |

**正确的委托方式：三条授权**

他应该去找自己的股票经纪人或证券交易商，**准确告诉他们自己到底想买入多少数量**的股票，并给出以下授权：

| # | 授权内容 | 目的 |
| :--- | :--- | :--- |
| ① | 尽可能**多地买入**股票 | 完成目标数量 |
| ② | 授权经纪人**忽略较小数量的卖盘供给** | 以免买入之后引来很多买家争相抬高价格买入 |
| ③ | **最重要**：完全允许经纪人以**高于最近价格的某个价位**买进 | 避免因僵守限价而彻底错失 |

至于具体高出多少，就要**和经纪人或证券交易商协商**，协商时需要考虑：

- 想要买入的**数量**；
- 那只股票**通常的成交量**；
- **许多买家是否急着买进**股票；
- 以及其他任何有关的影响因素。

#### 5.4 💡 如果你不信任你的经纪人

投资者可能会认为，自己没有一位具有良好判断力和辨别能力的经纪人或证券交易商可以托付此等大事。如果真是这样，他应该**马上去找一位值得信赖的经纪人或证券交易商**——毕竟，处理这种事**正是经纪人或证券交易商的专业所在**。

### 六、本章小结

#### 6.1 五条禁令速查

| # | 禁令 | 核心理由 | 正确做法 |
| :--- | :--- | :--- | :--- |
| **1** | 不要买创业阶段公司的股票 | 运营不足两三年、盈利不足一年的公司**无从观察**，只能靠猜；创业团队常存在结构性能力缺口，且**说不通、也补不上** | 把创业期投资留给能**补位管理人才**的专业机构；在老公司中寻找机会 |
| **2** | 不要忽视场外市场的好股票 | 场外报价是**买价/卖价**而非成交价，价差覆盖销售员佣金；但较好的场外股票流动性**优于**美交所和区域性交易所多数股票 | 选对证券 + 选对**能干而恪守职责**的经纪人，之后不必在意交易场所 |
| **3** | 不要因年报"语调"而买入 | 语调可能反映管理层哲学，也可能只反映**公共关系部门的能力**；年报经过精心加工，很少完整讨论真正的困难 | 深入探究事实；⚠️ 唯一可作负面信号的例外是年报**回避了真正重要的问题** |
| **4** | 不要认为高市盈率必然已反映未来成长 | 错误假设在于"**几年后市盈率会回落到市场平均水平**"；30 年保持 2 倍市盈率的公司，若政策不变，5 年后没有理由不是 2 倍 | 判定增长源是**一次性释放**还是**持续再造**；后者 5～10 年后市盈率仍将远高于一般股票 |
| **5** | 不要计较蝇头小利 | 为省 50 美元而错失一只**落后于大盘**的股票，少赚 46 500 美元，相当于要省对 **930 次**才能补回 | 小额投资者以**市价买入**；大额投资者向经纪人给出**数量、忽略零星卖盘、允许溢价**三项授权 |

#### 6.2 贯穿五条禁令的两条主线

| 主线 | 体现 |
| :--- | :--- |
| **可观察性优先于故事性** | 禁令 1、3 都在提醒：宁要可被检验的经营事实，不要蓝图、文案与包装 |
| **不要为省小钱牺牲大机会** | 禁令 2、4、5 都在提醒：交易场所的价差、貌似偏高的市盈率、几分之一美元的报价差，与真正优秀企业的长期复利相比都微不足道 |

> 💡 **一句话概括本章思想**：五个"不要"守住的是同一件事——把判断建立在**可核实的企业质地**上，而不要让直觉、文案与几十美元的精打细算，把你从最好的长期机会里赶出去。
