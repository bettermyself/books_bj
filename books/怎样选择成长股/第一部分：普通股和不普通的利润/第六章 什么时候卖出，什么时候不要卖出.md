## **第六章 什么时候卖出，什么时候不要卖出**

> **核心命题**：如果当初买进普通股时各项选择工作都做得很对，那么**卖出的时间几乎永远不会到来**。

---

### 一、先划清讨论的边界

投资者决定卖出普通股时，总是有很多听上去很合理的理由——他可能是要盖一栋新房子，或是给自己准备创业的儿子筹备资金。从追求幸福生活的角度来说，出于类似理由而卖出普通股都是合情合理的。

但在这些情况下卖出持仓，都是出于**个人的动机**，而不是出于**金融操作方面的考虑**，这就超出了本书的讨论范畴。

| 卖出动因 | 性质 | 是否属本章讨论范围 |
| :--- | :--- | :--- |
| 盖新房子、为子女创业筹资等 | 个人生活需要 | ❌ 不讨论 |
| 运用可用的投资资金取得最大的利益 | 金融操作考虑 | ✅ 本章唯一目标 |

---

### 二、卖出的三个理由——而且仅有三个

作者相信，**有三个理由，而且仅有三个理由**，足以让投资者卖出根据前文所阐述过的投资原则所选出并买入的普通股。

| 序号 | 卖出理由 | 触发条件 | 处理的关键 |
| :--- | :--- | :--- | :--- |
| **理由一** | 最初的买入行为本身就是一个错误 | 当下盈利的情况越来越清楚地表明，所买入公司的实际情况并不像原先所想象的那么优秀 | 主要靠**对情绪的控制**，也取决于投资者能不能坦诚地面对自己 |
| **理由二** | 公司基本面随时间推移而发生变化 | 与第三章所述"十五个原则"的契合度不再那么高 | **时刻提高警惕**，密切留意持股公司相关情况的发展 |
| **理由三** | 发现了明显更好的投资机会 | 有充分把握断定另一家公司的发展前景远优于现有持仓 | 极少出现，**必须非常有把握**才能执行 |

---

### 三、理由一：当初的买入就是一个错误

#### 3.1 普通股投资的两个重要特点

| 特点 | 含义 |
| :--- | :--- |
| **回报特点** | 如果处理得法，它能带来**丰厚的利润** |
| **门槛特点** | 若想把普通股投资做好，就必须有**高超的技能、知识以及判断力** |

由于获得这些如梦似幻的利润的过程极为复杂，所以**买入股票的过程中难免会犯下这样或那样的错误**。好在从那些真正优秀的普通股中所获得的利润，应该足够弥补正常犯错所造成的损失，弥补损失之后仍然应该有很大的涨幅。

#### 3.2 及早认识错误，能带来三重收益

1. **损失幅度更小** — 远低于买入错误的股票后长期持股所造成的损失。
2. **资金被盘活** — 将被困在不利状况中的资金解放出来。
3. **利润更多** — 把盘活的资金用于购买其他精心挑选出来的好股票。
#### 3.3 ⚠️ 最大的障碍：自尊心

有个很复杂的因素，使得对投资失误的处理更加困难——这种困难源于**我们每个人的自尊心，没有人喜欢承认自己犯下的错误**。

| 卖出结果 | 投资者的真实心理 | 判断是否理性 |
| :--- | :--- | :--- |
| 买入是错的，但卖出时获得**一点点利润** | 不会觉得自己当初的买入是错的 | ❌ 自我安慰 |
| 卖出时有**小的损失** | 对整个操作过程相当不满意 | ❌ 情绪化 |

这种反应其实是人之常情，但在操作中却可能十分危险，因为它会让我们在整个投资过程中**任性妄为**。

> ⚠️ 投资者死守一只本来不想再持有的股票，只因为希望有一天能够"**至少回本**"，却因此损失了更多的资金——这种赔钱的理由，在投资中可能多于其他任何一种赔钱的理由。

如果在认识到发生错误时能够果断处理，认赔卖出，腾出资金转而投资于更合适的股票并获得相应利润，这么算下来，**失去机会的成本更高**。

#### 3.4 不愿承担小损失，虽是人性却不合逻辑

如果投资于普通股的真正目标是在几年内获得**数倍于本金**的利润，那么 20% 的损失和 5% 的利润之间的差距，就显得不那么重要了。

| 对象 | 是否真正重要 |
| :--- | :--- |
| 会不会偶尔发生损失 | 并不重要 |
| 投资者是不是**经常没能赚得可观的利润** | **真正重要** — 若真是这样，投资者或他的投资顾问的理财能力一定会遭到质疑 |

#### 3.5 对待亏损的正确态度

- ❌ 不该因为亏损而**强烈地自责或出现情绪失控**；
- ❌ 也不应该**完全漠然视之**；
- ✅ 投资中若发生亏损就应该**仔细审视**，以便从每次的错误中获得教训。

> 💡 如果能透彻地了解在买入普通股时出现判断失误的成因，投资者就不会在下一次的投资行为中因为同样的原因而再次犯错。

### 四、理由二：公司基本面已经变化

如果一家公司的基本面情况随着时间的推移而发生变化，与第三章所述的十五个原则的契合度不再那么高，这时就应该卖出此公司的股票。这也是投资者**必须时刻提高警惕**的原因，也说明为什么持有一家公司的股票时，密切留意该公司相关情况的发展是多么的重要。

#### 4.1 走下坡路的两种原因

一家公司的经营状况走下坡路往往出于两种原因：

| 原因 | 具体表现 | 处理速度 |
| :--- | :--- | :--- |
| **A. 管理层的松懈退化** | 经营的成功冲昏了一个或多个重要管理人员的头脑，**沾沾自喜和懒惰松懈**取代了之前的干劲和创造力；或新的高级管理层达不到前任所设置的绩效标准——既没有继续奉行那些曾经让公司经营得十分出色的政策，也没有能力提出新政策让经营持续向好 | ⚠️ **马上卖出**，不管股市总体情况看起来有多好，或资本收益税有多高 |
| **B. 产品市场不再扩大** | 公司经历多年惊人成长后到达**瓶颈阶段**，继续成长的可能性几近枯竭，此后只能保持和行业内同类公司齐平的发展势头，增长率只能和全国的经济增长率保持同步 | 卖出行动**可以稍微放缓**，一部分持仓可以保留直到找到更合适的投资对象再行卖出 |

#### 4.2 为什么"产品市场枯竭"未必是管理层的错

这种变化可能**不是源于管理层退化**：

- 很多公司的管理层非常擅长在**行业内**开发相关或近似的产品，以便充分利用所在行业的发展机会；
- 但他们通常**不会进入一个不相干的行业**，因为他们在那里根本没有任何独特优势可言。

因此，如果一家公司在一个新型的成长性行业中连续多年有非常成功的表现，但在时过境迁之下市场成长潜力几近枯竭，其股票无法再达到十五个原则的要求时，就应该果断卖出。

> ⚠️ 无论如何都**不能再将这家公司视为合适的投资标的**。至于资本收益税，不管税金有多高，都不能让它作为阻止你调仓换股的理由——因为换股买入新股票之后，新股票未来几年的成长情况也许会跟被换掉的股票从前的表现一样出色。

#### 4.3 💡 一个实用的检测方法

谈及公司未来会不会出现预期中的进一步增长、是否不再适合投资时，可以用下面这个方法自问：

> **在下一个经济周期的顶部到来之时**（不管此前会发生什么事），这家公司的每股利润和目前的水平相比，其增幅**是不是至少和"上一个已知的经济周期高峰期 → 目前水平"的增幅一样大**？

| 计算口径 | 说明 |
| :--- | :--- |
| ✅ 需要算入 | 股利因素、股票拆分 |
| ❌ 不必考虑 | 用于筹措新增资本的发行新股 |

| 答案 | 应采取的行动 |
| :--- | :--- |
| **肯定** | 也许该股票就应**继续持有** |
| **否定** | 或许就应该**卖出** |

### 五、理由三：为了更好的机会而换股

#### 5.1 这个理由为何存在

如果当初买入股票时是按照正确的原则买入的，因为第三个理由而卖出的情况**会极少出现**，而且只有在投资者非常有把握的情况下才能执行。

这个理由之所以存在，是因为**好的投资机会往往是千载难逢的**。从买卖时机的角度，这种机会很少在刚好获得可供投资的资金时可以找到。

典型情形是：投资者拥有一笔可供长期投资的资金，找到一只值得投资的股票，于是把部分或全部资金投入这家他觉得成长潜力非常广阔、管理非常优秀的公司。但和之后发现的一些似乎更有吸引力的公司相比，这家公司的**平均年度成长率相形见绌**，在其他一些重要因素上也缺乏吸引力。

#### 5.2 换股的判断标准

如果**证据十分明显**，并且投资者对自己的判断有**十足的把握**，则卖出原有持仓、买入发展前景可能更好的股票，所带来的收益即使扣除资本利得税之后，可能仍然非常可观。

| 公司类型 | 长期平均年增长率 | 对持股人的意义 |
| :--- | :--- | :--- |
| 现有持仓 | 12% | 财富增长虽然也是很好 |
| 更优标的 | **20%** | 投资者应该**不怕麻烦**，也不必为资本利得税的问题而忧心，坚决执行换股操作 |

#### 5.3 ⚠️ 但对"随时准备换股"要慎之又慎

作者对"投资者随时准备卖出持仓的某只普通股、希望把资金投向更好的股票"这一做法**持谨慎态度**：

- 在决策过程中往往会**误判某些重要因素**，这种风险时刻存在。一旦发生误判，换股操作很可能达不到预期效果；
- 相反，警觉的投资者如果**持续持有某只股票一段时间**，一般就会熟悉它的优势与劣势。

> 💡 为了将资金转向更好的股票而卖出一只**令人相当满意**的股票，必须谨慎而准确地评估整个形势中的**所有**影响因素。

### 六、一个少有人懂的基本原则

说到这里，眼光独到的读者可能已经看出一个基本的投资原则——这个原则似乎也只有**极少数成功的投资者**才能够了解：

> **某只股票如果是精挑细选出来的，而且经历过时间的考验，则很少能够找到卖出它的理由。**

可是金融界总是会不断提出推荐和评论，给出各种卖出优秀普通股的理由。这些理由真的正确吗？下面逐一检验三种最常见的错误理由。

| 编号 | 常见的卖出理由 | 结论 |
| :--- | :--- | :--- |
| 错误一 | 担心整体股市即将出现某种幅度的下跌（熊市） | ❌ 不成立 |
| 错误二 | 这只优秀股票的**价格涨幅过大、股价过高** | ❌ 不成立 |
| 错误三 | 股价已有很大涨幅，上涨潜力"已被释放"，应换入还没上涨的股票 | ❌ **最荒谬** |

---

### 七、错误一：因为害怕熊市而卖出

#### 7.1 与上一章同样的逻辑

前一章已说过：如果由于担心大盘出现整体性下跌而推迟购买有吸引力的股票，那么从长期来看这种做法将会**损失惨重**。原因在于投资者的注意力错配：

| 影响走势的力量 | 判断依据 | 投资者的实际反应 |
| :--- | :--- | :--- |
| **较强因素** | 依靠自己的知识**能做出明确判断** | 被忽视 |
| **较弱因素** | 大致上只能依赖于**猜测** | 反而担心 |

买入值得投资的普通股时，不应该因为担心熊市的来临而受到过多影响。如果这个论点是正确的，那么**不能因为害怕熊市而卖出优秀的股票就更加有道理**——前一章提到的所有论点在此同样适用。

此外，考虑到**资本利得税**的因素，投资者正确卖出所持优秀股票的概率则进一步降低：优秀的股票在持有若干年后将会产生很大的利润，资本利得税将使出售持股的成本显得更为沉重。

#### 7.2 ⚠️ 代价更昂贵的理由：你不知道何时买回

如果最初所选的股票的确很好，那么出现下一次牛市的时候，这只股票一定会创出**新的股价高点，且远高于迄今为止的最高点**。

那么投资者如何知道什么时候应该买回股票呢？理论上应该在下跌出现之后买回——但这种说法的前提是**投资者知道跌势在什么时候结束**。

作者的实际观察：

| 情形 | 观察结果 |
| :--- | :--- |
| 因担心熊市而抛售 | 见过许多投资者抛售了**将在未来几年有巨大涨幅**的股票，结果熊市往往没有预期而至，整个大盘却一路高歌猛进 |
| 熊市真的来临 | 能够在**当初卖价以下**买回当初卖出股票的投资者，**不足 1/10** |

未能买回的两种典型原因：

1. 要么是在**苦苦等待股价跌得更多**；
2. 要么是股价的确继续下跌，但他们却**担心会发生一些别的事情**阻碍股价回升，因此一直没有将股票买回。

### 八、错误二：因为"股价过高"而卖出

这种思维方式使得本性淳朴但投资经验尚浅的投资者错过未来庞大利润：**一只优秀的股票价格涨幅过大，因此应该将其卖出**。还有什么比这种说法更有道理吗？如果一只股票的价格过高，为什么要坚持持股而不是将其卖出呢？

在草率地得出结论前，我们要深入探讨这种说法的正确性：**价格到底多高才算是过高？**

#### 8.1 "过高"的两种含义

任何真正优秀的股票，其价格与市盈率都会稍高于那些获利能力稳定但尚未出现获利能力提升趋势的股票。毕竟，**要想参与分享企业持续成长所带来的利益，显然需要付出得更多一些**。

我们说某只股票"价格过高"时，指的可能是：

1. 它的股价相对于其**预期获利能力**，高于我们预期其应有的水平；
2. 它的**市盈率**高于发展潜力与其类似的同行业公司。

#### 8.2 ⚠️ 问题在于：这种精确度根本做不到

这些说法都在试图以**超出可能范围的精确度**来衡量一些东西，实际上我们不能做到。

| 主体 | 能做到的判断 | 做不到的判断 |
| :--- | :--- | :--- |
| **投资者** | 只能用定性描述：**"大致相同""略有上涨""上涨很多""大幅上涨"** | 不能准确确定一家公司两年后的每股收益是多少 |
| **公司高级管理人员** | 判断几年后每股利润会不会大幅上升，能做的**和普通投资者基本类似** | 具体增加多少、到底什么时候出现这种增幅，通常包含了**很多的猜测** |

#### 8.3 一个假设：35 倍市盈率的贵，重要吗

假设目前某只股票的市盈率不是通常的 **25 倍**，而是 **35 倍**：

- 该公司也许在近期推出新产品，但金融界人士还无法知晓这种新产品真正的市场价值；
- 或许公司并没有这样的新产品，但**公司的成长性很高，10 年之后规模将达到当前规模的 4 倍**。

> 💡 那么"目前的股价是否被高估了 **35%**"，还有那么重要吗？真正需要注意的是——**不要轻易卖出未来价值将出现大幅提高的股票**。

#### 8.4 老朋友：资本利得税再次登场

成长型股票之所以被人认为价格过高而建议卖出，部分原因就是出售时持股人必须按规定缴纳金额很大的资本利得税。因此如果卖出股票，代价是**双重的**：

1. 失去这家公司的股票，从而无法在未来的几年继续分享其较高的成长；
2. 还必须缴纳**很大一笔税赋**。

| 提问 | 作者的回答 |
| :--- | :--- |
| 如果坚定相信这只股票的价格可能在一定时期内还能继续上涨，继续持有是不是更安全、更省钱？ | ✅ 是。我们在所投资的那只股票上可以赚得更可观的利润 |
| 如果股价在一段时间内下跌了 35%，这算是什么严重的事情吗？ | 并不算 |
| 如果能保持长久盈利的地位，暂时地失去小部分利润又能怎么样呢？ | 无关大局 |

### 九、错误三："涨得太多了，该换没涨的" —— 最荒谬的论点

投资者有时还持有另一种论点，使他们错失原本可以赚到的那部分利润，这个论点也是**所有错误看法中最荒谬的**：

> 自己所持仓的股票已经有了很大的涨幅，因此**仅仅因为股价有一定的涨幅**，就断定此股票大部分的上涨潜力已经被释放出来了，所以应该将其卖出，并将资金转向其他还没上涨的股票。

作者认为投资者只应该买入优秀的公司，而**真正优秀公司的股票根本不会以这种方式运作**。

#### 9.1 同学合约的假设实验

假定今天是你大学毕业的日子（如果你没上大学，就把今天当作高中毕业的那一天——是大学还是高中毕业并不重要）。

**交易条款：**

| 项目 | 内容 |
| :--- | :--- |
| **对方** | 你班上的所有男同学，他们所有人都很急需用钱 |
| **你付出** | 给他们每人一笔资金，金额相当于**他们毕业开始工作后一年之内总收入的 10 倍** |
| **你得到** | 他们今后**每年收入的 1/4** |
| **你的约束** | 虽然你认为这种交易方式非常好，但你拥有的资金**只能够与三位同学**做此交易 |

**此时你的推理方式，与投资者运用有效的投资原则选择股票的方式极为类似：**

- 你会马上开始分析这些同学，**不是**看他们的社交能力有多强、或在哪些方面富于才华，**只看他们日后能够赚多少钱**；
- 如果班上有很多同学，可能其中大多数人**一开始就会被排除**——因为你对他们了解程度并不够，没办法判断他们的赚钱能力到底有多强。

> 💡 从这一点来看，这又和**明智的普通股购买**非常类似。

#### 9.2 十年之后

最终你选出了三位同学进行交易，因为你觉得他们几个人在未来会赚到最多的钱。10 年过去了，其中一位表现非常出色：

- 他在一家大公司工作，不断地得到晋升；
- 公司内部人员已经传出消息，说总裁非常欣赏他，并准备让他在 **10 年之后接任总裁**的位置；
- 到那时候，他将拥有高额的薪水、股票期权和退休金。

**现在请那些总是建议投资者卖出"涨得过高"的好股票获利了结的股市评论家们想一想：**

| 摆在你面前的选择 | 你的反应 |
| :--- | :--- |
| 有人愿意给你相当于**原始投资金额 6 倍**的资金，买你和这位同学的合约 | 你会怎么做？ |
| 有人建议你卖出这份合约，转而去和另一位**年收入仍跟 10 年前刚毕业时基本相同**的同学签订合约 | ⚠️ 你一定会觉得提出这种建议的人是**脑子有问题** |

有人可能觉得"已经取得成功的同学收入已经达到顶峰，而财务上不成功的同学未来的成长空间还很大"——这样的说法显得**相当愚蠢**。

> 💡 如果你对自己所持的股票了解得非常清楚，一定会认为时常听到的那些**卖出好股票的建议也是一样愚蠢**。

#### 9.3 同学与普通股的唯一差别，反而强化了结论

你可能认为这些论点听起来也不无道理，毕竟同学跟普通股是有所区别的。两者之间的确有着一个很大的不同点：

| 对象 | 时间限制 |
| :--- | :--- |
| **同学** | 生命是有限的，最终会离开人世 |
| **普通股** | **没有类似的时间限制** |

这个不同点**更加强化**了下面这一论点：

> ⚠️ **绝对不要因为股价涨幅已经很大、而且在短期内股价过高，就卖出优秀的普通股。**

原因在于：发行普通股的公司能够**全面地甄选优秀的管理人才**，并且在公司的策略、运用方法和技术方面训练这些人才，使得这家公司能够**基业长青、传承数代**。

| 实证案例 | 说明 |
| :--- | :--- |
| **杜邦公司** | 已经传承了**两个世纪** |
| **陶氏化学公司** | 在其才华横溢的创始人**去世多年后**依然表现良好 |

在这个人类欲望无穷无尽、市场潜力惊人的时代，**企业的成长是无止境的**，而不像人类一样受到寿命的限制。

### 十、本章小结

**卖出的完整决策地图：**

| 情形 | 该不该卖 |
| :--- | :--- |
| 买入本身就是错误，公司实况远不如预期 | ✅ 果断认赔卖出，盘活资金 |
| 管理层松懈退化 | ✅ 马上卖出，不问大盘与税负 |
| 产品市场成长潜力枯竭，不再符合十五个原则 | ✅ 卖出，节奏可稍缓 |
| 有把握发现远优于现有持仓的标的（如 12% vs 20%） | ✅ 可换股，但需慎之又慎 |
| 担心大盘要跌、熊市要来 | ❌ 不卖 |
| 觉得市盈率太高、股价"过高" | ❌ 不卖 |
| 涨得太多了，想换成"还没涨的" | ❌ 绝对不卖 |

> 💡 **一句话概括本章思想**：如果当初买进普通股时各项选择工作都做得很对，那么**卖出的时间几乎永远不会到来**。
