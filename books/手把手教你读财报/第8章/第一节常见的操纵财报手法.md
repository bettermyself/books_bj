# 第一节　常见的操纵财报手法

> 上市公司操纵财务报表的行为，绝大部分集中在**利润表**（主要为美化利润表），也有小部分集中在**现金流量表**。

从会计恒等式出发：

$$资产 = 负债 + 所有者权益 + 收入 - 费用$$

- **操纵利润**：本质上无非是操纵收入和费用，并由此引发资产与负债的连锁变动。
- **美化现金流量表**：主要因为资本市场更在意经营活动现金流的变化。

本节从**操纵收入**、**操纵费用**和**操纵现金流**三个方面，梳理主要的操纵财报手法。

### 手法总览

| 操纵方向 | 主要目的 | 核心手法 |
| :--- | :--- | :--- |
| **操纵收入** | 多数为虚增收入，少数为虚减收入 | 虚构收入、借助一次性行为夸大收入、提前确认收入 |
| **操纵费用** | 多数为虚减费用，少数为虚增费用 | 将本期费用推至未来、掩盖成本或亏损、"洗大澡" |
| **操纵现金流** | 美化经营活动现金流 | 增加经营活动现金流入、减少经营活动现金流出、一次性行为美化 |

---

## 一、操纵收入

收入是利润的源头，因此操纵收入是上市公司操纵利润的**主要表现形式**。对上市公司而言，操纵收入主要表现为**虚增收入**，少数表现为**虚减收入**。主要操作手法有三类：虚构收入、借助一次性行为夸大收入、提前确认收入。

#### 1.1　虚构收入

在这种情况下，**交易是虚构的，是没有必要发生的**。虚构收入是 A 股市场最主要、最常见的造假手法，比较常见的具体形式有：

- 虚假交易
- 虚增成交金额
- 将非营利性交易确认为收入
- 显失公平的关联交易

> 💡 **手把手教你读财报——真实案例**

| 案例主体 | 主要手法 | 操作过程 |
| :--- | :--- | :--- |
| **LDD** | 虚假交易 | 上市前后陆续以注册和购买方式成立 35 家秘密控制的空壳公司协助虚增收入。以空壳公司 M 为例：以 100 元/亩购买山民 1.22 万亩林地，总价 100 余万元；再以 9000 元/亩卖给 LDD，总价约 1.1 亿元，虚增资产约 1.1 亿元。M 公司将收到的 1.1 亿元分转给其他公司，由其向 LDD 完成采购，形成 LDD 的营业收入。 |
| **XDD**（其一） | 虚增成交金额 | 半真半假，将虚假收入化整为零，分散到大量真实客户名下，提升单价并增加数量，但每位客户虚增金额不大。而后通过在建工程预付款、原材料采购款及补贴款等名义，将款项返回给客户。 |
| **XDD**（其二） | 将非营利性交易确认为收入 | 将当地政府给上市公司的部分政策补助，通过虚假合同化装成销售收入流入公司。 |
| **GHNY** | 显失公平的关联交易 | 包销控股股东旗下另一家房产公司的房产作为利润主要来源。实际不需干任何事，仅在销售房产时象征性地从 GHNY 走账一次，便产生商品房销售金额的 25% 作为毛利。 |

#### 1.2　借助一次性行为夸大收入

常见形式包括：将出售业务部门或资产所得转化为营业收入、将收购支出转化为营业收入、将亏损打包出售掩盖亏损、进行互换贸易夸大收入等。

**（1）将出售业务部门或资产所得转化为营业收入**

常见手法是将业务部门或资产**低价出售**，然后由买家将成交价与公允价格之间的差额，用于两种途径之一：

- 购买上市公司产品或服务，**增加**上市公司当期营业收入；
- 或反过来，低价向上市公司提供产品或服务，**降低**上市公司当期或后期营业成本。

**（2）将上市公司的收购支出转化为营业收入**

上述手法的反向操作。上市公司**高价收购或承诺高价收购**其他公司的业务部门或资产，卖家将超过公允价格的部分：

- 用来采购上市公司产品或服务，**增加**上市公司当期营业收入；
- 或低价向上市公司提供商品或服务，**降低**上市公司当期或后期营业成本。

**（3）将经营亏损打包出售掩盖亏损**

通过内部资源安排，将上市公司日常经营亏损或坏账损失，集中在某个子公司或业务部门，在适当时候高价出售以掩盖亏损、美化当年利润表。

⚠️ **注意**：买家并非傻子，其购买亏损子公司付出的高价，上市公司会通过其他途径予以弥补，例如借款、担保、项目合作、并购费用、咨询费用等，或者干脆出资收购买家的其他项目。

**（4）互换贸易**

上市公司高价出售商品或服务的同时，高价采购对方的商品或服务。最理想的状态是对方的商品或服务能与上市公司的投资项目挂钩——既产生营业收入，又产生投资现金流出，同时还给对方公司创造了营业收入。

> 💡 除商品或服务互换外，还可能有**非实物的权利互换**。例如影视版权互换：不同视频类公司相互让渡影视作品的使用权，但同时自身仍保留相应版权的所有权和使用权，将这种互换分别确认为销售和购买，达到增加营业收入的效果。

#### 1.3　提前确认收入

提前确认收入（少数情况下也有推后确认收入）是很多上市公司喜欢用的利润调节手法。

⚠️ **注意**：这不能完全算造假，而是介于合法与非法之间的一种**灰色状态**。

通常表现为以下三种情形：

**（1）确认尚未开始提供产品或服务的收入**

- 以优惠价格要求客户一次性购买多年的服务，然后将总金额确认在当年营业收入里；
- 年底前签订合同收款，在合同约定义务尚未开始履行的情况下，将合同款项确认为当年收入；
- 房地产上市公司以工程完工验收、收到房款确认收入（一般应是**交房**确认收入）。

**（2）买家没有明确承担付款义务时确认收入**

- 向客户发出错误的货；
- 向没有要求发货的客户发货；
- 答应客户可无条件退货的情况下，在退货期限内确认收入；
- 向根本没有付款能力的客户在大幅延长信用期的情况下发货。

**（3）确认超过完工百分比对应的收入**

- 对使用完工百分比法的公司（如建筑公司、装饰公司、系统集成公司、大型设备制造公司等），确认超过实际完工的收入很容易；
- 对销售商品并捆绑服务的公司（如自行研制的软硬件销售，约定提供免费维护或升级服务），通过将较大比例销售收入分配给销售、较少比例分配给后期维护，可大幅增加当期营业收入。

## 二、操纵费用

$$利润 = 收入 - 费用$$

通过调整当期费用的多寡来操纵利润表，也是上市公司的常见手法。由于费用调整受限较多、可调整幅度有限，使用起来不如操纵收入那么自由，因此对财报的调节显得相对"温柔"。

上市公司的费用调节主要表现为**虚减费用**，较少表现为**虚增费用**。

| 调节方向 | 俗称 | 常用手法 |
| :--- | :--- | :--- |
| **虚减费用** | —— | 将本期费用推迟至未来、掩盖成本或亏损 |
| **虚增费用** | "洗大澡" | 注销资产或存货、大额计提减值损失、将经常性费用归入一次性费用计提 |

#### 2.1　将本期费用推至未来

主要手法有：

- 延长折旧摊销年限；
- 漠视已经形成损失的坏账；
- 不适当地使用费用资本化手段；
- 不对受损资产或过时存货提取减值准备；
- 将费用暂时挂在应收账款或预付账款科目；
- 推迟在建工程转为固定资产，甚至将日常费用计入在建工程；
- 通过临时资金冲抵，将长时间坏账化装成刚形成的应收款，从而降低坏账计提比例。

> 💡 这些手法简单粗暴，在资产负债表章节基本都谈过，此处不再赘述。

#### 2.2　掩盖成本或亏损

掩盖成本或亏损主要表现为**多计收入、少计原材料成本、少计财务费用、少计销售费用和管理费用**等。多计收入已在操纵收入环节讨论，而少计成本和费用常常是多计收入的伴生操纵手段。

| 案例主体 | 手法 | 操作过程 |
| :--- | :--- | :--- |
| **ZGGH** | 少计财务费用 | 通过不计入对外拆借资金的利息，少计财务费用，增加当期利润。 |
| **KZYY** | 少计销售费用 | 销售过程中支付的回扣提成无法取得发票，遂按预付款挂账；后用公司其他款项打回公司，做预付款收回处理，从而减少销售费用、增加当期利润。 |
| **SXXC** | 少计原材料成本 | 2011 年和 2012 年通过少计原材料成本近 1 亿元，虚增利润 7000 多万元，使报表利润超过真实利润的 3 倍有余。常见手法是将价格不同的原材料定为不同名称，规避存货出库的会计政策约束，先计算低成本原材料，降低当期营业成本。 |

> 💡 除账目上多计收入或少计费用外，还有前述的"将众多子公司亏损及坏账集中在一家子公司里打包出售、掩盖亏损"的手法。老唐认为该手法的原创者应是央行和财政部——它们创造了"资产管理公司"收购银行坏账的模式。

#### 2.3　"洗大澡"

上市公司利用财务技巧，有意将公司经营及资产情况恶化。常见手法有：

- 注销资产或存货，以减低未来折旧或增加未来盘盈；
- 大额计提应收账款或存货减值损失，以便于未来转回；
- 将经常性费用归入一次性费用计提，以减少未来费用。

**"洗大澡"的两种动机：**

| 动机 | 说明 | 发生时机 |
| :--- | :--- | :--- |
| **毁尸灭迹** | 把以前虚增的利润冲掉 | 按需要发生 |
| **未来报表好看** | 把当期业绩做差，为未来账面增长率蓄力 | 通常在公司被并购之后或管理层更替之时 |

**（1）毁尸灭迹（按需发生）**

上市公司 ZGGH 创造性地利用这种手法，让自己盈利一年、亏损一年，如此重复，不断扭亏为盈、不断毁尸灭迹。既规避因连续亏损被打成 ST 股的命运，又避免虚假数字太高而穿帮，堪称一绝。

**（2）为未来报表好看**

通常发生在公司被并购之后或管理层更替之时：

- 新管理层倾向于把公司业绩做差，把责任推给前任（"我的前任是极品"），而后轻装上阵，彰显自己战绩辉煌、能力出众；
- 也有在公司遭遇经营困境、现任管理层回天无力时，索性破罐子破摔，把已经不好的业绩做得更差，博取来年的账面增长率。

**（3）两种相对少见的有趣做法**

- **帮上市公司埋单**：源自网络的段子。控股股东（有时是庄家）与高管吃饭必抢着埋单，理由是"帮上市公司承担 1 元费用，在股市上就会多几十元市值（取决于市盈率），对应持股比例的市值增长即是收益"。虽是段子，但大股东或利益关联人帮助或变相帮助上市公司承担费用，却是实实在在存在的事。
- **"自污"**：上市公司主动承认以前财报有问题（如使用了不恰当的会计政策或估计，或干脆承认会计差错），需要追溯调整以往报表。过程中，公司会把部分本应计入当期的费用，以认错改错的形式，调整到以前的会计年度里。

## 三、操纵现金流

资本市场更重视经营活动现金流，因而上市公司操纵现金流的主要目的一般是**美化经营活动现金流**。实现路径有三条，可单独或综合运用：

- 增加经营活动现金流入；
- 减少经营活动现金流出；
- 运用一次性行为综合美化。

#### 3.1　增加经营活动现金流入

核心思路：将**投资或筹资活动**的现金流入或流出，转化为**经营活动**现金流入。常见手法有：

| 序号 | 手法 | 说明 |
| :---: | :--- | :--- |
| （1） | 收购制造应收 | 收购一家公司获得其经营性现金流入。尤其在收购完成前，有意让收购对象付清应付款并制造应收款（让客户暂缓付款）；收购完成后，买来的应收款即变成经营活动现金流入。 |
| （2） | 出售分账 | 出售子公司或业务部门时，总款项分为首付款与未来收入分账两部分。收入分账部分未来计入经营活动现金流入，从而将投资活动现金流入转化为经营活动现金流入。 |
| （3） | 剥离保留应收 | 出售子公司或业务部门时，剥离并保留应收账款。待应收账款收回时，产生经营活动现金流入。 |
| （4） | 存货抵押回购 | 套用买入返售金融资产思路，将以存货抵押借款的行为，转化为先销售给出借方、下期加价回购，从而将筹资活动现金流入化装成经营活动现金流入。 |
| （5） | 互换贸易 | "你买我的产品，我买你的设备"。购买设备计入投资活动现金流出，产品销售作为经营活动现金流入。 |
| （6） | 担保融资 | "你买我产品，我帮你贷款"。上市公司以银行存款替客户担保融资，客户拿到钱后部分或全部购买上市公司产品。其实质是将投资活动现金流出转化为经营活动现金流入。某些公司的大额存款失踪奇案，背后很可能就潜伏着这种行为。 |

#### 3.2　减少经营活动现金流出

核心思路：将**经营活动**现金流出，转化为**投资或筹资活动**现金流出。常见手法有：

- **（1）归类转移**：将某些经营活动现金支出归入投资或筹资活动现金支出，减少经营性现金流出。例如购买电影电视节目版权、租入网络带宽、以融资租赁代替经营租赁等。
- **（2）承兑汇票采购**：以承兑汇票采购，减少当期经营活动现金流出；并在到期偿还时记录为债务偿还，归入筹资活动现金流出。

#### 3.3　一次性行为美化经营活动现金流净额

通过无法持续的一次性行为，美化当期经营活动现金流。常见手法有：

- **（1）打折出售应收款**：通过银行保理业务打折出售应收款，甚至利用关联公司或秘密控制公司创造应收款，然后出售并承担连带还款责任，从而夸大当期经营活动现金流入。
- **（2）高折扣催收/催付**：给出高额折扣，刺激客户在账期未到前付清应收款，或提前付款采购，增加当期经营活动现金流入。
- **（3）拖欠或减少采购**：拖欠供货商货款或减少正常采购，以减少当期经营活动现金流出，增加经营活动现金流量净额。

## 四、小结

以上大致就是上市公司常用的一些操纵财报手法。正如本书开篇谈到的三个案例，从 20 世纪到今天，手法变化并不大。

> **正所谓阳光之下无新事：操纵财报千变万化，不过是收入、费用和现金流。**

虽然确认和定罪很难，但**怀疑却不难**。作为投资者，要做的是对存在疑点的企业保持警惕。

在对财报的识假辨假上，**监管机构才是久经沙场的真高手**。证监会曾在 2012 年底发布《关于做好首次公开发行股票公司 2012 年度财务报告专项检查工作的通知》，明确指出了我国上市公司最可能出现问题的地方，提醒各保荐机构和会计师事务所进行核查。这部分专家意见很值得学习，原文附于下方知识链接。
