# 第一节 鸟瞰三大表

## 概述

资产负债表、利润表和现金流量表共同反映一家企业的全景信息，但侧重点和表现手法各有不同。这三张相互关联的报表构成了企业财务信息的完整体系。

---

## 一、三大报表的核心内容

### 1.1 资产负债表

**性质**：时点报表（企业在报表日的"照片"）

**反映内容**：企业的财务状况

| 维度 | 具体内容 |
|------|----------|
| **资产** | 企业拥有多少资产、资产类型分布 |
| **负债** | 负债总额、长短期负债结构、付息负债规模 |
| **核心意义** | 展示企业所控制资源的多寡强弱，决定企业持续经营和成长的能力 |

### 1.2 利润表

**性质**：期间报表（报表时段的"视频录像"）

**反映内容**：企业一段时间的经营成果

**核心逻辑**：
- 展示企业利用掌控的资源为他人创造价值并实现盈利的过程及结果
- 回放某段时间的企业经营行为和最终的赚赔结果
- **基本公式**：收入 - 费用 = 净利润

**与资产负债表的关系**：
```
净利润 = 期末留存收益 + 期内实施的分红 - 期初留存收益
```

### 1.3 现金流量表

**性质**：期间报表（利润表的"画外音"）

**反映内容**：企业现金流入流出的过程

**核心作用**：从另一个角度记录企业一段时间的活动，展示企业对现金的筹措和管控能力

---

## 二、三大报表的钩稽关系

### 2.1 现金流转逻辑

```
资金来源 → 现金流量表（入口）→ 转化为资产或费用 → 产生收入 → 现金流量表（回流）
```

| 现金流入来源 | 流向 | 对报表的影响 |
|-------------|------|-------------|
| **债务融资** | 保留为现金 | 增加资产负债表的货币资金 |
| **股东投入** | 支出减少债务 | 改变资产负债表的负债数额 |
| **经营收入** | 支出变成资产 | 超过一年作用期限，计入资产负债表 |
| | 支出变成费用 | 一年内作用期限，从利润表扣除 |

### 2.2 会计恒等式的演化

**传统恒等式**：
```
资产 = 负债 + 所有者权益
```

**因利润表存在而演化的新等式**：
```
资产 = 负债 + 所有者权益 + 收入 - 费用
```

### 2.3 利润操纵的识别

⚠️ **重要洞察**：

从新等式可以看出，企业如果想要虚增利润（收入-费用），必将：
- **虚增资产**（90%的造假选择） 
- **虚减负债**（10%的造假选择，需债权人配合，相对困难）

### 2.4 收入与现金流的勾稽关系

利润表的每笔收入必然产生以下两种结果之一：
- 产生了现金 → 与现金流量表产生关系
- 产生了应收 → 与资产负债表联系起来

**关键验证公式**（涉及增值税的企业）：

```
销售商品、提供劳务收到的现金 ≈ 
含增值税营业收入 
+ (应收票据期初余额 - 期末余额 - 本期已贴现票据)
+ (应收账款期初余额 - 期末余额)
+ (预收款项期末余额 - 期初余额)
- 非现金抵账 
+ 收回已核销坏账
```

其中：
- 含增值税营业收入 = 营业收入 × (1 + 增值税税率)
- 账面余额 = 账面价值 + 减值准备

💡 **偏差分析**：

若上述等式出现较大偏差，最可能的原因是公司将承兑汇票背书支付给供货商，导致销售收入既没有体现为现金，期末的应收票据里也没有踪影。需要在财报附注中搜索"背书"，查看：

- 使用票据背书转让购买商品或劳务的金额
- 使用票据背书转让购买固定资产及无形资产的金额

若加上背书金额仍有较大偏差且无法获得合理解释，则营业收入真实性存疑。

## 三、企业财务分析四步法

### 第一步：浏览科目，关注异常

**异常定义**：某科目出现明显过大比例的变动

#### 资产负债表重点关注科目

| 报表位置 | 重点科目 | 异常标准 |
|---------|---------|---------|
| **资产端** | 应收账款、应收票据、其他应收款、长期待摊费用 | 明显超过营业收入增长比例 |
| **负债端** | 应付票据、应付账款、其他应付款、短期借款 | 大比例增长 |

#### 利润表重点关注指标

| 检查顺序 | 关注指标 | 检查内容 |
|---------|---------|---------|
| **第一** | 营业利润率 | 是否有大比例变化 |
| **第二** | 公允价值变动收益、投资收益、资产减值损失 | 三者之和在营业利润中的占比是否发生重大变化 |
| **第三** | 营业利润与净利润的比例 | 是否保持基本稳定 |

⚠️ **处理原则**：
- 无异常 → 进入下一步分析
- 有异常 → 必须在附注中寻找解释，甚至致电公司
- 无法获得完整可信解释 → 对整份财报心存警惕

**核心理念**：财报是用来排除企业的。

### 第二步：财务指标的历史分析

**分析目的**：寻找可靠性

**类比说明**：
- 经常考90分的学生考95分 → 可信度高
- 经常考60分的学生考95分 → 可信度低，需进一步核查

**分析原则**：

| 项目 | 建议 |
|------|------|
| **观察周期** | 至少5年以上 |
| **关键指标** | 净资产收益率（ROE） |
| **普遍规律** | 上市当年ROE通常较上市前3年平均水平下跌超过50%，且以后年度很难恢复 |

**ROE下跌原因**：
- **台面说辞**：IPO导致净资产变大，投资项目尚未产生收益
- **台面下理由**：上市时化妆师下手太狠

💡 **历史同比分析的必要性**：避免受某年异常情况影响，是投资者不应忽略的功课。

### 第三步：对比利润和现金流量变化趋势

**核心目标**：证明利润的含金量

**健康标准**：

| 维度 | 标准 |
|------|------|
| **比例关系** | 净利润总量与经营活动现金流量净额总量保持大致稳定比例 |
| **理想状态** | 经营活动现金流净额 ≥ 净利润 |

⚠️ **警示信号**：

若出现以下情况，必须深入思考：
- 企业获利很好
- 现金流很差

**关键问题**：企业利润为什么没有转化为现金？

**分析工具**：根据现金流三大板块（经营活动、投资活动、筹资活动）的正负值建立企业现金流肖像，查阅对应类型企业应关注的要点。

### 第四步：与竞争对手比较

**分析价值**：带来更广阔的视野，避免被孤立的企业增速迷惑

**案例说明**：
- 企业营业收入同比增长20%（看似不错）
- 行业平均增幅50%
- **结论**：企业市场份额在降低，竞争优势在消失

**比较维度**：

| 维度 | 比较内容 | 分析目的 |
|------|---------|---------|
| **资产负债结构** | 与行业内企业对比资源运用方向 | 观察行业对未来发展是否有共识 |
| **利润表指标** | 各项收入和费用所占比例 | 评估管理层是否称职、是否有效运用股东资源 |

---

## 四、财务分析的最终目标

通过以上四步分析，投资者可以完成对企业的全面评估：

| 评估维度 | 分析手段 |
|---------|---------|
| **安全性** | 异常情况关注 + 历史对比 |
| **盈利能力** | 利润表指标分析 + 同业对比 |
| **成长性** | 趋势分析 + 行业对比 |
| **营运能力** | 现金流分析 + 资产周转分析 |

**最终输出**：企业价值的量化评估
