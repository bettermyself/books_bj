# 第二节 财报阅读入门

## 一、财报基础知识

### 1.1 时间规则

#### 境外上市企业
- 可根据行业或经营特点自定财年起止日
- **案例**：阿里巴巴（美国+香港上市）财年为当年4月1日至次年3月31日

#### 我国上市公司
- **财年标准**：统一按自然年（1月1日-12月31日）
- **报告类型**：一季报、半年报（中报）、三季报、年报

**披露时间要求**

| 报告类型 | 披露时间 | 特殊要求 |
|---------|---------|---------|
| 年报 | 年度结束后4个月内 | 必须经会计师事务所审计 |
| 一季报 | 一季度结束后1个月内 | 不得早于年报披露 |
| 半年报 | 8月底之前 | - |
| 三季报 | 10月底之前 | - |

**信息详细程度排序**：年报 > 半年报 > 一季报/三季报

### 1.2 报表范围

#### 三大报表
每份财报至少包含：
1. **资产负债表**
2. **利润表**
3. **现金流量表**

#### 母公司报表 vs 合并报表

| 报表类型 | 记录范围 | 子公司处理方式 |
|---------|---------|---------------|
| **母公司报表** | 仅上市公司本部 | 仅记录股权投资成本及现金分红 |
| **合并报表** | 上市公司本部+全部子公司 | 合并全部资产、负债、收入和费用 |

⚠️ **重点关注**：投资者应重点分析**合并报表**数据

#### 合并报表编制逻辑
合并报表将上市公司本部和全部子公司视为一个"假想的企业集团"：
- 采用统一会计政策（以上市公司本部为准）
- 合并所有资产、负债、收入和费用
- 抵销集团内部的投资、交易及债权债务
- 最终反映集团与外部单位/个人的关系

## 二、资产负债表解读

### 2.1 核心逻辑

> **一句话记忆**：表的右边记录**钱的来源**，表的左边记录**钱的去处**

**会计第一恒等式**：

```
资产 = 负债 + 股东权益
或
股东权益 = 资产 - 负债（净资产）
```

### 2.2 资产负债表基本结构

| 资产 (钱的去处) | 负债和股东权益 (钱的来源) |
| :-------------- | :------------------------ |
| **流动资产**    | **流动负债**              |
| **非流动资产**  | **非流动负债**            |
|                 | **股东权益**              |
| **资产总计**    | **负债和权益总计**        |

### 2.3 排列原则

#### 左侧（资产）：按变现便捷度排列
**从上到下**：货币资金 → 其他流动资产 → 固定资产/无形资产/商誉

#### 右侧（负债+权益）：按归还紧迫程度排列
**从上到下**：流动负债 → 非流动负债 → 股东权益

| 分类标准 | 流动类 | 非流动类 |
|---------|-------|---------|
| **时间界限** | 1年或1个营业周期内 | 超过1年或1个营业周期 |
| **资产举例** | 货币资金、应收账款、存货 | 固定资产、无形资产、商誉 |
| **负债举例** | 短期借款、应付账款 | 长期借款、应付债券 |

### 2.4 阅读技巧

#### 纵向对比（时间维度）
- 与历史数据对比，分析变化趋势
- 思考管理层为何这样调整资产/负债结构

#### 横向对比（行业维度）
- 与同行业公司对比资产占比差异
- **重点科目**：应收票据、应收账款、应付账款、预付款项、预收款项
- 💡 这些科目反映公司在产业链中的地位和竞争力

#### 实用建议
- 新手可将"百万"或"亿"后的数字四舍五入
- 训练对三位分节法数字的快速识别能力

## 三、利润表解读

### 3.1 基本结构

| 计算步骤 / 项目        | 计算结果       |
| :--------------------- | :------------- |
| **营业总收入**         | 初始数据       |
| **- 营业总成本**       |                |
| **+ 非主营业务净收入** | **营业利润**   |
| **+ 营业外收支净额**   | **利润总额**   |
| **- 所得税**           | **净利润**     |
| **- 少数股东损益**     | **归母净利润** |

### 3.2 权责发生制

⚠️ **风险警示**：权责发生制是财务造假的"温床"

**核心原则**：以权利或责任的发生确定收入和费用，而非现金实际收付

**举例说明**

| 会计处理 | 案例 |
|---------|------|
| **费用分摊** | 购买100万货车，预计使用5年，每年计入20万费用，而非当年全部计入 |
| **收入确认** | 第四季度运输费未收到，但12月31日仍需计入本年度收入 |

**潜在问题**
- 没收到的钱，可能被算作本期收入
- 没付出的钱，可能被记录为本期成本
- 已收到的钱，可能不是本期收入
- 已付出的钱，可能不是本期成本

### 3.3 归母净利润

#### 关键概念

| 科目 | 位置 | 含义 |
|------|------|------|
| **少数股东权益** | 资产负债表 | 合作伙伴持有子公司少数股份对应的净资产 |
| **少数股东损益** | 利润表 | 合作伙伴持有子公司少数股份对应的利润/亏损 |
| **归母净资产** | 资产负债表 | 归属于上市公司股东的权益 |
| **归母净利润** | 利润表 | 归属于上市公司股东的净利润 |

#### 重要财务指标

**每股指标**
```
每股净资产 = 归母净资产 ÷ 总股本
每股收益 = 归母净利润 ÷ 总股本
```

**估值指标**
```
市净率(PB) = 股票价格 ÷ 每股净资产 = 总市值 ÷ 归母净资产
市盈率(PE) = 股票价格 ÷ 每股收益 = 总市值 ÷ 归母净利润
```

## 四、现金流量表解读

### 4.1 核心原理

类似日常记账：期初现金 + 期间收入 - 期间支出 = 期末现金

### 4.2 现金等价物

由于企业很少持有大量现金，流动资金通常以以下形态存在：
- 银行存款
- 理财产品
- 高流动性短期债券

⚠️ **法规要求**：根据《现金管理暂行条例》，企业保留现金限额一般为3-5天零星开支（边远地区不超过15天）

### 4.3 三大活动分类

#### 经营活动

| 企业类型 | 经营活动定义 |
|---------|-------------|
| **制造企业** | 生产或销售商品 |
| **银行** | 借入/借出资金 |
| **证券公司** | 提供股票交易服务、自营买卖股票 |

**通用原则**：与投资和筹资活动无关的现金流入/流出

#### 投资活动
包括内容：
- 固定资产、无形资产等长期资产的买入或处置
- 对外股权投资和处置及持有期间回报
- 金融理财类投资

⚠️ **注意**：现金等价物范围内的形态转换（如活期存款↔短期债券）不计入投资活动

#### 筹资活动
包括内容：
- 发行股票、回购股票
- 分配股利
- 借债、还债、支付利息

⚠️ **排除**：日常经营活动中产生的应收应付款项

### 4.4 基本结构

```
期初现金及现金等价物余额
＋ 经营活动产生的现金流量
＋ 投资活动产生的现金流量
＋ 筹资活动产生的现金流量
＋ 汇率变动影响
═══════════════════════════
期末现金及现金等价物余额
```

## 五、补充阅读要点

### 5.1 必读内容

| 内容 | 阅读重点 | 阅读技巧 |
|------|---------|---------|
| **董事会报告** | 判断董事会可信度、市场判断准确性、企业掌控力 | 将多年报告连读，前后对比 |
| **重要事项** | 影响企业经营的重大事件 | 细读全文 |
| **财报附注** | 三大表的详细解释 | 企业不愿让投资者明白的内容常藏于此 |

### 5.2 业绩预告规则

#### 上海证券交易所

**必须披露情形**（1月31日前）：

1. 预计全年亏损
2. 扭亏为盈
3. 实现盈利且净利润同比增长或下降≥50%

**其他报告期**：鼓励自愿披露

#### 深圳证券交易所

**必须披露情形**

| 情形 | 年报 | 一季报 | 半年报 | 三季报 |
|------|------|--------|--------|--------|
| **披露时间** | ≤1月31日 | ≤4月15日 | ≤7月15日 | ≤10月15日 |

**触发条件**（满足之一即需披露）：
1. 亏损
2. 扭亏为盈
3. 实现盈利且净利润同比变动≥50%
4. 期末净资产为负值
5. 年度营业收入<1000万元

**豁免规则**：符合条件③但上年同期基数较小的可申请豁免

**基数较小定义**

| 报告期 | 上年同期每股收益阈值 |
|--------|---------------------|
| 年度 | ≤0.05元 |
| 前三季度 | ≤0.04元 |
| 半年度 | ≤0.03元 |
| 第一季度 | ≤0.02元 |

## 六、入门总结

掌握三大报表的基本阅读框架，你就算财报入门了：

✓ **资产负债表**：看懂企业家底，分析资产负债结构  
✓ **利润表**：理解盈利能力，警惕权责发生制陷阱  
✓ **现金流量表**：追踪现金流向，验证利润真实性

💡 **进阶建议**：
- 高手更关注资产负债表而非利润表
- 三表结合分析，相互印证
- 结合董事会报告和附注深入研究
