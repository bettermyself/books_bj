# 第四节 负债和所有者权益

## 概述

负债是债权人的权益。债权人没有参与经营的权利，也没有参与企业利润分配的权利，但享有按照约定收回本金和利息的权利。负债可能源于经营活动、融资活动或投资活动。

---

## 一、负债

### 1.1 负债的特点

| 特点 | 说明 |
|------|------|
| **计量客观性** | 价值通常有既定数额或由既定计量模式确定，计量的主观性较小，很少引起会计学争论 |
| **投资人关注度** | 相比资产，负债较少成为关注重心。资产可能恶化，而负债不会变得更糟 |
| **造假难度** | 负债里通常很少会有假账，直接隐瞒负债在信息时代比较困难 |

### 1.2 负债的分类

#### 按属性分类

| 分类 | 特征 | 会计科目 | 重分类规则 |
|------|------|----------|-----------|
| **交易性金融负债** | 需要归还的本息总额**不确定**，受市场因素或企业自身信用因素变化影响 | 以公允价值计量且其变动计入当期损益的金融负债 | 两种金融负债之间**不允许重分类** |
| **其他金融负债** | 需要归还的本息总额**确定** | 以摊余成本计量的金融负债 | 同上 |

💡 **会计错配特例**：为消除会计错配，企业可将某些相互依存的金融资产和负债指定为"以公允价值计量且其变动计入当期损益"类别，**指定一经做出，不得撤销**。

#### 按偿还期限分类

- **流动负债**：距离到期时间一年以内
- **非流动负债**：距离到期时间一年以上

⚠️ 超过一年的长期借款和债券，伴随时间推移距离到期日小于一年时，需要转入"一年内到期的非流动负债"。

### 1.3 投资人视角的负债分类

#### 按来源分类

| 负债类型 | 来源 | 主要科目 | 是否有息 |
|---------|------|----------|---------|
| **融资性负债** | 因运营或投资需要借贷或发行债券 | 短期借款、交易性金融负债、长期借款、应付债券、一年内到期的非流动负债 | 通常**有息** |
| **分配性负债** | 伴随企业盈利而产生，应付但未付的股利和所得税 | 应付股利、应交所得税 | 通常**无息** |
| **经营性负债** | 伴随企业经营活动产生 | 应付账款、预收款项、应付职工薪酬等 | 通常**无息** |

#### 按是否承担利息分类

- **有息负债**：融资性负债
- **无息负债**：经营性负债、分配性负债

### 1.4 负债的双刃剑效应

| 积极作用 | 消极风险 |
|---------|---------|
| 扩大企业控制的资产规模，为股东创造更多财富 | 可能成为企业不能负担之重，在危机中吸干企业现金流，成为推动企业倒塌的重要推手 |

💡 **投资人关注要点**：

1. **现金覆盖率**：企业的现金及现金等价物能否覆盖有息负债
2. **负债比例**：有息负债占总资产比例，最好与同行（尤其是行业龙头）对比

## 二、负债主要科目解读

### 2.1 金融机构特有科目

#### 向中央银行借款

金融机构（银行和非银行金融机构）的特权。央行作为银行的银行，在金融机构出现短期资金周转不灵时提供资金支持（如SLF、PSL）。

#### 吸收存款及同业存放

| 项目 | 说明 |
|------|------|
| **吸收存款** | 金融机构吸收的集团内部各公司存款 |
| **同业存放** | 其他金融机构存放的资金 |
| **合并抵销** | 上市公司及其控制的子公司存放在财务公司的存款，在制作合并报表时抵销 |
| **利息特点** | 需要付息，但同时产生利息收入和手续费收入，类似原材料采购，通常无须视为有息负债 |

### 2.2 应付职工薪酬

包括职工的工资、奖金、补助、五险一金、福利、工会经费、职工教育经费、辞退补偿等。

**计入科目规则**：

| 人员类型 | 计入科目 |
|---------|---------|
| 生产员工 | 生产成本 |
| 车间管理人员 | 制造费用 |
| 企业管理人员 | 管理费用 |
| 销售人员 | 销售费用 |
| 在建工程相关人员 | 在建工程 |

⚠️ **投资者注意**：对于净利润率很低且职工人数较多的公司，需测算工资上调多大比例会使公司由盈转亏。该比例如果比较小，建议慎重决策。

### 2.3 专项应付款

政府投入的具有专项或特定用途的款项，如科研项目补助、公益性拆迁补偿等。

**特点**：无须偿还，属于"良性"债务，是政府白给的资金。

### 2.4 预计负债

企业自行估计的，因以下活动大概率会导致公司承担责任的预计支出金额：

- 对外担保
- 未决诉讼
- 产品质量保证
- 重组义务
- 亏损性合同

💡 **大概率定义**：管理层判断发生概率在**50%～95%**。

### 2.5 递延收益（新准则）

**内容**：企业已收到或应收到的政府补助

**处理方式**（企业自选，选定后不能轻易改变）：

| 补助类型 | 处理方式 |
|---------|---------|
| 与资产相关 | 冲减资产账面价值 OR 确认为递延收益，在资产使用寿命里平均分配计入损益 |
| 补偿未来费用或损失 | 确认为递延收益，在对应费用或损失发生的同期转入损益或冲减相关成本 |
| 补偿已发生费用或损失 | 直接计入当期损益或冲减当年相关成本 |

## 三、所有者权益（股东权益）

### 3.1 所有者权益的构成

**计算公式**：所有者权益 = 总资产 - 总负债

**主要组成部分**：

```
所有者权益
├── 实收资本（股本）
├── 资本公积
├── 盈余公积  ─┐
└── 未分配利润 ┘ 留存收益
```

💡 **净资产概念**：属于上市公司股东拥有的净资产 = **归属于母公司所有者权益合计**（不包括少数股东权益）

### 3.2 实收资本（股本）

**定义**：实收资本 = 注册资本 ÷ 股票面值

**股票面值**：

| 项目 | 说明 |
|------|------|
| **标准面值** | 深交所和上交所上市公司通常为1元/股 |
| **特例** | 紫金矿业（0.1元/股）、洛阳钼业（0.2元/股） |
| **意义** | 仅为方便示意在注册资本里所占比例，与股票价值无对应关系 |

### 3.3 资本公积

#### 来源

| 来源 | 说明 | 纳税情况 |
|------|------|---------|
| **股本溢价** | 发行价格超出面值的部分（扣除上市相关支出） | - |
| **利得和损失** | 与企业日常经营活动无关、与股东投入无关，但能导致净资产增减的因素（如外部捐赠、资产评估价值变动） | - |
| **转增股本** | 经股东大会同意，资本公积可转成股本 | **不纳税** |

#### 三种特例（计入当期损益而非资本公积）

1. 交易性金融资产的公允价值变动
2. 以公允价值模式计量的投资性房地产公允价值变动
3. 汇率波动导致的外汇资产汇兑损益

#### 送股 vs 转增

| 对比项 | 送股 | 转增 |
|-------|------|------|
| **资金来源** | 未分配利润 | 资本公积 |
| **法律实质** | 先将利润分配给股东，再按面值向全体股东等比例发行新股 | 股东投入的本金在不同科目间调整 |
| **纳税** | 需缴纳个人所得税 | 不纳税 |

### 3.4 库存股

#### 产生原因

1. 上市公司（及其子公司）回购自己的股票后，暂时没有来得及处置
2. 股权激励过程中，尚未达到解锁条件的限制性股票（2014年5月后）

#### 回购目的

| 目的 | 说明 |
|------|------|
| **股权激励** | 用于董事、管理层及核心员工的激励，意图长期利益捆绑 |
| **注销** | 提升每股价值（前提：回购价格低于公司每股内在价值） |
| **私有化退市** | 国内股市不常见 |

#### 股权激励特点

1. **不白给**：通常以折扣价格卖给激励对象
2. **有锁定期**：一般有约定锁定期（如三年后才能卖出）

#### 库存股的会计性质

- **不是资产**：是股本和资本公积的**抵销科目**
- **无权利**：不享有分红权，也没有表决权
- **金额记录**：回购花费的总金额计入库存股（如按10元回购1亿股，库存股科目记录10亿元）

### 3.5 股权激励方式对比

| 方式 | 定义 | 现金支付时点 | 价格特点 |
|------|------|-------------|---------|
| **回购股票低价出售** | 回购股票后折价卖给激励对象 | 激励对象需支付折扣价 | 折价幅度自定 |
| **股票期权** | 约定未来达到条件后，激励对象有权以约定价格（行权价格）认购公司发行的股票 | **不需要现在支付** | 行权价格较高 |
| **限制性股票** | 激励对象现在可用折扣价格（授予价格）认购公司增发的股票，但达到约定条件前不能转让或抵押 | **需要现在支付** | 授予价格通常低于期权行权价格 |
| **股票增值权** | 不给股票，激励对象享受约定时间段内的股价涨幅，现金结算差价 | 现金结算 | - |
| **虚拟分红权** | 给激励对象虚拟股权，享有分红权（或许还有投票权），离职后权利丧失 | - | - |

💡 **薪酬支出处理**：股权激励的公允价值需根据激励对象岗位，分别计入营业成本、管理费用或销售费用，并在服务期间**按时间加权分摊**。

#### 股权激励薪酬支出分摊示例

**假设**：张三获得36万股期权，每满一年可按X元获得12万股，期权公允价值10元/股

| 时间 | 当年薪酬支出计算 | 累计支出 |
|------|----------------|---------|
| 第一年末 | (12万+6万+4万)×10元 = 220万元 | 220万元 |
| 第二年末 | (6万+4万)×10元 = 100万元 | 320万元 |
| 第三年末 | 4万×10元 = 40万元 | 360万元 |

### 3.6 专项储备和一般风险准备

| 项目 | 适用行业 | 用途 |
|------|---------|------|
| **专项储备** | 高危行业 | 安全生产费及类似性质费用 |
| **一般风险准备** | 金融机构 | 预防可能产生的亏损而额外准备的资金 |

### 3.7 盈余公积

#### 利润分配顺序

1. 弥补以前年度亏损（若有）
2. 按当年税后利润的10%计提**法定盈余公积**
3. 由股东决定是否提取**任意盈余公积**
4. 决定是否向股东分配

#### 盈余公积类型对比

| 类型 | 提取比例 | 提取上限 | 决定权 |
|------|---------|---------|-------|
| **法定盈余公积** | 当年利润的10% | 累积到注册资本的50%后可不继续提取 | 政府强制 |
| **任意盈余公积** | 股东自定 | 无上下限 | 股东自愿 |

⚠️ **注意**：法定盈余公积的10%提取要求，是以**上市公司本部净利润（母公司利润表净利润）**为基数，不是合并利润表的净利润或归母净利润。

### 3.8 未分配利润

**定义**：公司历年赚取的报表利润中，没有分给股东，也没有划为盈余公积的部分。

⚠️ **重要提示**：未分配利润按照**权责发生制**计算，并不等于现金。即便利润全是现金，这些"未分配利润"也很可能已经变成土地设备、固定资产、在建工程及其他投资。

💡 **查看现金余额**：资产负债表"货币资金"科目才代表公司账上现金数量。

### 3.9 资金使用自由度排序

```
未分配利润 > 盈余公积 > 资本公积 > 注册资金
   ↓           ↓          ↓          ↓
股东自由决定  可弥补亏损   只可转成    完全不能动
             或送股      股本     （抽逃注册资金
                                  是刑事犯罪）
```

### 3.10 其他权益工具（新准则）

**定义**：企业发行在外、除普通股以外的其他带有权益性质的金融工具账面价值

**包括**：优先股、永续债、可回售工具、可转债（权益部分）、期权、认股权证等

#### 分类原则

| 判断标准 | 归入金融负债 | 归入其他权益工具 |
|---------|------------|----------------|
| **强制义务** | 企业承担交付现金或其他金融资产的强制义务 | 企业无强制交付义务 |
| **风险承担** | 持有人不承担企业经营风险及股价波动风险 | 持有人和企业共担风险 |
| **交换方式** | 需要用**可变数量**的企业股权交换 | 用**固定数量**的企业股权交换 |

#### 重分类规则

| 重分类方向 | 账面价值处理 | 差额处理 |
|-----------|------------|---------|
| 其他权益工具 → 金融负债 | 以重分类日公允价值为金融负债账面价值 | 差额调整股东权益 |
| 金融负债 → 其他权益工具 | 以金融负债账面价值为其他权益工具账面价值 | - |

⚠️ **名称辨析**：

- **其他权益工具**（权益科目）：本公司发行的融资工具
- **其他权益工具投资**（资产科目）：本公司投资的其他公司股权

## 五、股权激励新规定（2016）

### 5.1 时间和数量限制

| 项目 | 要求 |
|------|------|
| **激励时间跨度** | 不得短于1年，不得长于10年 |
| **公司总激励额度** | 全部在有效期内的股权激励总数，累计不得超过公司股本总额的**10%** |
| **个人激励额度** | 任何一名激励对象通过全部在有效期内的股权激励计划获授的股票，累计不得超过公司股本总额的**1%**（非经股东大会特别决议批准） |

### 5.2 限制性股票

#### 授予价格

原则上不得低于下列价格的**较高者**：

1. 股权激励计划草案公布前1个交易日成交均价的**50%**
2. 股权激励计划草案公布前20/60/120个交易日成交均价之一的**50%**

#### 解除限售要求

| 项目 | 要求 |
|------|------|
| **授予日与首次解除限售日间隔** | 不得少于12个月 |
| **分批解除限售** | 每期间隔不得少于12个月 |
| **每期解除比例** | 不得超过激励对象所获限制性股票总量的50% |

### 5.3 股票期权

#### 行权价格

原则上不得低于下列价格的**较高者**：

1. 股权激励计划草案公布前1个交易日成交均价
2. 股权激励计划草案公布前20/60/120个交易日成交均价之一

#### 行权时间要求

| 项目 | 要求 |
|------|------|
| **授权日与首次可行权日间隔** | 不得少于12个月 |
| **分期行权** | 每期时限不得少于12个月 |
| **后期起算** | 后一行权期的起算日不得早于前一行权期的届满日 |
| **每期可行权比例** | 不得超过所获期权总额的50% |

### 5.4 其他限制

⚠️ **禁止财务资助**：上市公司不得向激励对象提供任何形式的财务资助，包括贷款、贷款担保及其他形式。

## 六、大额分红的警惕

⚠️ **分红陷阱**：

当上市公司宣布大额现金分红时，需多想一分钟：

1. **净资产下降**：股东大会通过分红方案后，分红所需现金从"未分配利润"划入"应付股利"，导致公司净资产下降
2. **提高ROE**：大额分红降低净资产基数，在净利润不变的前提下提高净资产收益率（ROE = 净利润 ÷ 净资产）
3. **再融资动机**：企业再融资、股权激励等资本活动常需要ROE满足某数值要求
4. **飞去来器**：先大额分红、再巨额融资的公司，不少是利用了这个规则

💡 **投资建议**：看见公司实施大额现金分红时，不要第一时间将其归为利好，请多想一分钟。
