# 第三节 速读利润表

## 概述

理解了资产负债表后，利润表就是一张特别简单的表。我们拿到一张利润表，关注**四个要点**足矣：

- 营业收入
- 毛利率
- 费用率
- 营业利润率

看清楚了它们，单独就利润表而言就算可以了。需要和其他报表配合起来看的部分，我们在第五章聊。

---

## 一、营业收入

### 1.1 营业收入的重要性

营业收入展示企业经营状况和发展趋势。作为投资者，首选的企业是营业收入**增长、增长、增长**——过去增长，现在增长，预计在可见的未来将继续保持增长的企业。

### 1.2 收入增长的三种途径

如果不考虑收购兼并式的增长，企业收入的增长通常有三种途径：

| 增长途径 | 特点描述 | 可靠性评估 | 需要评估的风险 |
|---------|---------|-----------|--------------|
| **潜在需求增长** | 行业内不会产生受损者，仅受益程度不同 | ⭐⭐⭐ 最强 | 无明显风险 |
| **市场份额扩大** | 以竞争对手受损为代价 | ⭐⭐ 中等 | 竞争对手的反击力度及反击下增长的可持续性 |
| **价格提升** | 以客户付出更多为代价 | ⭐ 较弱 | 产品或服务的替代性强弱，客户可能减少消费或寻找替代品 |

### 1.3 关注增速与行业对比

投资者不仅要看企业营业收入绝对数的增长，还要看**增速是否高于行业平均水平**。

- ✅ **增速高于行业平均** - 证明企业的市场份额在扩大，仍然是行业中的强者
- ⚠️ **增速低于行业平均** - 提示企业的市场份额在缩小，可能意味着：
  - 行业内出现了更强硬的对手
  - 企业某方面的竞争优势正在"融化"

### 1.4 特殊情况：佛龛市场（利基市场）

**佛龛市场特点：**
- 市场规模有限，容不下更多对手参与竞争
- 企业已建立相当强的竞争优势
- 新对手加入后，很可能导致两家都很难赚到钱
- 空间狭小，和其他区域间隔明显

💡 **投资策略：** 对这种市场里的企业，投资者无须关注营业收入的增长，而是要**重点关注经营所得现金的去向和利用效率**。

### 1.5 持续增长的难度

⚠️ **常识提醒：** 持续的增长相当困难。

**案例分析：** 以贵州茅台2013年310亿元营业收入为起点，假设公司能持续保持20%的年增长水平：
- 到2055年，营收将达到65.6万亿元
- 高于2014年我国GDP（约63.6万亿元）
- 这显而易见是不现实的

💡 **投资提示：** 估算企业未来增长幅度及可持续时间，尤其是估值时会用到的"永续增长率"假设数据，一定要**防止自己过于乐观**。

## 二、毛利率

### 2.1 毛利率的计算与意义

**计算公式：**
```
毛利润 = 营业收入 - 营业成本
毛利率 = 毛利润 ÷ 营业收入
```

**毛利率的意义：**
- **高毛利率** - 产品或服务具有很强的竞争优势，替代品较少或替代代价很高
- **低毛利率** - 产品或服务存在大量替代品且替代代价很低，价格微小变动都可能使客户放弃购买

### 2.2 投资建议

一般来说，建议投资者**尽量选择高毛利率的企业**。

> 💬 巴菲特说过："我并不试图超过七英尺高的栏杆，我到处找的是我能跨过的一英尺高的栏杆。"

投资不是竞技，投资者追求的不是克服困难的快感，而是**稳定轻松的获利**。选择低毛利率的企业，意味着要依赖管理层的运营能力或者冒高倍杠杆的风险，实属不必要。

**案例：** 巴菲特投入17亿美元买入英国超市运营商特易购（TESCO）约4%的股份，2014年亏损超过7亿美元，不得不"割肉"减持。

### 2.3 毛利率评判标准

| 毛利率区间 | 企业状态 | 投资建议 |
|-----------|---------|---------|
| **≥ 40%** | 通常具有某种持续竞争优势 | ✅ 优先选择 |
| **20% - 40%** | 处于高度竞争的环境 | ⚠️ 谨慎评估 |
| **< 20%** | 竞争激烈，利润空间极小 | ❌ 留给专业人士 |

**A股高毛利率行业：**
- 信息技术
- 生物医药
- 食品饮料
- 餐饮旅游
- 文化传播
- 房地产

*基本也是牛股集中营*

## 三、费用率

### 3.1 费用的构成

费用一般习惯性地被称为"三费"（2018年后为"四费"）：

| 费用类型 | 说明 |
|---------|------|
| 销售费用 | 营销推广相关费用 |
| 管理费用 | 日常管理运营费用 |
| 财务费用 | 利息收支相抵后的净额 |
| 研发费用 | 2018年后单独披露 |

### 3.2 费用率的计算方法

**保守策略：**

- **财务费用为正数**（净支出）：
  ```
  费用率 = (销售费用 + 管理费用 + 财务费用) ÷ 营业总收入
  ```

- **财务费用为负数**（净收入）：
  ```
  费用率 = (销售费用 + 管理费用) ÷ 营业总收入
  ```

### 3.3 费用率的警示信号

⚠️ **主要需警惕：** 费用率过高或费用率剧烈变化的公司。

#### 3.3.1 销售费用分析

| 销售费用水平 | 产品特性 | 扩张风险 |
|------------|---------|---------|
| **高** | 产品缺乏"拉力"，必须靠营销"推力"才能完成销售 | 扩张时需要配套新团队、资金和促销方案，对管理能力要求极高 |
| **低** | 产品或服务本身容易引起购买者的重复购买，甚至自发分享、传播 | 扩张风险较小 |

#### 3.3.2 管理费用分析

**正常情况：** 管理费用增幅应等于或小于营业收入增幅。

⚠️ **异常情况：** 管理费用增幅大于营业收入增幅，需要查出明细，挖掘究竟是什么发生了变化。

**特别警惕：** 连续数年出现小额净利润的公司，可能利用管理费用调控报表：
- 将实际的微亏调整为微利
- 累积几年微利后，搞一次大亏，填完以前的坑（俗称"洗大澡"）
- 常用手段：折旧、摊销、计提准备等

### 3.4 费用率评判标准

**以费用占毛利润的比例观察：**

| 费用占毛利润比例 | 企业评价 |
|----------------|---------|
| **≤ 30%** | ✅ 优秀企业 |
| **30% - 70%** | ⚠️ 具有一定竞争优势 |
| **> 70%** | ❌ 关注价值不大 |

### 3.5 毛利率与费用率的联合分析

**案例1：毛利率40%，费用占毛利润80%**
- 100元销售收入 → 40元毛利润
- 其中32元费用 → 8元营业利润
- 扣除25%所得税 → **净利润率仅6%**

**案例2：毛利率20%，费用占毛利润80%**
- 100元销售收入 → 20元毛利润
- 其中16元费用 → 4元营业利润
- 扣除25%所得税 → **净利润率仅3%**

💡 **结论：** 如此微薄的利润空间，市场稍有波动就可能导致企业账面难看。从投资的角度说，如果有得选，尽量避免在这种公司身上浪费宝贵的资本和时间。

### 3.6 研发费用的辩证思考

#### 3.6.1 保守派观点：规避高研发费用企业

**理由：**
- 不断投入巨额研发费用的公司，很可能经营前景不明，风险较高
- 依靠专利权保护或技术领先的企业，一旦专利到期或遭遇新技术替代，竞争优势会丧失殆尽
- 金钱的堆积并不意味着技术的成功，研发失败概率大于成功概率

**案例：** 2014年10月6日，因为研发失败，美股GTAT在一个交易日内从11美元以上跌至0.8美元，随后一周跌破0.4美元。

#### 3.6.2 激进派观点：拥抱高研发费用企业

**理由：**
- 新技术或新产品的研发一旦成功，可能带来巨大的回报
- 高风险对应高收益

#### 3.6.3 投资建议

| 投资者类型 | 策略建议 |
|-----------|---------|
| 风险规避型 | 远离研发费用高的企业 |
| 风险偏好型 | 合理配置投入比例，以应对潜在的高波动性和高不确定性 |

## 四、营业利润率

### 4.1 计算公式与意义

**计算公式：**
```
营业利润率 = 营业利润 ÷ 营业收入
```

营业利润率是**公司分析的核心指标之一**，基本完整体现了企业的盈利能力。

### 4.2 优化建议

💡 **更符合逻辑的算法：**

如果将营业利润排在"公允价值变动收益"之前，由营业总收入减去营业总成本得出一个**不含"公允价值变动收益、投资收益和汇兑收益"的"营业利润"**，然后再除以营业收入得到的比例，其实更符合逻辑。

*可惜财政部不会听老唐的，所以，我们要么自己算，要么就凑合使用利润表上的现成数据，坚持同口径就好。*

### 4.3 案例分析：贵州茅台

贵州茅台这种高毛利率企业，成本和费用占比变化不大，结果就是伴随营业收入的高速增长，营业利润率可以**飙升至高达70%左右**。

### 4.4 营业利润率分析要点

投资者不仅要看数字大小，更要**对比历史变化**。

#### 营业利润率上升时，需要分析原因：

| 可能原因 | 需要思考的问题 |
|---------|--------------|
| **售价提升** | 提价会不会导致市场份额下降？ |
| **成本下降** | 是全行业一起降了，还是本公司独降？<br>原因是什么？<br>是一次性影响还是持续影响？ |
| **费用控制得力** | 费用控制有没有伤及公司团队战斗力？<br>是一次性的费用减少还是永久性的费用减少？<br>竞争对手是否可以采用同样行动？ |

## 五、关键验证：净利润的现金实现

看完上面四个要点，一份利润表就基本清楚了。但还有**非常重要的一步**：确认净利润是否变成现金回到公司账户。

### 5.1 验证方法

**计算公式：**
```
现金实现率 = 经营现金流净额 ÷ 净利润
```

**数据来源：**
- 经营现金流净额 - 来自**现金流量表**
- 净利润 - 来自**利润表**

### 5.2 评判标准

| 比值情况 | 评价 |
|---------|------|
| **持续大于1** | ✅ 优秀企业的重要特征，代表净利润全部或大部分变成了真实的现金 |
| **小于1** | ⚠️ 需要关注利润质量 |

### 5.3 利润与现金流的权衡

- **利润** - 充满估计和假设
- **现金** - 实打实的硬通货

企业的经营总是在利润和现金流之间权衡：
- 究竟是在保证现金流的前提下最大化追求利润？
- 还是在实现利润最大化的前提下考虑现金流？
