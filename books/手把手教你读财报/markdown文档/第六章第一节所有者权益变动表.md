# 第一节 所有者权益变动表

所有者权益变动表，也称"股东权益变动表"，负责反映公司本期内所有者权益的变动情况。其核心作用体现在三个方面：

- 反映**直接计入权益的利得和损失**
- 反映**权益总量**的增减变动
- 反映**权益增减变动的结构**

所有者权益的来源主要有三大块：**股东直接投入、留存收益、直接计入权益的利得和损失**。

> 💡 **提示**：所有者权益变动表的内容，本质上是"资产负债表"和"利润表"相关内容的整理与归集。如果已经仔细阅读过前两张报表，本表读不读影响不大。本节内容是对前文的复习，即便跳过也不影响财报的使用。

---

### 一、核心概念解析

#### 1.1 利得与损失的由来

"利得"是 **2007 年**正式引入我国会计准则的新定义。它的引入，将以前的"收入"按来源拆分为两部分：

| 来源 | 名称 | 对应关系 |
| :--- | :--- | :--- |
| 来自日常经营活动 | **收入** | 收入 − 费用 = 利润 |
| 来自资产及负债的价值变化或偶然事件 | **利得** | 利得 − 损失 = 可能形成利润，也可能直接形成净资产 |

#### 1.2 利得和损失的两大分类

利得和损失分为两大块，两者又各含五小块，均为"资产负债表"和"利润表"章节已讨论过的内容。

**① 计入当期利润的利得和损失**

1. 资产减值损失
2. 公允价值变动收益
3. 投资收益
4. 汇兑收益
5. 营业外收支

**② 不计入当期利润的利得和损失**

指按照会计准则，在利润之后的"其他综合收益"部分披露，包括：

1. 可供出售金融资产公允价值变动（不含减值损失和汇兑收益）
2. 金融资产重分类，重分类日公允价值与账面价值差额
3. 自用或存货房地产转换为公允价值模式核算的投资性房地产，转换日公允价值与原账面价值的差额
4. 采用权益法核算的长期股权投资，被投资单位除净利润以外的所有者权益变动，在持股比例不变的情况下，企业按持股比例计算应享有的份额
5. 可转换债券所含权益对应的公允价值

> 💡 若对上述内容有疑惑，回看前文投资类资产及利润表"其他综合收益"部分即可。

### 二、以茅台为例：读懂报表结构

利得、资本的投入（或减少投入）、利润，都会引发所有者权益发生变化，所有者权益变动表正是归纳和展现这一变化过程的报表。下面对照**贵州茅台 2013 年财报**的合并所有者权益变动表，观摩其过程。

#### 2.1 表头三大板块

合并所有者权益变动表的表头分为三大块，如表 6-1-1 所示：

**表 6-1-1　合并所有者权益变动表**

| 项目 | 归属于母公司所有者权益 | 少数股东权益 | 所有者权益合计 |
| :--- | :--- | :--- | :--- |
| …… | 实收资本 / 资本公积 / 盈余公积 / 未分配利润 | — | = 前两者加总 |

其中：

- **归属于母公司所有者权益**：本表展示的重心。
- **少数股东权益**：上市公司下属子公司中占少数股份的股东所拥有的权益。
- **所有者权益合计**：前两者的加总。

> ⚠️ **注意**：这份报表是给上市公司股东看的，他们重点关心的是"归属于母公司所有者权益"，因此该项是全表的展示重心。

#### 2.2 归属于母公司所有者权益的构成

在资产负债表中已谈过，所有者权益主要由四大块构成：**实收资本、资本公积、盈余公积和未分配利润**。因此"归属于母公司所有者权益"部分即按这四个项目展示。

由于"少数股东权益"的变化与"归属于母公司所有者权益"按比例同步，而"所有者权益合计"只是二者加总，均清晰明了，故下表仅展示"归属于母公司所有者权益"的变化细节。

### 三、期末权益总额的计算过程

会计从上年年末数据开始，罗列造成各科目变化的原因，最终推导出期末余额。整个过程分为两个阶段。

#### 3.1 第一阶段：从上年末余额到本年初余额

先以上年末余额为起点，加上会计政策变更或会计差错更正带来的变化（若有），得到本年初余额。

**表 6-1-2　归属于母公司所有者权益构成（本年初余额）**

| 项目 | 说明 | 数据来源 |
| :--- | :--- | :--- |
| **A：上年年末余额** | — | 上年的资产负债表所有者权益对应科目 |
| **B：会计政策变更导致的变化** | 若有（变化为负值，则表达为负值） | — |
| **C：前期会计差错更正** | 若有（变化为负值，则表达为负值） | — |
| **D：本年年初余额** | **D = A + B + C** | — |

#### 3.2 第二阶段：从本年初余额到期末余额

用"本年年初余额"加上"本期增减变动金额"，得出"本期期末余额"。其中最重要的"本期增减变动金额"分为五块：

| 代号 | 项目 | 含义 |
| :--- | :--- | :--- |
| **E** | 净利润 | 当期实现的净利润 |
| **F** | 其他综合收益 | 主要指五项不计入当期利润的利得和损失 |
| **G** | 所有者投入或减少资本 | 股东对资本的投入或减少 |
| **H** | 利润分配 | 当年对净利润的处理：提取盈余公积、提取一般风险准备、提取专项储备、向股东派发红利 |
| **M** | 所有者权益的内部结转 | 资本公积转增股本、盈余公积弥补亏损或转增股本 |

**表 6-1-3　期末所有者权益总额获取的过程**

| 代号 | 项目 | 数据来源 |
| :--- | :--- | :--- |
| **D** | 本年年初余额 | D = A + B + C |
| **E** | 净利润 | 当期合并利润表 |
| **F** | 其他综合收益 | 当期合并利润表（主要是五项不计入当期利润的利得和损失） |
| **G** | 所有者投入或减少资本 | 合并资产负债表实收资本和资本公积科目 |
| **H-I** | 当年提取的盈余公积 | 财报重要提示之"提取盈余公积" |
| **H-J** | 当年提取一般风险准备 | 财报重要提示之"提取一般风险准备" |
| **H-K** | 当年提取的专项储备 | 同上，若有（高危行业提取的安全生产费） |
| **H-L** | 当年实施的上年度分红 | 上年度分红方案（给钱出去，用负数表示） |
| **M** | 所有者权益内部结转 | 送股、转增股本、盈余补亏等 |

> ⚠️ **注意**：如果有需要补充说明的其他项目，上市公司会在表中单列或以其他项列出。

#### 3.3 关键计算公式

**期末所有者权益总额 = D + E + F + G + L**

需要特别理解**为什么该公式不包含 M、I、J、K**：

- **不含 M**：M 只是所有者权益内部存在形式的变化，增加其中某项一定会同时减少其他项，不引起"归属于母公司所有者权益"总额的变化。
- **不含 I、J、K**：净利润分配中的 I、J、K 三项，只是将留存公司的净利润换了一个科目摆放，增加 I、J、K 的同时会减少净利润，总量不变。
- **仅含 L（分红）**：只有分红才真正减少了公司的所有者权益，因此需要减去（在公式中表示为加上其负值）。

> 💡 理解了上述"内部结转不改变总量、只有分红才流出"的逻辑，这张表就非常简单了。

### 四、新准则升级版

新准则下的所有者权益变动表变化不大，主要**新增两个项目**。

| 新增项目 | 记录内容 | 参考章节 |
| :--- | :--- | :--- |
| **其他权益工具持有者投入资本** | 企业发行的除普通股以外、分类为权益工具的金融工具带来的新增资本金额 | 第二章第四节"所有者权益新增科目：其他权益工具"（第 164 页） |
| **其他综合收益结转留存收益** | 见下方两项明细 | 见下方参考 |

**"其他综合收益结转留存收益"**具体记录以下两项：

1. **其他权益工具投资处置**：处置时，之前计入其他综合收益的利得和损失转入留存收益（未分配利润和盈余公积）的金额。
   - 📖 参见第二章第三节"新准则升级版"中有关其他权益工具投资的内容（第 132 页）。
2. **企业自身信用风险变动**：由企业自身信用风险变动引起的、被计入其他综合收益的金融负债公允价值变动，在处置金融负债时需转入留存收益的金额。
   - 📖 参见第三章第一节"新准则升级版"中的"企业自身信用风险公允价值变动"部分（第 194 页）。
