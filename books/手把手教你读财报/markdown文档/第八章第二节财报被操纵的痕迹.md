# 第二节 财报被操纵的痕迹

> 上市公司操纵财报的**主要目的**是美化利润表，**次要目的**是美化经营活动现金流。

根据会计恒等式：

$$资产 = 负债 + 所有者权益 + 收入 - 费用$$

美化收入和费用带来的所有者权益变动，最终必须通过调整资产和负债科目来体现。俗话说，雁过留声——这些操纵与调整必然会留下痕迹：利润表和现金流量表上会有，而**更多的痕迹则会留在资产负债表上**。

---

## 一、利润表常见操纵痕迹

### 1.1 营业收入

收入是利润的源头，**虚构收入是上市公司造假的主要方式**。识别线索主要有以下四类：

#### 1.1.1 毛利率异常提升

虚构收入是为了虚增利润，因此操纵者一般首选**高毛利业务**入手。无论财报操纵还是造假都是系统工程，涉及环节众多，绝非账目上写个数字即可。一笔高毛利造假可抵多笔低毛利造假，既减少工作量，也降低被发现的概率。其代价是：故意增加高毛利产品销售收入，会扭曲正常产品销售结构，**显著改变公司当期毛利率**。

毛利率提升的可能原因及验证方式如下：

| 提升原因 | 验证方式 | 是否合理 |
| :--- | :--- | :--- |
| 高毛利产品造假 | 观察销售结构是否被扭曲 | ⚠️ 造假嫌疑 |
| 销售单价提升 | 观察市场状况，证实或证伪 | 合理 |
| 原材料成本下降 | 对比同行竞争对手财报 | 合理 |

💡 当发现上市公司毛利率**显著高于同行**，且**同比大幅波动**时，应首先排查"单价提升"和"成本下降"两种合理情况。若均无法解释，则很可能存在财报操纵。

#### 1.1.2 毛利率与供应链地位不匹配

毛利率大幅提升，一般说明产品竞争力增强，企业在供应链上的地位随之提升。与之吻合的财报特征应为：

- **应收账款减少**——在买家面前地位提升
- **应付账款增加**——在上游供应商面前地位提升

⚠️ 如果毛利率显著提升，却同时伴随**应收账款增加、应付账款减少**，往往提示需注意造假嫌疑。

#### 1.1.3 交易对手可疑

虚构收入需要交易对手，关注临时出现的交易对手可能发现疑点：

- 销售以往从未生产或经销过的产品
- 与财报中从未出现的大客户交易，且金额不小、交易方式显示双方具有一定信任度
- 交易标的对该客户不具有合理用途
- 交易价格明显偏离正常市场价格

#### 1.1.4 配套费用的勾稽异常

有些细节容易被操纵者忽略，从而暴露破绽：

- 运费或装卸费**增长比例显著低于销售收入增长比例**，且无合理解释
- 出口收入与海关费用之间呈**反向变动**

💡 可根据所关注公司产品的特点，梳理产品销售会经过的环节及应产生的费用，观察它们与营业收入之间的关系。日积月累，便能形成自己的"秘密武器"。

### 1.2 其他业务收入和营业外收入

其他业务收入，指营业收入中除主营业务收入以外的收入（参见贵州茅台 2013 年财报第 80 页第一张表）。

从财务角度看，**操纵其他业务收入比操纵主营业务收入更方便、更隐蔽**，原因在于两者披露要求存在差异：

| 收入类型 | 披露要求 | 操纵空间 |
| :--- | :--- | :--- |
| 主营业务收入 | 详细 | 较小 |
| 其他业务收入 | 简单 | 较大 |

许多上市公司玩弄文字游戏，把模糊业务在"主营业务"与"其他业务"之间随意划转，甚至将一笔收入同时记入两处。

⚠️ 需警惕的信号：

- 其他业务收入在营业收入中的**占比突然大幅提升**，又无令人信服的解释
- 公司利润主要来自**偶然的营业外收入**
- 多年反复发生这种"偶然"

### 1.3 销售费用和管理费用

销售费用和管理费用通常应与营业收入**同向变动**，并在营业收入变化不大时保持比例相对稳定。该比例可从两个维度对比：

- **纵向**——与公司历史数据对比
- **横向**——与竞争对手对比

⚠️ 如果销售费用和管理费用占营业收入的比例某年**同比大幅降低**，且显著低于竞争对手水平，需考虑财报操纵的可能。

### 1.4 营业外支出和一次性费用

好公司的财务数据通常很容易理解。而意图隐藏问题的公司，常会创造一些让人不知所云的费用科目，用于藏匿不想被投资者追究的支出，例如：

- 各类"其他 ××"科目
- "重组""资产清理""商誉清理"等支出

⚠️ 财报上出现**金额较大的"其他 ××"**，或一些很少见过的科目名称，都是值得警惕的信号。

### 1.5 资产减值损失

资产减值损失的异常，往往指向"洗大澡"（故意做低盈利基数）：

- 资产减值损失同比大增，同时若按上年同期水平计算，利润同比波动并不大——需考虑"洗大澡"的可能
- 资产负债表上的固定资产、存货、应收账款、金融资产等**大幅计提减值损失，乃至价值归零**——同样需考虑"洗大澡"的可能

## 二、现金流量表常见操纵痕迹

企业操纵现金流量表受制于银行现金余额，**操纵成本相对较高**。因此，直接伪造银行现金余额或函证单据这类犯罪行为相对偏少。由于操纵的主要目标是**美化经营活动现金流量**，可能显露痕迹的地方主要有：

### 2.1 经营活动现金流量净额

| 异常现象 | 隐含风险 |
| :--- | :--- |
| 经营活动现金流净额持续优于同行，同时投资活动现金净额持续为大额负数 | 可能将投资活动现金流出转换为经营活动现金流入 |
| 经营活动现金流量净额持续多年为负 | 往往提示财报其他地方存在操纵或造假 |

### 2.2 收到其他与经营活动有关的现金

该科目金额通常应偏小。

⚠️ 如果金额**突然增大**，而附注又无可信解释，需考虑是否有关联企业或利益相关人士打款进来，帮助企业美化经营活动现金流入。

### 2.3 投资活动现金流出

一般来说，上市公司的资本支出并非临时起意，而是年初就经董事会商定，并以财务预算方案形式提交年度股东大会讨论。

⚠️ 如果投资活动现金流出金额**超过年初预算很多**，很可能存在临时救急：将投资活动现金流出化装成经营活动现金流入，虚增营业收入或美化经营活动现金流。

> 💡 **提示**：可用下载财报的方法，在深沪交易所或巨潮网输入"股东大会会议资料"，查找《公司 20×× 年度财务预算方案》进行核对。

### 2.4 筹资活动现金流中的利息支出

该项支出可对应资产负债表的有息负债观察：

- 若公司借债**利率偏高**，很可能存在某方面不为人知的问题
- 若将高息借来的债务或增发新股融来的资金，**闲置在银行且收益率明显低于借债利率**，是明显的报警信号
- 若公司本身**货币资金充足，却又高息借债**，造假或操纵财报的可能性非常大

## 三、资产负债表常见操纵痕迹

### 3.1 应收账款

以下情形均可能预示财报操纵：

- 应收账款大幅增长，且**增幅超过同期收入增幅**
- 应收账款周转率**低于同行水平，且呈明显下降趋势**

其背后既可能是公司临时放宽信用政策以促进短期收入，也可能是提前确认收入甚至虚构收入。

### 3.2 其他应收款

应收账款主要指赊销产生的款项；而其他应收款指与销售无关的往来款，可能是委托理财、借款，或使用某种资产、权利的款项等。**与销售无关却要调动资金往来，本身就存疑，当然越少越好**。优秀上市公司的一个特点，就是其他应收款和其他应付款科目数额极小，甚至为零。

| 对比维度 | 应收账款 | 其他应收款 |
| :--- | :--- | :--- |
| 业务关联 | 与销售相关 | 与销售无关 |
| 所需单据 | 发票、仓单、运输等一系列 | 无 |
| 造假难度 | 较高，易暴露 | 较低，操作空间大 |
| 价格设定空间 | 较小 | 较大 |

⚠️ 其他应收款数额较大，即便不是财务操纵的结果，也可能显示资金被控股股东或关联人占用。因此，对该科目金额大的公司，**建议先把它当作坏人对待**。

> 💡 **提示**：由于会计准则变化，阅读 2018 年之后的企业财报时，需自行将"其他应收款"中的"应收股利"和"应收利息"剔除后再观察。

### 3.3 预付账款

⚠️ 需重点关注两类异常：

- 预付账款大幅增加，尤其是**预付工程款、预付专利或非专利技术采购款**大幅增加——可能通过预付款流出资金，最终以营业收入回流，虚增利润
- 预付账款**挂账时间长**——超过一年的预付款大概率有问题。因为金钱有时间价值，现实中很少有商人在不急需提货的情况下，提前很久支付预付款。

### 3.4 应付账款和应付票据

应付账款和应付票据，通常是公司需付给上游供货商的款项。这两个科目数额大增，有两种截然相反的解读：

| 可能原因 | 含义 |
| :--- | :--- |
| 公司在商业链条上地位大增 | 对供应商更加强势（正面） |
| 公司资金链出问题 | 开始拖欠供应商货款（负面） |

💡 具体属于哪种，需结合对公司和市场的了解判断。至少应通过网络搜索，看看有无该公司供应商拉横幅讨债之类的新闻或信息。

### 3.5 存货

以下情形提示可能存在财报操纵：

- 存货（尤其是**数量和价值不易确定**的存货）大幅增长，且增幅超过同期营业成本增长
- 存货周转率显著低于同行水平，并呈下降趋势

可能的操纵手法包括：

1. 虚构存货采购流出资金，最终化装成销售收入返回
2. 单纯加大生产，利用更多产品平摊固定成本，降低本期销售产品成本，虚增利润
3. 存货积压却不计提存货跌价准备，虚增利润

⚠️ **存货周转率明显下降 + 毛利率显著上升**，通常是很明显的警示信号，基本可按大概率造假考虑。

**推理逻辑**：存货周转率下降表明产品滞销。若不采取措施，会因存货占用资金时间加长而提高成本；若采用降价或增加销售费用促销，则会导致营收下降或费用上升。这几种情况下，毛利率都应**下降**才对。因此毛利率不降反升，逻辑上存在矛盾。

### 3.6 在建工程

在建工程因**总值高、进度和造价难以准确界定**的特点，成为财报操纵者的"挚爱"。

⚠️ 在建工程大幅增加，尤其是与生产经营规模和发展规划不相适应地大幅增加，可能存在：

- 通过在建工程支出将资金转出，最终以销售收入面目回流，虚增利润
- 将本应当期从利润表扣除的费用打进在建工程成本，虚减费用、增加利润

💡 **普通投资者的判断角度**：从公司募集资金开始看，当初承诺的项目——

| 观察点 | 异常信号及可能原因 |
| :--- | :--- |
| 是否在预定时间内由在建工程转为固定资产 | 迟迟不转固：可能工程本身虚构，或已完工却为避免计提折旧而拒不转固 |
| 是否如期产生效益 | 未如期产生效益需警惕 |
| 是否不断追加资金 | 即便正常追加，也说明管理层规划时专业不足或过于乐观 |
| 刚转固不久是否又需大修或技改 | 通常是提醒注意的信号 |

### 3.7 长期待摊费用

长期待摊费用大增，通常是公司**不恰当地使用费用资本化手段**的信号。

### 3.8 无形资产和商誉

#### 3.8.1 无形资产

无形资产的采购，尤其是**专利或非专利技术的采购**，是向外转移资金的一种常见手段。

💡 该科目数额较大时，投资者需确认该技术是否与公司生产经营紧密相关（这要求真正理解该行业）。若不相关，则可能是操纵财报的手段。

#### 3.8.2 商誉

由于商誉**年年进行减值测试而无须摊销**的特点，备受企业并购爱好者青睐。商誉减值测试主观性很强，收购方通常喜欢：

- **压低**收购中可辨认资产的价值
- **做高**商誉的价值

如此可减少资产折旧、少产生折旧费用、增加利润；需要降低利润时，又可按需减值——**进可攻，退可守**。

⚠️ 如果公司经常收购并常产生大额商誉，投资者有必要尝试将商誉还原成资产，按资产折旧规则重新考虑公司价值。此外，做高收购商誉，还可能是与卖家合作，借此将投资活动现金流出转化为经营活动现金流入。

### 3.9 应付职工薪酬

通过应付职工薪酬的预提（尤其是**年终奖金、效益奖金**等非固定工资的预提）来平滑利润，是操纵财报的常见方法。其在财报上的双重特征为：

| 特征科目 | 表现 | 说明 |
| :--- | :--- | :--- |
| 应付职工薪酬 | 余额波动大 | 直接体现预提调节 |
| 递延所得税资产 | 数额增加很大 | 税务局不认可这笔职工薪酬 |

⚠️ 上述两种情况同时出现，预示公司存在用应付职工薪酬调节年度间利润的可能。

### 3.10 坏账准备

⚠️ 明显的财报操纵信号：

- 坏账准备计提比例**显著低于同行业竞争对手**
- 不考虑账龄因素，甚至不公布账龄结构，只按某固定比例对所有应收账款和其他应收款统一计提坏账准备

💡 投资者尤其需要注意：如果恰好知道某欠款单位已明显不可能归还欠款（例如破产，或虽未破产但已资不抵债），而上市公司仍未对该笔应收账款计提 100% 减值，就需怀疑该公司**所有**应收账款都可能存在少计坏账准备的问题。

## 四、财报以外的信号

除财报本身的信号外，还有些外部信号也能帮助识别危险公司。常见的警惕信号包括：

| 类别 | 具体信号 |
| :--- | :--- |
| 信息披露 | 无法按时发布财报 |
| 审计机构 | 更换甚至再次更换会计师事务所（国资委要求的定期更换除外） |
| 股东行为 | 控股大股东持续大量减持公司股票 |
| 高管变动 | 财务总监频繁更换；独立董事集体辞职 |
| 交易对手 | 主要供应商或客户可疑（执照未年审、注册地在居民楼、虚假注册地、税务资料缺失等） |
| 并购行为 | 经常跨行业玩收购，且主要依赖发行股票支付收购款 |

---

## 五、总结

以上要点和技巧，应能过滤掉大部分问题企业。若再叠加你对公司商业模式及行业地位的熟悉，骗子想骗你就不是一件容易的事。

> 💡 **核心心法**：资本市场里，欺诈与反欺诈是永恒的话题。只要牢记 **"事反必妖"**——无论突然出奇地好，还是突然出奇地坏，都需探索背后的解释。如果没有可靠的解释，就必须从**收入、费用、现金流**等角度考虑是否存在欺诈可能。如此，方能在市场里长久地避开陷阱。
