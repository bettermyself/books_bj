# 读财报检查清单

> 依据《手把手教你读财报》读书笔记整理。按实际阅读顺序编排：先做排除性筛查，再逐表逐科目核查，然后算指标、读附注、做估值，最后过一遍造假信号。所有阈值/公式均为书中原始标准，多数判断强调"连续数年"而非单年。

---

## 〇、前置准备与整体框架

- [ ] 使用**合并报表**分析（母公司报表除个别科目外观察价值低）；每股指标、盈余公积等仍看母公司口径
- [ ] 优先看**资产负债表**（高手更关注它），三表结合相互印证
- [ ] 牢记权责发生制是造假温床：未收的钱可能记为本期收入，未付的钱可能记为本期成本
- [ ] 纵向做历史对比（观察周期**至少 5 年**），横向做同行业对比
- [ ] 秉持"疑罪从有 / 事反必妖"：出奇地好或坏都要找解释，无可靠解释即回避
- [ ] **核对各定期报告披露时间与分析口径**：一季报须在 4 月底前且不得早于年报；半年报 8 月底前；三季报 10 月底前；信息详细度年报 > 半年报 > 季报，年报必须经审计，分析以年报为准、季报与半年报仅作跟踪
- [ ] **按重要程度分配阅读精力**：必读三节：财务会计报告、董事会报告、重要事项；次要推荐两节：股份变动及股东情况（看股东结构变化）、董监高和员工情况（看高管任职与薪酬）；其余释义、公司简介、治理、内部控制等可略读
- [ ] **识别借壳上市公司**：公司经历反向收购（法律收购方 ≠ 会计收购方）时，合并表以被借壳资产为会计主体；合并表股本是调节后的「虚拟股本」（如真实 2.91 亿 + 虚拟 0.42 亿 ＝ 3.34 亿），现实中不存在，无观察价值，股东权益其他项也不宜直接解读
- [ ] **借壳公司每股指标的分母**：每股净资产、每股收益都以母公司资产负债表的真实股本为分母，勿用合并表股本；其余阅读方式与普通公司无区别
- [ ] **合并表减母公司表看子公司层面**：除长期股权投资外，合并表各科目 − 母公司表对应科目 ＝ 子公司层面的资产或负债；母公司表的长期股权投资仅反映投资成本，看不出子公司真实规模
- [ ] **差额反推隐含信息**：存货差额可视为子公司已购入未售出的货，再按毛利率换算市价规模：差额 ÷（1 − 毛利率）（原文例：茅台 2013 年 2.66 亿 ÷ 7% ≈ 38 亿元市价的酒）；货币资金差额大则看子公司资金能否被母公司调用

## 一、排除性筛查（审计意见 + 重要提示）

- [ ] 核对审计意见为**标准无保留意见**；保留意见 / 无法表示意见 / 否定意见 → **直接排除**
- [ ] 三处查找审计意见：年报第 1 页《重要提示》、"财务会计报告"开头、审计报告"审计意见"部分
- [ ] 确认无控股股东及关联方非经营性资金占用（应为"否"）
- [ ] 确认无违规决策程序对外提供担保（应为"否"）
- [ ] 重视独立董事 / 监事的任何异议、特殊声明或提醒
- [ ] 对"预计、计划、我们将……"等前瞻性陈述不视为承诺

## 二、资产负债表 — 逐科目核查

### 货币资金
- [ ] 核对现金及现金等价物（剔除受限资金）与现金流量表期末余额对应
- [ ] 确认与短期债务、经营需要相匹配：过小 → 偿债不足；过大 → 运用能力弱或性质有问题
- [ ] **反常信号**：① 货币资金远小于短期负债（偿债危机）；② **存贷双高**——资金充裕却借高息负债（大概率虚构/挪用/被冻结）；③ 定期存款/其他货币资金巨大却缺可动用流动资金；④ 其他货币资金巨大且无合理解释；⑤ 利息收入显著低于存款利率（资金可能只在报表日短暂停留）
- [ ] 警惕控股股东"集团资金管理协议"归集资金池
- [ ] 检查**货币冗余**：账面留存数倍于投资支出及分红所需现金 → 运用能力低下，估值扣分
- [ ] 核对受限资金明细（准备金、冻结、质押、保证金）——不能随时支取的不算现金等价物；股票不算
- [ ] **辨析定期存款能否算现金等价物**：约定到期才能支取的不算；仅需提前通知即可支取的可算，注意「双方都同意不会实施的通知」条款会改变资金性质；金融机构法定准备金受限、超额准备金可随时支取（算现金等价物）；其他受限类型还有合同约定最低存款余额、公司信用卡账户存款、各类票证保证金、保险公司资本金存款

### 应收票据 / 应收账款 / 应收款项融资
- [ ] 看应收票据占营收比例与构成：全为银票 = 强势；含大量商票 = 靠宽松销售政策；一贯银票突然大量商票 = 遭遇销售困境
- [ ] 收款条件优劣排序：现金 > 银票 > 商票 > 应收账款
- [ ] 检查应收账款是否异常增长（放宽信用或提前/虚构收入）
- [ ] 计算**应收账款周转率** = 营业收入 ÷ 应收账款平均余额〔(期初+期末)÷2，建议含商票〕；营收增长而周转率下降 = 放松政策（警惕）
- [ ] 检查是否有很大部分（如**超三成**）为一年以上应收款 → 质疑收入真实性
- [ ] 查坏账准备计提标准并与同行对比（常见：1 年内 5% / 2-3 年 30% / 5 年以上 100%）；计提越严越可信
- [ ] 警惕计提政策变更：宽松突转严格（疑"洗大澡"备转回）；严格突转宽松（美化当年利润）
- [ ] 检查前五名应收账款单位是否集中于关联企业、是否有持股 5% 以上股东欠款
- [ ] **警惕应收账款造假的「高级手法」**：低级手法是把应收换成预付款 / 存货 / 其他应收款；高级手法是收回应收款后，再经在建工程、购买无形资产、长期股权投资等流出资金，靠摊销或减值「毁尸灭迹」——识别窗口：款项收回前后是否新增金额近似、时间相近的异常支出

### 预付账款
- [ ] 判断地位：经常预付大量款 = 产业链地位低 / 信用差
- [ ] **数量异常**：预付工程款 / 专利技术采购款大幅增长 → 疑资金流出再回流虚增利润
- [ ] **时间异常**：长期挂账（超一年）→ 疑以采购名义挪用资金
- [ ] 跟踪历年预付款占营收 / 营业成本比例，大幅波动无解释需防雷

### 其他应收款 / 长期应收款
- [ ] 检查"其他××"科目金额：优秀公司应很小甚至为零；金额大先按"经营不规范"看待
- [ ] 警惕被用于隐藏短期投资、转移资金给大股东、私设小金库、隐藏利润费用
- [ ] 若企业自身缺钱却容忍大量其他应收款 → 直接怀疑造假
- [ ] 2018 年后需先剔除并入的应收股利、应收利息再判断金额
- [ ] **识别长期应收款的两类来源**：融资租赁应收款；递延方式分期收款（有明确利息，或买方付款总额明显超过商品公允价值）。后者实质是「卖货收全款现金后再把钱借出去」，对应对方的长期应付款——按出借资金看待其信用风险与回收性
- [ ] **新租赁准则下的口径变化**：新租赁准则施行后，承租方不再区分经营 / 融资租赁，原长期应付款中的融资租赁部分改列租赁负债；对比新旧年报时先还原口径

### 存货
- [ ] 确认按**成本与可变现净值孰低**计量；明显贬值存货是否故意不计提跌价准备
- [ ] 关注高贬值风险行业（生鲜、高科技制造、过期食品饮料）
- [ ] **造假信号**：① 存货增长大幅超过营业成本增长且账面价值显著高于同行（疑虚构采购流出资金）；② 靠加大产量 + 加权平均法降低单位成本欺诈性提升毛利率
- [ ] **存货周转率明显下降 + 毛利率显著上升 = 高概率造假**（滞销本应毛利率下降，逻辑矛盾）
- [ ] 计算**存货周转率** = 营业成本 ÷ 存货平均余额；结合产品特性（易贬值应高周转，茅台可低周转）
- [ ] **拆解存货结构（原材料 / 在产品 / 半成品 / 库存商品）**：增长主要来自在产品、半成品，且出厂价远高于成本、存货不贬值（如酒类陈酿）时，属蓄水式增长而非积压；增长集中在库存商品且销量下滑才是滞销信号
- [ ] **核对产销存三数勾稽**：生产量 − 销售量 ≈ 期末库存量 − 期初库存量；三数均为成品口径，库存量对应存货「库存商品」；库存增速明显快于销量 = 滞销预警，产销严重背离需找解释
- [ ] **确认存货发出计价方法**：财报搜「存货的计价方法」；个别计价法最准确、适用大件商品；先进先出只是核算假设；加权平均法（期末一次 / 移动）下本期产量直接进入本期销售成本，企业可借改变产量调节利润——用加权平均法者须重点防「加大产量摊薄固定成本」（茅台为移动加权平均）
- [ ] **识别「多生产摊薄固定成本」型利润美化**：信号组合：产量远大于销量、库存商品堆积、单位成本下降、毛利率上升而与同行成本无同步变化；原文案例：固定成本 1000 万不变，产销 1 万件改为产 2 万销 1 万，单件成本 2000 → 1500 元，毛利率 50% → 62.5%，毛利润 +500 万——利润来自把固定成本搬进库存，不是真降本；固定成本占比低的行业也不能放过（某白酒企业 2014 年半年报案例）；这类利润以存货增加和当期多缴税为代价，后续有存储成本、减值、过时归零风险，须跟踪是否出现大额存货减值
- [ ] **毛利率上升先归因再下结论**：① 旺销 / 提价（产品竞争力）；② 同行业有近似幅度的成本下降；③ 两者都不成立而库存同时增加 → 警惕欺诈

### 生产类资产
- [ ] **固定资产**：查折旧政策，警惕突然变更；识别账面归零但实际增值资产（大坝、酒窖、城区房产）；警惕"先减值后出售"（成交价显著高于账面）；减值一经计提不可转回
- [ ] **在建工程 / 工程物资**：警惕数额巨大持续多年不转固（避折旧或虚构工程转移资金）；投入增加但进度停滞
- [ ] **无形资产 / 开发支出**：查研发资本化 / 费用化倾向（全费用化更可靠）；外购价格是否公平；减值不可转回
- [ ] **商誉**：关注爆雷风险；警示——商誉占收购对价超高（如 **90% 以上**）、仅笼统称"未减值"无详细信息；经常收购产生大额商誉时应还原重估
- [ ] **长期待摊费用**：数字越大资产质量越差（无变现价值，用于减费增利）
- [ ] **生物资产**：对农林渔牧格外警惕（蓝田案），警惕"先减值后转回"；造假高发行业共性（税收优惠多、产品难核查、无价格参照）
- [ ] **融资租赁判定五标准（出租方）**：专用性、期满转移所有权、优惠购买选择权、租期 ≥ 资产寿命 75%、租金折现值 ≥ 公允价值（实务 ≥ 90%）；承租人在新租赁准则下已不区分

### 投资类资产
- [ ] 先看分类（决定对利润表影响）：交易性金融资产涨跌计入当期损益，可供出售 / 其他权益工具不计入
- [ ] 查可供出售金融资产减值判断标准（常见自设：累计跌幅超成本 20%~50% 为"严重下跌"，连续跌超 12 个月为"非暂时"）
- [ ] 长期股权投资：辨明控制 / 重大影响（持股 20%~50%）/ 无重大影响的分类
- [ ] **股权投资雷区**（利益输送高发）：大额减值 + 次期卖出、伪装非同一控制收购创造利润、控制权临界点反复小额交易、金融资产↔联营临界点小额增持伴大额投资收益、拆分一揽子减持
- [ ] 递延所得税：对股东有利的是递延所得税负债（税务局无息贷款）；两者不能互抵
- [ ] **交易性金融资产的归类规则**：按持有意图归类，归入后不得转出；衍生工具必须归入此类；交易费用直接费用化；公允价值变动计入利润，会经市盈率倍数放大股价涨跌，税法上仅在卖出时确认
- [ ] **投资性房地产的模式约束**：公允价值模式须同时满足：所在地有活跃交易市场、能获取同类房产市场价格；一家公司只能选一种模式，不能部分成本部分公允；公允价值模式不可转回成本模式；沪深房企多用成本模式，港股多用公允价值模式

### 负债
- [ ] 对负债依次追问：为何借？向谁借？借多久？利息几何？
- [ ] 计算**有息负债率 = 有息负债 ÷ 总资产**；**≥60% 属激进**，只与同期同行比
- [ ] 区分融资性负债（有息）与经营性 / 分配性负债（无息）
- [ ] 检查应交税费与经营规模匹配（可次年 5 月 31 日前汇算清缴属正常）
- [ ] 预计负债：关注对外担保、未决诉讼、产品质保、亏损合同
- [ ] 对净利率低、员工多的公司，测算工资上调多少比例会由盈转亏
- [ ] **专项应付款与递延收益**：专项应付款是政府给的专项资金、无须偿还，属良性负债；递延收益是已收到或应收到的政府补助，与资产相关的分期摊入损益——两者均不属有息负债，计算有息负债率时应剔除，并与「其他收益」口径交叉核对
- [ ] **长期借款 / 债券一年内到期的重分类**：距到期不足一年须转入「一年内到期的非流动负债」，评估短期偿债压力时须把它算进去
- [ ] **顺手核对现金对有息负债的覆盖**：算完有息负债率即对照——货币资金 ÷ 有息负债应能覆盖（见「资产负债表速读」比值 Ⅲ）；保守口径：现金及现金等价物 ÷ 有息负债 ≥ 1（见 8.1 现金债务比）

### 所有者权益
- [ ] 记住未分配利润 ≠ 可分配现金、≠ 现金余额（查现金看"货币资金"）
- [ ] 分红上限按合并与母公司报表中**较小的未分配利润**确定
- [ ] 法定盈余公积按**母公司净利润 10%** 计提，累计超注册资本 50% 后可停提
- [ ] 辨析"其他权益工具"（本公司发行，权益）与"其他权益工具投资"（投资他公司，资产）
- [ ] **警惕大额现金分红陷阱**："先大额分红再巨额融资"——分红降净资产抬高 ROE 满足再融资 / 股权激励门槛
- [ ] **股权激励 2016 新规核对**：激励期不短于 1 年、不长于 10 年；全部有效期内激励总额不超过股本 10%，个人累计不超过 1%（股东大会特别决议除外）；限制性股票授予价不低于草案公布前 1 日均价或前 20 / 60 / 120 日均价之一的 50%（取较高者）；期权行权价不低于前 1 日均价或前 20 / 60 / 120 日均价之一（取较高者）；授予日到首次解除限售 / 可行权日 ≥ 12 个月，每期间隔 ≥ 12 个月，每期解除 / 行权比例 ≤ 50%；禁止对激励对象提供贷款、担保等财务资助；激励费用按服务期分摊计入成本费用
- [ ] **「其他权益工具」与金融负债的分类标准**：看企业有无强制交付现金的义务、持有人是否分担经营 / 股价风险、用可变数量还是固定数量的股权交换；分类决定永续债、优先股算负债还是权益，直接影响有息负债率
- [ ] **资本公积与每股净资产**：归属于母公司所有者权益是每股净资产的分母；资金使用自由度：未分配利润 > 盈余公积 > 资本公积 > 注册资本，抽逃注册资本属刑事犯罪

### 资产负债表速读（四个关键比值 + 三视角）
- [ ] **生产资产 ÷ 总资产**：判断轻 / 重公司，优选轻资产（生产资产 = 固定资产 + 在建工程 + 工程物资 + 无形资产中的土地）
- [ ] **轻重比值 = 税前利润总额 ÷ 生产资产**，显著高于社会平均资本回报率（≈ 12%）为轻公司
- [ ] **应收款 ÷ 总资产**：**超 50% 明显有问题，超 30% 已属严重**；增幅不应超过营收增幅
- [ ] **货币资金 ÷ 有息负债**：应能覆盖（可放宽为 货币资金 + 交易性金融资产 + 应收票据 ≥ 有息负债）；刚性标准，无须与同行比
- [ ] **非主业资产 ÷ 总资产**：判断是否专注主业
- [ ] 观察各比值历史趋势与竞争对手同期：趋同 = 行业共识；迥异 = 战略分歧，藏机会或陷阱

## 三、利润表 — 逐科目核查（速读四要点：营收 / 毛利率 / 费用率 / 营业利润率 + 现金验证）

### 营业收入
- [ ] 确认呈"过去、现在、未来预计"三重增长；对比增速是否高于行业平均
- [ ] 判断增长来源可靠性：潜在需求增长（最可靠）＞市场份额扩大＞价格提升（最弱）
- [ ] 首读该公司时搜索"满足以下条件时确认"，查收入确认原则（核心：所有权风险报酬转移，与是否收款无关）
- [ ] 对采用"完工百分比法"的劳务 / 建造企业提高警惕（成本估算掌握在公司手中）
- [ ] 检查前五大客户营收占比，评估大客户依赖度
- [ ] 对主业涉猎特别广泛的公司打价值折扣（多元化易变"多元恶化"）
- [ ] **新收入准则五步法与细则**：识别合同 → 拆分单项履约义务 → 判断时点还是时段 → 分摊交易价格 → 履行时确认；「某一时段」履约义务三种特征：在客户场地建造、建造客户专用资产、常规重复服务，可按投入成本比例确认（成本估算空间仍在）；已收订单对价而未交付计「合同负债」；多重履约义务按各项单独售价占合同总价比例分摊总价与折扣——对一次性销售影响不大，对未完工劳务 / 建造合同影响明显

### 毛利率
- [ ] 计算毛利率 = (营业收入 − 营业成本) ÷ 营业收入
- [ ] 按阈值评判：**≥40%**（通常有持续竞争优势，优先）；20%~40%（高度竞争，谨慎）；**<20%**（竞争激烈利润极薄）
- [ ] 与同行比较——比同行高很多的，要么业内强者，要么造假骗子
- [ ] 毛利率变化先定位原因（成本下降 or 售价上升），判断是否可信、一次性还是持续；口径需前后一致
- [ ] **毛利率提升本应伴随应收账款减少 + 应付账款增加**；若反向 → 造假嫌疑
- [ ] **毛利率变化的三种原因逐一验证**：高毛利产品造假 → 查销售结构是否被扭曲；提价 → 查市场状况证实或证伪；降本 → 对比同行财报

### 费用（三费 / 四费）
- [ ] 计算费用率：财务费用为正时 = (销售+管理+财务) ÷ 营业总收入；为负时 = (销售+管理) ÷ 营业总收入
- [ ] 以费用占**毛利润**比例评判：**≤30%**（优秀）；30%~70%（有一定优势）；**>70%**（关注价值不大）
- [ ] 检查管理费用增幅 ≤ 营收增幅，否则查明细
- [ ] 特别警惕连续数年小额净利润的公司用管理费用（折旧、摊销、计提）调控利润，累积后"洗大澡"
- [ ] 销售费用高 = 产品缺拉力靠营销推力、扩张风险高
- [ ] 研发费用按风险偏好取舍（高研发有专利到期 / 技术替代风险）
- [ ] **警惕研发费用单列带来的口径变化**：2018 年起研发费用单列、2019 年起自行开发无形资产的摊销也由管理费用移入研发费用——跨年比较管理费用增幅时须按同口径还原

### 营业成本 / 税金及附加
- [ ] 营业成本理解为本期从存货科目搬走的价值
- [ ] 搜索"税项"/"税率"确认主要税种；注意营改增后"营业税金及附加"改"税金及附加"、运输装卸费改计入营业成本
- [ ] **营改增的价内税 / 价外税口径**：营业税是价内税、增值税是价外税，营改增后营业收入与税金会同时降低——2016 年前后的收入、毛利率、税金同比不可直接比

### 资产减值损失（利润操纵重灾区）
- [ ] 视大额资产减值为"管理层自我打脸"（承认以前决策失误）
- [ ] 警惕调节手法：不提 / 少提（增当期利润）、多提（备以后转回）、超额计提（降后期折旧摊销）
- [ ] 该科目总体应很小；经常出现或正或负大额数字 → 警惕报表调控
- [ ] 区分新准则"信用减值损失"（应收款及债权投资）与"资产减值损失"（其他）
- [ ] **权益类金融资产减值转回的权益分支**：有公开报价的权益类可转回，但转回到资本公积 / 其他综合收益，影响股东权益而不影响利润；无报价的权益类不得转回

### 营业利润与三块单独损益
- [ ] 以**营业利润率**（营业利润 ÷ 营业总收入）的趋势为看利润表**最重要指标**，与同行对比
- [ ] 营业利润率上升时分析原因（售价 / 成本 / 费用），判断是否可持续、对手能否复制
- [ ] 关注"公允价值变动收益 + 投资收益 + 汇兑收益"三块，警惕主业外损益粉饰（可剔除后算"纯营业利润率"）

### 营业外收支与净利润
- [ ] 净利润 = 营业利润 + 营业外收支净额 − 所得税；营业外收支不可持续
- [ ] 营业外收支净额较大时，直接用**营业利润的 75%** 看待当年净利润
- [ ] 若利润主要经常来自营业外收支 → 基本可断定打扮报表，远离
- [ ] 只看合并报表"归属于母公司所有者的净利润"，剔除少数股东损益
- [ ] "其他综合收益"当作股东备忘录，与净利润相加得综合收益总额
- [ ] **计算扣非净利润占比**：扣除非经常性损益后的净利润 ÷ 归属于母公司净利润；显著偏低说明利润依赖营业外收入、政府补助、资产处置等非经常项，利润质量差（与「营业外收支占大头即打扮报表」互补）
- [ ] **区分计入利润与不计入利润的利得 / 损失**：计入利润的五项：资产减值、公允价值变动、投资收益、汇兑收益、营业外收支；不计入利润（进其他综合收益）的：可供出售金融资产公允价值变动、金融资产重分类差额、房地产转换差额、权益法下被投资单位其他权益变动份额、可转债权益成分——权益变动表中「其他综合收益」大额变动须追查来源，防好坏消息绕过利润表
- [ ] **所得税费用 ≠ 税前利润 × 税率**：所得税费用 = 当期所得税 + 递延所得税费用 + 以前年度所得税调整；差异来自纳税调整、5 年内亏损抵扣、递延所得税资产 / 负债；原书称投资者无须会算，仅在利润与税费明显不匹配时回查

### 利润与现金勾稽（跨表关键验证）
- [ ] 计算现金含金量 = 经营活动现金流净额 ÷ 净利润；持续 **≥1** 为佳，长期 **<0.8** 需警惕
- [ ] 记住净利润 ≠ 挣到钱；不产生现金却要实缴税款的"纸面利润"无法长久
- [ ] 例外：房地产行业不适用（卖期房必有大量预收款）

## 四、现金流量表 — 逐项核查

### 经营活动现金流
- [ ] 只看合并现金流量表
- [ ] 第一层：经营活动净额是否 **>0**（为负通常入不敷出，银行 / 控股公司除外）
- [ ] 第二层：与折旧摊销比较——小于零（需筹钱度日）/ 等于零（勉强维持）/ 大于零但小于折旧摊销（无更新能力）/ 大于折旧摊销（有成长性，越多越好）
- [ ] 警惕大量收票据后既不到期也不贴现、直接背书支付上游（流入流出都不体现）
- [ ] 用间接法观察净利润质量与差异原因
- [ ] **销售收现比长期远小于 1**：说明大量款项以应收账款形式被欠着，产品 / 服务缺乏竞争力，或需警惕虚增收入
- [ ] **读间接法的三类调整**：① 加回已扣除但未付现的费用：资产减值准备、折旧、摊销、资产处置报废损失；② 加回与经营无关的项目：财务费用、投资损失、公允价值变动损失；③ 调整经营性变动：递延所得税、存货、经营性应收应付——存货减少、应收减少、应付增加都会增加现金，经营性应付增加 = 额外拖欠成本
- [ ] **降税让利归属与含税口径**：利润表数据不含增值税，其他三表项目含税，勾稽须处理；降税后若不改含税出厂价，减少的税额变成营业收入

### 投资活动现金流
- [ ] 剔除短期理财滚动买入 / 到期干扰后判断趋势（为负 = 扩张；为正 = 收缩）
- [ ] 评估三点：① 是否在能力范围（慎跨行业）；② 回报率是否显著高于社会平均（贷款基准利率两倍估算）；③ 资金来源是自产现金还是筹资（偏好自产）
- [ ] 估算**自由现金流 ≈ 经营活动现金流净额 − 购建固定资产 / 无形资产 / 其他长期资产支付的现金**
- [ ] **注意几个「其他」类科目的口径**：「收到的其他与经营活动有关的现金」含除税费返还外的其他政府补助；「收到 / 支付其他与投资活动有关的现金」含关联方资金拆借；因被动稀释丧失对子公司控制而减少的货币资金记在「支付其他」；「汇率变动影响」通常按净增加额倒挤

### 筹资活动现金流
- [ ] 区分权益性（发行价反映价值预估）与债务性筹资（利率反映信用）
- [ ] **核对筹资中的超高利息或中间费用**：查「分配股利、利润或偿付利息支付的现金」与「支付其他与筹资活动有关的现金」明细；利息或中间费用显著偏高，可能意味着企业遭遇必须「江湖救急」的生存危机

### 现金流肖像（8 种组合，顺序：经 / 投 / 筹；须连续数年）
- [ ] `+ + +` 妖精型 → 无大规模投资计划则远离
- [ ] `+ + -` 老母鸡型 → 看是否低 PE、高股息率（值得拥有）
- [ ] `+ - +` 蛮牛型 → 考量项目前景 + 资金能否支撑到产生现金
- [ ] `+ - -` 奶牛型 → 经营流入 > 投资流出 + 不含分红的筹资流出（正 = 优质成长；负 = 随时变蛮牛）
- [ ] `- - -` 大出血型 → 坚决拒绝
- [ ] `- - +` 赌徒型 → 看项目前景 + 管理层品性
- [ ] `- + -` 混吃等死型 / `- + +` 骗吃骗喝型 → 先辨投资流入靠变卖家当还是此前投资分红，再看现金净增加额；不建议投资
- [ ] A 股（除科创板未盈利）经营现金流为负基本可认定处于衰退期

### 优质企业四组数据（须数年持续 / 累计；现金债务比见 8.1）
- [ ] ① 经营活动现金流量净额 > 净利润 > 0
- [ ] ② 销售商品提供劳务收到的现金 ≥ 营业收入
- [ ] ③ 投资活动现金流出 > 流入，且主要用于扩张而非维持
- [ ] ④ 现金及现金等价物净增加额 > 0（可放宽为排除现金分红后仍 >0）

### 勾稽验证
- [ ] 期末现金及现金等价物 = 期初 + 经营净额 + 投资净额 + 筹资净额 + 汇率变动影响，且等于资产负债表货币资金中的现金及现金等价物总额

## 五、财务指标分析

### 安全性（偿债能力）
- [ ] **流动比率** = 流动资产 ÷ 流动负债，理想值 ≈ **2**
- [ ] **速动比率** = (流动资产 − 存货) ÷ 流动负债，理想值 ≈ **1**
- [ ] **资产负债率** = 负债总额 ÷ 资产总额；**净资产负债率** = 负债总额 ÷ 所有者权益
- [ ] **利息保障倍数** = (利息总额 + 利润总额) ÷ 利息总额，越高越好
- [ ] **核心把关——现金债务比**：现金及现金等价物 ÷ 有息负债 **≥ 1**（保守者只用此一项）；放宽版含可迅速变现金融资产，或对一年内到期有息负债 ≥ 1

### 盈利能力
- [ ] **营业利润率** = 营业利润 ÷ 营业收入（最重要指标）
- [ ] **净利率** = 净利润 ÷ 营业收入（毛利率口径见 6.1 节毛利率）
- [ ] **净资产收益率 ROE** = 净利润 ÷ 平均净资产〔(期末+期初)÷2〕；巴菲特标准**只选 ROE 超过 20%** 的企业，用 5 年以上历史观察
- [ ] **总资产收益率** = 净利润 ÷ 平均总资产（同 ROE 下更高者更优、风险更小）
- [ ] 用 ROE 找**经济商誉**：ROE > 无风险收益率 → 有经济商誉，反之价值损毁；注意 ROE 与买入价格无关

### 成长性
- [ ] 计算营业收入 / 营业利润 / 资产 / 净资产增长率 = (本期 − 上期) ÷ 上期；区分同比与环比趋势

### 营运能力（周转率）
- [ ] **固定资产周转率** = 营业收入 ÷ 固定资产净值
- [ ] **总资产周转率** = 营业收入 ÷ 平均总资产
- [ ] **固定资产 / 总资产周转率怎么读**：固定资产周转率低 = 重资产（与比值Ⅰ交叉）；总资产周转率越高 = 资产运用能力越强，改善路径只有「提收入」或「降占用」两条；存货周转率的目标是在不断供前提下库存最小化，须先分存货是否贬值

### 杜邦分解
- [ ] **ROE = 净利率 × 总资产周转率 × 权益乘数**，识别驱动因素：高净利率（茅台模式，最优）/ 高周转（沃尔玛模式，依赖管理层）/ 高杠杆（银行模式，最脆弱）
- [ ] 用现金流量数据验证杜邦结果（杜邦体系不含现金流）

### 四步分析法（穿透式）
- [ ] 第一步浏览科目查异常：资产端看应收账款 / 应收票据 / 其他应收款 / 长期待摊费用是否超营收增长；负债端看应付票据 / 应付账款 / 其他应付款 / 短期借款；利润表看营业利润率、(公允价值变动+投资收益+资产减值损失)占营业利润比重、营业利润与净利润比例是否稳定；异常必须在附注找到可信解释
- [ ] 第二步历史分析：观察 ≥5 年 ROE；留意**上市当年 ROE 通常较上市前 3 年均值下跌超 50%** 且难恢复
- [ ] 第三步利润与现金流趋势对比：理想状态经营活动现金流净额 ≥ 净利润
- [ ] 第四步与竞争对手比较（营收增速、资产负债结构、收入费用占比）
- [ ] 验证收入真实性钩稽：销售商品收到的现金 ≈ 含增值税营业收入 ± 应收 / 预收变动；偏差大时到附注搜"背书"，加回后仍不平且无解释则营收真实性存疑
- [ ] **用会计恒等式倒推造假落点**：资产 = 负债 + 所有者权益 + 收入 − 费用；利润虚增必落在资产（应收 / 存货 / 固定资产，约 90%）或负债（虚减，约 10%，需债权人配合、难度大）；负债无合理解释地异常减少同样要警惕
- [ ] **追问利润为何没变成现金**：净利润总量与经营现金流净额总量应保持大致稳定的比例；利润好而现金差时，要么纸面富贵（应收 / 存货堆积），要么走向资金链断裂，再按现金流肖像（7.4）归类
- [ ] **把增速放到行业坐标里判读**：营收 +20% 而行业 +50% = 份额流失、优势消退；资产负债结构趋同看行业共识；收入费用占比偏离同行，用来评估管理层是否称职

## 六、附注 / 权益变动表 / 董事会报告 / 重要事项

### 附注（约占财报 70% 篇幅，必读）
- [ ] 重点细读"合并报表项目解释"和"母公司财务报表主要项目解释"
- [ ] 首次细读会计政策 / 估计 / 前期差错，后续关注变化；经常有差错的企业警惕
- [ ] 查合并范围及变动；可反推子公司净资产 = 少数股东权益 ÷ 少数股东持股比例
- [ ] 审查**关联交易**：价格是否公平、是否产生大额应收 / 高额预付、是否有风险巨大的关联担保、是否确有必要（关联交易占营收**超 30% 重点核查**）
- [ ] 关注金融工具风险披露与公允价值披露
- [ ] **日后事项分类处理**：调整事项（报表日前已存在、日后才获知）已改报表数，查是否涉及利润 / 减值调整；非调整事项（日后新发生）仅披露，查是否有大额诉讼、并购、重组、大额亏损、分红预案——其负面影响不在报表数字里，须自行折算
- [ ] **股份支付**：查授予对象和规模、行权 / 解锁条件（工作年限、业绩考核难度）及费用摊销对利润的影响；业绩条件过松 = 福利化
- [ ] **或有事项：确定的负面信息是否被藏在附注**：对照预计负债科目，金额可估计、败诉概率大却仅附注披露 = 隐藏负债；正面或有事项（未来可能收钱）不可计入价值
- [ ] **关联方名单与披露要素**：先核对关联方名单是否完整（含母公司系、共同投资方、高管及家属控制的公司），再逐笔看交易内容 / 定价机制 / 付款条件，与历史关联交易及同行对比
- [ ] **用附注自算分产品 / 分地区毛利率**：看高毛利产品占比升降、海外占比变化，前五名客户占比同看；发现数据异常先到会计政策 / 估计说明找原因，政策或税率变更须在董事会报告 / 重要事项有专项说明，无说明则存疑

### 所有者权益变动表
- [ ] 核对期末所有者权益 = 年初余额 + 净利润 + 其他综合收益 + 所有者投入/减少资本 − 分红
- [ ] 理解内部结转、盈余公积 / 一般风险准备 / 专项储备提取只改变内部存放不改变总量；只有**分红真正流出**
- [ ] **验证净利润与留存收益变动是否吻合**：净利润 ≈ 期末留存收益 − 期初留存收益 + 本期分红；差额大时回查盈余公积 / 未分配利润的其他变动项（会计差错更正、政策变更等）；重心在「归属于母公司」，少数股东权益随之同步变化

### 董事会报告
- [ ] 细读经营情况讨论分析、未来发展讨论分析（可靠性高于券商研报）
- [ ] 核对产销存数据；看客户集中度（前五名占比）
- [ ] **投资状况分析**（宝藏）：重点看募集资金使用（项目变更、计划 vs 实际、进度逐年对比）；未来成长股常为当前投资活动现金流净额为负
- [ ] 读经营目标与 **SWOT**，做纵向（与往年表述比）横向（与对手比）对比，用历史数据验证管理层预判准确性
- [ ] **通读投资状况分析的另三块**：对外股权投资总体（本期 vs 上年）；非金融类公司的委托理财及衍生品投资（规模是否与主业匹配、是否不务正业炒理财）；主要子公司 / 参股公司的收入利润（是否有拖累或贡献集中）
- [ ] **募集资金变更与计划 vs 实际的判读**：变更原因是适应变化还是「收钱变脸」（评估管理层品性）；计划与实际投资金额差异过大 → 对管理与专业能力打折；多次变更用途 → 减分
- [ ] **累计数相减还原当年产出**：项目进度类累计数据，用本年累计 − 上年累计还原当年产出，再算投入产出比，判断产能释放节奏与产品工艺差异
- [ ] **读主营业务分析表与非法定披露数据**：对比收入 / 成本 / 费用 / 现金流变动比例，重点看费用增速是否显著超过营收增速、现金流三类净额与利润是否匹配；留意仅在此处披露的数据（产销存、客户集中度、产能、在建项目）；利润分配或转增预案粗略浏览近三年
- [ ] **管理层行业判断只作参考**：用龙头提价 / 出厂价调整、供不应求、库存与渠道价等先行信号交叉验证；管理层口径的转变往往滞后实际拐点一至两年
- [ ] **核对业绩预告**：应预告情形：预计全年亏损、扭亏为盈、净利润同比增降 ≥ 50%（深市另有期末净资产为负、年度营收 < 1000 万元）；应预告而未预告是警示；预告与年报差异过大要追问；上年同期基数小可申请豁免属正常，不必误判为隐瞒

### 重要事项
- [ ] 通读 11 项披露（重大诉讼、资金占用、破产重整、资产交易、股权激励、关联交易、合同履行、承诺履行、聘任解聘会计师、处罚整改等）

## 七、估值

- [ ] **现金流折现法（DCF）**：企业价值 = 剩余存在期自由现金流折现值；逐笔算数年自由现金流 → 其后估永续价值（= 自由现金流 ÷ (折现率 − 永续增长率)）→ 全部折现加总；市价低于评估价值时回报更高，保守者按折扣（安全边际）买入；仅适用现金流可预测的成熟企业，不适用初创 / 科技企业，只求大致估算
- [ ] **清算价值法**（格雷厄姆，悲观）：锁定市值远低于有形资产账面净值的企业；有形资产净值 = 总资产 − 总负债 − 无形资产 − 商誉
- [ ] **股市价值法**：选可比公司，按市盈率（每股收益）/ 净资产倍数（每股净资产）/ 收入倍数（每股销售收入）估值
- [ ] 面向未来快捷估值：预测第 3 年每股净利润 × 市盈率 → 未来股价 → 按回报要求（如 3 年翻倍）打折确定买入价
- [ ] 估算增长率 / 永续增长率时防止过于乐观（茅台若年增 20%，到 2055 年营收将超全国 GDP，不现实）
- [ ] **先判断能否用 DCF**：产品变化小、需求稳定、有持续竞争优势才用；初创 / 科技 / 现金流不可预测的企业不要硬套，改用清算价值或股市价值法
- [ ] **DCF 结果做敏感性检验**：折现率、年增长率、永续增长率的细微变动会使结果差距巨大；保守与乐观两组假设各算一遍，只取大致区间；逐笔预测通常 5–10 年，其后合并为永续价值；自由现金流取「经营净额 − 购建长期资产支付的现金」（见 7.2）
- [ ] **把买入价换算成预期回报**：买入价 = DCF 估值 → 预期年回报恰为所选折现率，价格越低回报越高
- [ ] **清算价值法的局限**：正常市场中符合「市值远低于有形资产净值」的标的稀少，多在极端悲观市场批量出现，不应为凑标的放宽标准
- [ ] **股市价值法的对照方式**：可对照目标公司招股说明书「发行价确定」部分核对可比公司

## 八、造假识别（危险信号清单）

### 收入造假痕迹
- [ ] 毛利率显著高于同行且同比大幅波动，排除"提价 / 降本"后仍无法解释
- [ ] 可疑交易对手：销售从未生产经销的产品、与从未出现的大客户大额交易、价格明显偏离市场
- [ ] 运费 / 装卸费增长显著低于收入增长且无解释、出口收入与海关费用反向变动
- [ ] 其他业务收入 / 营业外收入占比突然大幅提升无解释、利润主要来自偶然营业外收入
- [ ] 提前确认收入：一次性确认多年服务款、义务未履行即确认、房地产未交房即确认、无条件退货期内确认、向无付款能力客户延长信用期发货
- [ ] **虚假交易 / 自我交易（资金循环）**：资金经往来款、采购、预付款等名义转出，再经客户以销售回款形式回流；常借空壳或秘密控制公司；留意资产突然虚高、客户与资金去向对不上
- [ ] **显失公平的关联交易**：利润主要来自与控股股东 / 关联方的包销、代销、独家交易，公司几乎不增值却拿固定比例毛利，疑为输送利润
- [ ] **毛利率与其他收入的验证缺口**：毛利率提升须逐一验证高毛利产品造假 / 提价 / 降本；其他业务收入 / 营业外收入多年反复「偶然」发生，或收入在主营与其他业务间随意划转甚至一笔记两处，均须追问

### 费用造假痕迹
- [ ] 销售 / 管理费用占营收比例同比大幅降低且显著低于对手
- [ ] 金额较大的"其他××"科目、"重组 / 资产清理 / 商誉清理"等罕见科目名称
- [ ] "洗大澡"信号：减值损失同比大增而还原后利润波动不大
- [ ] 虚减费用手法：延长折旧摊销年限、漠视坏账、不当费用资本化、费用挂应收 / 预付、推迟在建工程转固
- [ ] **少计销售费用**：无票回扣提成挂预付款，再以其他款项打回冲销，查预付款挂账与回款是否异常
- [ ] **压低员工薪金或推迟正常费用开支**：阶段性降低人工成本、推迟正常经营管理所需费用以增加利润（可结合 12 节人均薪酬估算核对，警惕异常偏低）；外购固定资产推迟达到预定使用状态的时间以延迟折旧起点
- [ ] **「毁尸灭迹」型洗大澡**：盈一年亏一年交替、亏损后又扭亏，疑为冲掉以前虚增利润并规避 ST；固定资产 / 存货 / 应收 / 金融资产大幅计提减值乃至价值归零，或经常性费用归入一次性计提，均为信号
- [ ] **「自污」**：频繁出现会计差错更正 / 追溯调整以前年度报表，疑把当期费用以认错形式转入以前年度、美化当期

### 现金流造假痕迹
- [ ] 经营现金流净额持续优于同行但投资净额持续大额为负（疑将投资流出转为经营流入）
- [ ] "收到其他与经营活动有关的现金"突然增大又无可信解释（疑关联方打款美化）
- [ ] 投资支出超年初预算很多（疑临时救急，可核对《年度财务预算方案》）
- [ ] 借债利率偏高、高息借来资金却闲置、货币资金充足却高息借债
- [ ] **现金流量表三种造假情形**：短期挪用：控股股东 / 管理层期间挪用现金，报表日前归还；一次性美化；活动错配：把投资、筹资流入伪装成经营流入，或把经营流出伪装成投资、筹资流出；另有直接伪造银行收款单、询证回复函以虚构账面现金余额

### 资产负债表造假痕迹
- [ ] 应收账款增幅超收入增幅、周转率低于同行且明显下降
- [ ] 在建工程与经营规模不匹配大增、不按期转固、刚转固又大修
- [ ] 长期待摊费用大增、无形资产（尤其专利 / 非专利技术采购）
- [ ] 商誉：并购者压低可辨认资产做高商誉
- [ ] 应付职工薪酬余额波动大 + 递延所得税资产大增同时出现（疑用奖金预提平滑利润）
- [ ] 坏账准备计提比例显著低于同行、不分账龄按固定比例统一计提；已知欠款方破产却未计提 100% 减值
- [ ] **数量和价值不易确定的存货**：靠加大产量、以更多产品平摊固定成本降低销售成本；积压不计提跌价，均须结合周转率与毛利率交叉验证

### 财报以外信号
- [ ] 无法按时发布财报；更换（尤其再次更换）会计师事务所（国资委轮换除外）
- [ ] 控股大股东持续大量减持；财务总监频繁更换、独立董事集体辞职
- [ ] 主要供应商 / 客户可疑（执照未年审、注册地在居民楼、税务资料缺失）
- [ ] 经常跨行业收购且主要靠发行股票支付
- [ ] 核心心法"**事反必妖**"：突然出奇地好或坏都要找解释，无可靠解释就从收入 / 费用 / 现金流三角度考虑欺诈可能
