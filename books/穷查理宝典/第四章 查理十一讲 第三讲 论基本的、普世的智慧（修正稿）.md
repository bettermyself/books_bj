## 一、引言：普世智慧的必要性

### 1.1 持续学习的重要性

在今天的演讲中，我想进一步发挥两年前我在南加州大学商学院所讲的内容。你们手头有我在南加大演讲的讲稿，里面没有哪一点是我今天不会重复的，但我想扩展我当时说过的话。

**核心观点**：
- 如果沃伦·巴菲特从哥伦比亚大学商学院毕业之后没有吸取新的知识，伯克希尔将不可能取得现在的成就
- 沃伦从格雷厄姆那里学到的知识足以让任何人变得富裕
- 但如果没有继续学习，他将不会拥有伯克希尔·哈撒韦这样的企业

### 1.2 如何获得普世智慧

> 你们要怎样才能得到普世智慧呢？使用哪种方法能够让你们跻身于世上极少数拥有基本实践智慧的人士之列呢？

**答案**：在头脑里形成一个由各种**思维模型**构成的框架，然后将实际经验和间接经验（通过阅读等手段得来的经验）悬挂在这个强大的思维模型架上。

💡 **技巧**：使用这种方法可以让你们将各种知识融会贯通，加深对现实的认知。

## 二、跨学科思维模型

### 2.1 思维模型的框架

长久以来，我相信有某种方法——它是几乎所有聪明人都能掌握的——比绝大多数人所用的方法都有效。

**关键要求**：
1. 掌握各个学科的主要模型
2. 将它们统统派上用场
3. **不要理会学科的法定界限**

⚠️ **注意**：这个世界并不是按照跨学科的方法组织起来的。它反对跳出学科的法定范围。大规模的企业也是这样。学术界本身也反对这么做——我认为学术界错得有些离谱，功能失调。

### 2.2 专业化危险的警示

许多企业之所以会出现那些最糟糕的毛病、功能失调，是因为人们将现实分割为各自为政、互不相干的独立部门。所以如果你们想要成为好的思想家，就必须养成跳出法定界限的思维习惯。

**核心原则**：
> 你们不需要了解所有的知识，只要吸取各个学科最杰出的思想就行了。那并不难做到。

### 2.3 跨学科先驱：威廉·奥斯勒爵士

| 项目 | 内容 |
|------|------|
| **姓名** | 威廉·奥斯勒爵士（Sir William OsLer） |

| **国籍** | 加拿大 |
| **称号** | "现代医学之父" |

**奥斯勒的警示**：

**生平与成就**：
- 在魁北克蒙特利尔的麦吉尔大学求学和教书，获得医学学位
- 后来成为巴尔的摩约翰斯·霍普金斯大学的第一位医学教授

- 拥有杰出的**化繁为简**的能力

**查理最喜欢的奥斯勒名言**：

## 三、桥牌比喻：理解模型的综合运用

### 3.1 桥牌高手的必备技能

我打算用定约桥牌（的比喻）来证明这一点。假定你想要成为定约桥牌的高手：

**基本规则**：
- 如果你手里有大牌或者最大的王牌，那么你肯定能够成为赢家

**复杂情况的处理**：
如果你们手里有一套墩或者两张短套花牌，要怎样才能得到其他需要的牌墩呢？

| 技巧名称 | 说明 |
|---------|------|
| 做长套花牌 | 通过建立长套来获取额外赢墩 |
| 飞牌 | 尝试用较小的牌赢得一墩 |
| 扔牌 | 故意输掉一墩以获取更大利益 |
| 交叉将吃 | 利用将牌在不同手之间交替吃张 |
| 挤牌 | 迫使对手放弃关键牌张 |
| 误导防守方 | 通过各种方式诱导对手犯错 |

**关键结论**：
> 这些方法并不算多。但如果你们只懂得其中的一两种，那么你们肯定会一败涂地。

### 3.2 模型间的相互联系

此外，这些方法相互之间也有联系。因此，你必须懂得它们之间是怎样相互影响的。否则你就无法把牌打好。

### 3.3 正反两面思考

同样，我曾建议你们**正反两面都要考虑到**。优秀的桥牌庄家会想：

1. **正面思考**："我要怎样才能抓到好牌呢？"
2. **反面思考**："犯哪些错误会导致我手里全是烂牌？"

> 这两种思考方式都很有用。所以，要想在人生的赌局中获胜，你们应该掌握各种必要的模型，然后反复地思考。桥牌的哲理在生活中同样有效。

## 四、学术界的局限与自我教育

### 4.1 学术结构的缺陷

由于你们的学术结构大体上并不鼓励你们的思想跳出法定的学科界限，你们处于一种不利的地位。虽然学术对你们来讲非常有用，但是你们的老师没有教对。

### 4.2 小红母鸡的启示

我为你们设想的对策是我很小的时候在保育院学到的：**小红母鸡的故事**。

> 💡 **核心启示**："'那我就自己来吧'，小红母鸡说。"

**行动指南**：
- 如果你们的教授并没有教给你们正确的跨学科方法
- 如果每个教授都想过度地使用他自己的模式，对其他学科的重要模型弃之不用
- **你们可以自己改正那种愚蠢的做法**
- 他是个笨蛋，并不意味着你们也要成为笨蛋
- 你们可以向其他学科学习能够更好地解决问题的模型
- 只要养成正确的思维习惯你们就能做到这一点

### 4.3 马克·吐温的智慧

查理的自学建议遥遥呼应了马克·吐温的经典名言：
> "我从来不让上学影响我的学习。"

### 4.4 桥牌的文化意义

定约桥牌在你们这代人里不流行了，这真是悲剧。

| 对比 | 情况 |
|------|------|
| 中国 | 从小学就开始教桥牌，玩得比我们好 |
| 美国 | 不懂桥牌，却和一群精通桥牌的人竞争 |

> 要是他们也实行资本主义，天知道他们该发展得多好。如果我们美国人不懂桥牌，却和一群精通桥牌的人竞争，那么我们就又多了一个没必要的劣势。

## 五、商业案例分析

### 5.1 好时公司（Hershey）

**背景信息**：

| 项目 | 内容 |
|------|------|
| **创始人** | 密尔顿·赫尔希（Milton S. Hershey） |
| **生卒** | 1857—1945 |
| **出身** | 宾夕法尼亚州中部的农村地区，只受过很少的正式教育 |
| **成就** | 后来成了美国的大富豪 |

**创业历程**：
1. **1876年**：创办了兰卡斯特奶糖公司
2. **六年后**：公司倒闭
3. **不屈不挠**：重整旗鼓，获得了巨大的成功
4. **1893年**：掌握了制作巧克力的技术，创办了好时巧克力公司
5. **发展壮大**：开始生产其他食品，在宾夕法尼亚州建立了好时镇

**核心竞争优势——味道**：
- 好时巧克力的味道很独特
- 用来制造可可脂的石磨非常古老，是19世纪在宾夕法尼亚州开业时传下来的
- 巧克力含有少量的可可豆的外皮
- 因此好时巧克力的味道很棒，人们都很喜欢

**品牌保护案例**：
> 好时清楚地知道，如果他们想要把业务拓展到加拿大，那么就不应该改变那种无往不胜的味道。因此，他们依照原样制造了新的石磨。光是复制原来的味道，他们就花了整整**五年的时间**。

**结论**：味道是非常重要和关键的。

### 5.2 国际香料香精公司

现在还有一家叫作国际香料香精公司的企业。这是一家产品并没有获得版权或者专利权却又能够收取永久授权费的公司，据我所知仅有这一家。

**商业模式**：
- 帮助其他许多公司，为它们的各种品牌产品添加香料和香味
- 例如：刮胡膏——添加淡淡的香味能够极大地促进消费

**核心洞察**：
> 所以味道是极其重要的。

### 5.3 卡奈森公司（Carnation）

**历史背景**：

| 项目 | 内容 |
|------|------|
| **创立时间** | 1899年 |
| **创始人** | 杂货店主E. A. 斯图亚特（E. A. Stuart） |
| **技术** | 当时尚属新奇的脱水技术 |
| **地点** | 华盛顿州 |
| **原名** | 太平洋海岸浓缩牛奶公司 |
| **商标来源** | 当地一家烟草店的招牌"卡奈森" |
| **品牌联想** | "满意的奶牛"和高品质的牛奶制品 |
| **收购** | 1985年，雀巢公司收购了卡奈森 |

**商标价值的经典案例**：

从前有个人卖的鱼肉叫卡奈森鱼肉。老天爷，他的商标就叫卡奈森，所以卡奈森公司想收购他的品牌。

| 时间 | 报价 | 卖家要求 |
|------|------|---------|
| 第一次 | 25万美元 | 40万美元 |
| 四年后 | 100万美元 | 200万美元 |

> 他们就这样一直讨价还价。卡奈森公司一直没有把那商标买下来。

**巧妙的替代方案**：
> 最后，卡奈森公司的人无奈地去跟那个人说："我们打算派遣我们的质量检查员到你的鱼肉厂，以便确保你生产的鱼肉都是完美的，所有的费用我们来出。"那人笑逐颜开，很快就点头同意了。所以他的鱼肉厂得到了免费的质量管理服务——卡奈森公司的款待。

**商标的激励机制**：
> 这段历史让我们明白，如果你给某个家伙一个（他能够保护的）商标，你就创造了巨大的激励机制。这种激励机制对文明社会来说是非常有用的。

**卡奈森公司的声誉保护**：
> 正如你们看到的，卡奈森公司为了顾惜自己的声誉，甚至不惜去保护那些并不属于它的产品。

**微观经济学启示**：
> 这种结果（对整个社会）非常非常非常非常有好处。所以从非常基本的微观经济学原理来看，哪怕是共产主义国家，也应该保护商标。

## 七、心理学：最重要的缺失模型

### 7.1 心理学的重要性

在寻找普世智慧的过程中，我们已经讨论了几种主要的思想。现在我想回头来谈谈一种比刚才谈到的更加极端和特殊的模型。

> 在所有人们应该掌握却没有掌握的模型中，**最重要的也许来自心理学**。

### 7.2 史蒂芬·平克与《语言本能》

**作者信息**：

| 项目 | 内容 |
|------|------|
| **姓名** | 史蒂芬·平克（Steven Pinker） |
| **出生** | 1954年 |
| **出生地** | 蒙特利尔 |
| **教育** | 麦吉尔大学实验心理学系毕业，哈佛大学博士学位 |
| **教职** | 哈佛大学和麻省理工学院任教，现为哈佛大学心理学系约翰斯通家族讲席教授 |
| **研究领域** | 视觉认知、儿童的语言发展 |

**核心观点**：
- 平克说，人类的语言能力不仅仅是后天学来的——从很大程度上来说，它还跟先天的遗传有关
- 其他动物，包括黑猩猩，都缺乏真正有用的语言基因
- 语言是上天赐给人类的礼物

**与乔姆斯基的对比**：

| 学者 | 观点 | 芒格评价 |
|------|------|---------|
| **诺姆·乔姆斯基** | 语言能力是否基于人类基因尚无定论 | 犹豫确实有点不可理喻 |
| **史蒂芬·平克** | 人类得到语言本能的途径跟得到其他本能的途径完全一样——那就是达尔文的自然选择 | 资历较浅的教授明显是对的 |

**乔姆斯基犯错的原因**：
> 乔姆斯基的意识形态太过强烈。他虽然是个天才，却是个极端的平等主义左翼分子。他非常聪明，知道如果他承认这个达尔文理论，他的左翼意识形态就会受到威胁。所以他的结论自然受到他的意识形态偏见的影响。

## 八、意识形态偏见的危险

### 8.1 意识形态的警示

> 除了利用来自不同学科的多元思维模型之外，我还想补充的是，你们应该**警惕严重的意识形态偏见**。

**判断标准**：

| 情况 | 评价 |
|------|------|
| 把准确、勤奋和客观当成笃信的意识形态 | 那倒不要紧 |
| 因为受到意识形态的影响，而确凿无疑地相信最低工资应该提高或者不该提高 | 那么你们就变成了傻子 |

**复杂系统的思考**：
> 这是一个非常复杂的系统。生活总是环环相扣的。如果综合考虑，你们猜想提高或者降低最低工资会让整个社会变得更加文明，那是没有问题的。这两种想法都对。但如果你们带着强烈的意识形态把自己的观点当作不可动摇的真理，那么我认为你们的想法是很愚蠢的。

**最终警告**：
> 所以要警惕意识形态造成的思维紊乱。

## 九、心理学教材的缺陷

### 9.1 德摩斯梯尼的洞察

大约在基督出生之前三个世纪，德摩斯梯尼（Demosthenes）就说过：
> "一个人想要什么，就会相信什么。"

### 9.2 平克对心理学教材的批评

> "我看过许多心理学教材。都很烂。"他说："整个学科被搞得乱七八糟，教得也不对。"

**芒格的认同**：
> 说到心理学，我的资格远不如平克。实际上，我从来没上过一节心理学课。然而，我的结论跟他的差不多——许多心理学教材虽然不乏闪光之处，但大体上都是垃圾。

### 9.3 米尔格拉姆实验的误读

**实验背景**：
- 米尔格拉姆开展这个实验，是在希特勒命令许多虔诚的路德教徒、天主教徒去做他们明知道不对的事情之后不久
- 他想要发现权威在多大程度上可以被用来操控品德高尚的人，迫使人们去做一些明显错得很离谱的事情

**实验结果**：
- 他得到了非常具有戏剧性的实验效果
- 他设法让那些品德高尚的人做了许多可怕的事情

**教材的误读**：
> 但是许多年来，心理学教材把这个实验当做是对权威的作用的证明——权威如何被用来说服人们去做可怕的事情。

**正确的理解**：
> 当然，这是个似是而非的结论。这不是一种完整和正确的解释。权威发挥了一定作用。然而，还有其他几种朝同一个方向发挥作用的心理因素，它们造成了那种**lollapalooza效应**，原因恰恰在于它们发挥了组合作用。

**实验数据**：

| 项目 | 内容 |
|------|------|
| **实验者** | 斯坦利·米尔格拉姆（Stanley Milgram） |
| **出生** | 1933年，纽约 |
| **教育** | 皇后学院政治学学位，哈佛大学社会关系博士 |
| **教职** | 耶鲁大学 |
| **关键发现** | 65%的受试者（纽黑文地区的普通居民）愿意对一个发出抗议的可怜受害者施加明显有害的电击 |
| **原因** | 仅仅因为有个科学权威命令他们那么做，完全不顾受害者并没做过错事，不该受罚 |

### 9.4 检查清单的重要性

**聪明人为什么会犯错？**

> 答案是他们没有做我正要让你们去做的事情——**掌握所有主要的心理学模型，把它们当作检查清单，用来审视各种复杂系统的结果**。

**类比说明**：

| 职业 | 做法 |
|------|------|
| 飞行员 | 起飞前核对检查清单：A、B、C、D…… |
| 桥牌手 | 需要另外两张墩的时候迅速查对检查清单 |

**心理学教授的错误**：
> 但这些心理学教授认为他们聪明到不需要检查清单。可他们其实没那么聪明。几乎没有人那么聪明。或者换句话说，可能没有人那么聪明。

**清单的作用**：
> 如果他们使用检查清单，他们将会意识到米尔格拉姆实验利用的心理学原理至少有**六种**——而不是三种。他们必须去看检查清单，才能发现他们漏掉了什么。

**最终结论**：
> 同样道理，如果缺乏这种获得各种主要模型并以组合的方式使用它们的方法，你们也将会一而再、再而三地失败。

## 十、被忽视的心理学模型

### 10.1 心理否认

**问题**：心理学教授回避心理否认问题的原因之一在于，如果要做有关心理否认的实验，他们肯定会违反道德规范。

**巴甫洛夫的实验**：
- 巴甫洛夫本人在他生命的最后十年里一直在做对狗的酷刑实验
- 他发表了论文，我们拥有了翔实的资料，知道痛苦如何导致狗的精神失常
- 然而，你在任何心理学教材中都看不到巴甫洛夫这次研究的成果

**原因分析**：
> 我不知道这是因为他们不喜欢巴甫洛夫折磨狗，还是由于B. F. 斯金纳因为过度渲染而使用动物行为来推断人类行为的方法不受欢迎。总之，由于某些疯狂的原因，心理学教材对痛苦引起的精神失常着墨甚少。

**重要性**：
> 如果我的理论没有错，这种忽视抹杀了几个你们需要的模型。此外，你们对思想模型的掌握应该是这样的，如果有20个，那么你们就应该掌握20个。换句话说，你们不应该只用10个。你们要把它们当作一张检查清单。

**最终要求**：
> 所以你们必须了解各种导致人类作出错误判断的心理因素，把所有模型组织起来，以便需要的时候能够用得上。

## 十一、杰出人物的智慧

### 11.1 本杰明·格雷厄姆

**对沃伦·巴菲特的影响**：
- 沃伦有一位教授或者说导师，那就是本杰明·格雷厄姆
- 他对沃伦的影响很大

**格雷厄姆的学术成就**：

| 项目 | 内容 |
|------|------|
| **学术水平** | 学问很好 |
| **毕业邀请** | 从哥伦比亚毕业时，有三个不同学科的系邀请他去攻读博士课程并要求一入学就开始授课 |
| **三个系** | 文学系、希腊和拉丁古典系、数学系 |
| **性格** | 非常适合做学问，非常专注，非常聪慧，外表也像个学者，是个好人 |
| **对金钱的态度** | 对赚钱并不那么用心，但去世时家财万贯，总是非常慷慨 |
| **教职** | 在哥伦比亚当了30年穷教书匠 |
| **著作** | 独力或合作撰写了许多后来成为他那个学科最好教材的著作 |

**芒格的评价**：
> 格雷厄姆的性格非常适合做学问。我认识他。他特别像亚当·斯密——非常专注，非常聪慧。甚至他的外表也像个学者。而且他是个好人。

### 11.2 杰克·韦尔奇与沃伦·巴菲特

**阅读作业**：
- 杰克·韦尔奇和沃伦·巴菲特分别为通用电气和伯克希尔·哈撒韦股东撰写的最新年度股东信

**背景**：

| 人物 | 背景 |
|------|------|
| 杰克·韦尔奇 | 拥有工程学博士学位 |
| 沃伦·巴菲特 | 如果愿意，能够取得任何学科的博士学位 |
| **共同点** | 两位先生也都是资深的教师 |

**结论**：
> 如果你们认真研究的话，会发现普世智慧是一门相当高深的学问。不信你们看看通用电气取得的成就，看看伯克希尔·哈撒韦已有的业绩。

## 十二、核心总结

### 12.1 普世智慧的关键要素

| 序号 | 要素 | 说明 |
|------|------|------|
| 1 | **跨学科思维** | 掌握各个学科的主要模型，跳出法定界限 |
| 2 | **模型综合** | 理解模型之间的相互联系和组合作用 |
| 3 | **正反思考** | 既考虑如何成功，也考虑如何避免失败 |
| 4 | **检查清单** | 将模型当作检查清单使用 |
| 5 | **警惕意识形态** | 避免意识形态偏见造成的思维紊乱 |
| 6 | **持续学习** | 不断吸收新知识，像小红母鸡一样"那我就自己来吧" |
| 7 | **心理学模型** | 掌握所有主要的心理学模型，特别是被教材忽视的 |

### 12.2 最终忠告

> 如果你把自己训练得更加客观，拥有更多学科的知识，那么你在考虑事情的时候，就能够比那些比你聪明得多的人更厉害，我觉得这还蛮有意思的……

> 再说了，那样还能赚到很多钱，我本人就是个活生生的证据。
