# 在慈善圆桌会议早餐会上的讲话

> 📅 **时间**: 2000年11月10日  
> 🎯 **核心主题**: 股市财富效应、灰金理论与投资管理的深层问题

---

## 一、开场白：一个门外汉的经济学观察

### 1.1 坦诚的自我介绍

今天我要谈的是美国股市上涨带来的"财富效应"。

首先坦白三点：
- 我从未上过任何经济学课程
- 我不是学院派经济学家
- 我从未通过预测宏观经济赚到一分钱

### 1.2 核心观点

**尽管如此,我认为**: 那些拥有博士学位的经济学家**严重低估了**股市财富效应在当前极端情况下的威力。

💡 **核心启示**: 有时候,门外汉的视角反而能看到专家忽略的盲点。

---

## 二、股市财富效应的两大特殊性

### 2.1 什么是财富效应?

目前所有人都同意两个基本观点:

| 观点 | 内容 |
|------|------|
| **观点一** | 股价上涨 → 消费意愿上升<br>股价下跌 → 消费意愿下降 |
| **观点二** | 消费意愿对宏观经济至关重要 |

**但专家们存在分歧的地方**:
- 财富效应的具体规模有多大?
- 作用时机如何把握?
- 与其他经济因素如何互动?
- 股价上涨 → 消费增加 → 股价进一步上涨,这种循环如何量化?

⚠️ **复杂性**: 这些问题涉及复杂的数学谜题,远未像物理学理论那样被清晰解释。

### 2.2 当前情况的两大特殊之处

#### 特殊性一: 史无前例的涨幅

**现象描述**:
- 大量上市公司股价飞速上涨
- 股价上涨速度**远超**国民生产总值增速
- 这种情况前所未有

**结论**: 相关财富效应必然同样惊人。

#### 特殊性二: 日本的警示

**日本案例的冲击**:
- 过去10年日本经济的崩溃震惊了经济学界
- 人们极度担心财富效应反向作用引发的经济衰退

## 三、日本的前车之鉴

### 3.1 日本泡沫经济的轨迹

| 阶段 | 表现 |
|------|------|
| **上升期** | • 金融界腐败严重<br>• 股票和地产价格长期大幅上涨<br>• 实体经济增长强劲 |
| **破裂期** | • 资产价格急剧下跌<br>• 经济一蹶不振 |
| **应对期** | • 巨额财政赤字<br>• 利率接近零<br>• 各种凯恩斯政策和货币政策轮番上阵 |
| **结果** | **年复一年经济依然没有起色**<br>消费意愿对任何政策都无动于衷 |

### 3.2 日本案例的启示

💡 **换句话说**: 当资产泡沫破裂后,即使动用所有经济学教科书上的工具,也可能无法让经济恢复活力。消费者信心一旦崩溃,重建极其困难。

**对慈善基金会的影响**:
如果类似情况在美国发生,财富大幅缩水的慈善基金将会抱怨生不逢时。

**一线希望**:
有人认为日本的糟糕局面主要由其特殊的社会心理和腐败造成。我们应该希望这种说法正确,这样美国经济才有安全保障。

## 四、传统经济学分析的局限

### 4.1 专业经济学家的分析框架

基于美联储数据,专家们会这样分析:

#### 数据基础

| 指标 | 数值 |
|------|------|
| 家庭净资产增长(10年) | 不到100% |
| 股票市值占家庭净资产比例 | 不到1/3(扣除退休金后) |
| 最富1%家庭持股占比 | 约50% |
| 最穷80%家庭持股占比 | 仅4% |

#### 专家结论

假设每个家庭将其股票资产的3%用于消费:
- 过去10年持续的史无前例股价上涨
- 每年对消费支出的拉动**不到0.5%**

### 4.2 这种分析的根本缺陷

**我的判断**: 这种经济学思考与现实严重脱节。

**两大错误**:
1. 使用的数据不对
2. 提出的问题不对

💡 **核心启示**: 有时候,提错问题比算错答案更致命。

## 五、加尔布雷思的"黑金"理论

### 5.1 "黑金"概念的提出

> **人物介绍**: 约翰·肯尼斯·加尔布雷思(1908—2006)
> - 哈佛大学经济学系教授
> - 肯尼迪总统好友
> - 曾任美国驻印度大使
> - 著有《美国资本主义》《富裕社会》等经典著作

**"黑金"(bezzle)的定义**:
- 尚未败露的贪污中得到的金钱
- 与贪污相关的概念

### 5.2 黑金的消费刺激作用

#### 作用机制

**普通交易的情况**:
```
女裁缝卖衣服给鞋匠(20美元)
→ 鞋匠少了20美元可消费
→ 女裁缝多了20美元可消费
→ 总消费支出不变(零和游戏)
```

**黑金的情况**:
```
贪污者得到20美元
→ 贪污者花钱更大手大脚(因为钱来得容易)
→ 雇主支出一如既往(尚不知钱被偷)
→ 总消费支出增加(双赢假象)
```

💡 **换句话说**: 黑金创造了一种虚假繁荣——两方都觉得自己有钱花,但实际上只有一份钱存在。

### 5.3 凯恩斯乘数效应

类似政府印钞票购物:
- 卖家多得钱
- 没人觉得自己钱变少
- 产生乘数效应刺激消费

**结论**: 尚未败露的贪污所得,对消费的刺激效应大于同等规模的诚实交易。

### 5.4 加尔布雷思的局限

**他停下的地方**:
- 认为黑金不可能增长太大
- 大规模贪污迟早败露
- 吞掉的钱迟早要吐出来
- 私人黑金无法长期驱动经济

**他没有追问的关键问题**:
> ⚠️ **是否存在某种东西,起到与黑金相同的作用,但数额足够大,也不会短期内自我消亡?**

## 六、创新概念："灰金"与投资浪费

### 6.1 三个新造词

我像加尔布雷思那样生造几个词:

| 新词 | 含义 |
|------|------|
| **灰金** | 作用与黑金相同的东西 |
| **捞灰金** | 创造灰金的过程 |
| **灰金客** | 从事捞灰金的人 |

### 6.2 灰金的重要来源

**震撼性结论**: 一个重要的灰金来源就在这个房间里——**你们这些慈善基金会**。

#### 灰金产生机制

**假设场景**:
```
某基金持有大量普通股
→ 采用不明智的投资管理措施
→ 每年浪费3%资产在多余的、不带来收益的管理成本上
→ 股票投资组合正处于急速上涨阶段
→ 基金仍觉得自己变富裕了
→ 得到这3%的人(灰金客)认为钱是正当赚来的
```

💡 **核心启示**: 这种情况起到的作用与尚未败露的挪用公款几乎一样。

### 6.3 灰金的自我维持特性

**关键特点**:
- 可以自我维持很长时间
- 灰金客貌似消费自己赚来的钱
- 实际是来自股价上涨带来的隐蔽"财富效应"

### 6.4 对老派价值观的冲击

**传统观念**: 勤俭节约、避免浪费是美德

**经济学现实**: 非理性花销是成功经济的必要部分

这让老派价值观持有者既困惑又不安。

**术语引入**:
- **傻子消费**: 非理性花销
- **捞灰金**: 与挪用公款起相同作用的行为

⚠️ **重要声明**: 我不喜欢捞灰金,但我认为:
- 现在捞灰金行为很普遍
- 给经济造成重大影响
- 人们应该认清现实,即使不喜欢它
- **当不喜欢时,更应该认识清楚**

## 七、投资管理中的惊人数据

### 7.1 浪费远超3%

很多机构浪费的**远不止3%**。

### 7.2 共同基金研究的惊人发现

**研究数据**(15年期):

| 指标 | 数值 |
|------|------|
| 股票基金年均回报率 | 12.8%(扣除成本后) |
| 基金投资者实际年均回报率 | 7.2% |
| **差距** | **5.6%** |

💡 **换句话说**: 基金本身已经跑输市场,而投资者拿到手的收益又比基金本身少了5.6个百分点!

### 7.3 收益差的根源

**罪魁祸首**: 频繁更换投资经理

#### 恶性循环

```
解雇业绩落后的投资经理
→ 彻底清仓他们选中的股票
→ 聘请新投资经理
→ 给新经理施加巨大压力
→ 要求重新买进股票
→ 超快速卖出买进
→ 投资结果恶化
```

### 7.4 个人困扰

**我的烦恼**:
- 如实描述的现象太过可怕
- 人们往往认为我言过其实
- 新出现的情况比我描述的更可怕

> 怪不得芒格对现实的看法总是不受欢迎。这也许是我最后一次受邀向慈善基金会演讲。

## 八、股票期权：另一个灰金源头

### 8.1 股票期权的规模

**当前数据**:
- 美国所有公司职工股票期权总额: **7500亿美元**
- 总数不固定,但不停增长
- 旧期权不断变现,新期权不断加入

### 8.2 会计腐败助长灰金

**问题所在**:
| 现象 | 影响 |
|------|------|
| 标准会计规则不把股票期权当作公司成本 | 这是腐败的会计行为 |
| 职工股票期权引起的"财富效应" | 实际上是"灰金"效应 |

### 8.3 财富效应的真实规模

**计算基础**:
- 标准普尔指数每上涨100点
- 股市总值增加1万亿美元
- 再加上所有捞灰金行为的凯恩斯乘数效应

**结论**: 宏观经济的财富效应**比普遍认为的大得多**。

## 九、市场非理性与集体疯狂

### 9.1 股票的双重属性

**思考实验**: 退休金基金投资古代艺术品

#### 历史案例
英国某大型退休金基金:
- 买进许多古代艺术品
- 计划10年后抛售
- 10年后确实抛售,利润过得去

#### 极端假设

| 假设情景 | 后果 |
|----------|------|
| 所有退休金基金全部资产购买古代艺术品 | 给宏观经济带来糟糕结果 |
| 一半退休金基金投资古代艺术品 | 结果同样很糟糕 |
| **股票价值有一半是疯狂哄抬的结果** | **与上述情况一样可怕** |

💡 **核心启示**: 股票既有理性的一面(基于未来现金流估值),也有投机的一面(因为价格一直在涨而买入)。当投机属性占主导,危险就来了。

### 9.2 对"有效市场"理论的批判

**误人子弟的教授们**:
- 过度信奉"理性人"假设
- 对心理学的"非理性人"理论所知甚少
- 缺乏实际生活经验

**现实真相**:
> 人类与旅鼠一样,在某些情况下都有"集体非理性"倾向。

这种倾向导致:
- 聪明人产生不理智想法
- 做出不理智行为
- 比如许多基金会的投资管理实践

### 9.3 机构投资者的可悲现状

⚠️ **当今最可悲的事**: 每个机构投资者最害怕的,就是自己的投资实践与大家不同。

## 十、道德责任与谨慎原则

### 10.1 演讲的真正目的

**我的演讲并非为了**:
- 让慈善基金会掌握投资技巧

**我的真实目的**:
- 让基金会理解自身投资运作与大环境的密切关系

### 10.2 一个粗略但重要的道理

> 如果一个机构在复杂大环境中有一方面做得不够好,那么它其他方面也**极有可能**做得不够好。

**推论**:
- 需要改善基金投资实践
- 也要提高基金捐赠智慧

### 10.3 两个古老法则

#### 道德法则：塞缪尔·约翰逊的教诲

> **人物背景**: 詹姆斯·博斯韦尔(1740—1795)
> - 苏格兰律师和杂文家
> - 1791年出版《塞缪尔·约翰逊传》而声名大噪

**约翰逊的道德法则**:
> 对于身居要位的官员而言,保持可以轻易消除的无知,就是在道德责任上的渎职。

💡 **换句话说**: 当你有能力、有责任了解真相时,选择无知就是失职。

#### 谨慎法则：华纳及史瓦塞公司的智慧

**广告语启示**:
> "需要新机器而尚未购买的公司,其实已经在为它花钱了。"

**应用到思想工具**:
- 如果缺乏正确的思想工具
- 你和你试图帮助的人
- 已经深受这种**可以轻松消除的无知**的毒害

## 十一、后记：理论的延伸思考

### 11.1 演讲后的反馈

**令人失望的现实**:
- 听过或看过讲稿的人
- **完全没有人**作出理论回应
- 没有任何受过经济学训练的人试图探讨

**我的态度**:
- 这种漠视没有让我灰心
- 我打算进一步发挥理论

### 11.2 思想实验：2006年的极端场景

#### 假设条件

| 变化项 | 数值 |
|--------|------|
| 股票价格上涨 | 200% |
| 企业盈利增长 | 0% |

#### 推演结果

**第一步**: 全部美国企业所有可合理分配的利润,**还没有**股票持有者的投资成本多。

**原因**: 投资成本上涨比例与股价相同。

**第二步**: 扣除投资成本后,全部企业所有者**得不到一分钱**。

**第三步**: 摩擦成本制造者所得,**超过**全部可合理分配的企业利润。

**第四步**: 企业所有者想赚钱,只能将股份卖给"新资金"提供者。

**第五步**: 新资金提供者:
- 付出持续高涨的投资成本
- 只能指望股价无休止上涨
- 得不到任何净利润
- 除非再卖给又一批新资金提供者

💡 **核心启示**: 这就是典型的**庞氏骗局结构**。

### 11.3 不同视角的解读

#### 摩擦成本制造者的观点
最理想状态:
- 企业可合理分配利润100%落到他们手里
- 这是天经地义的
- 落到股东手里才是浪费

#### 某些经济学家的观点
这样的结果很好:
- 因为这是自由市场的结果

#### 我的观点

这种怪异现象是**三种东西的结合体**:

| 比喻 | 本质 |
|------|------|
| 贪婪收取不合理手续费的赌场 | 剥削投资者 |
| 天价艺术品市场般的庞氏骗局 | 明显不适合养老基金参与 |
| 终将破裂的投机泡沫 | 可能给宏观经济造成恶果 |

### 11.4 对社会文明的威胁

⚠️ **严重警告**:
- 这种情况极有可能给社会文明制度带来巨大破坏
- 美国的声誉会受到伤害
- 而且理所当然

### 11.5 苏格拉底的忠告

> 请爱护你的声誉,像珍惜最贵重的珠宝那样——因为信誉就像火焰,点着之后可以轻松让它燃烧,可是一旦扑灭,必须很费力才能再次点燃它。
> 
> 获取好声誉的办法是:努力成为你想要成为的人。
> 
> —— 苏格拉底
