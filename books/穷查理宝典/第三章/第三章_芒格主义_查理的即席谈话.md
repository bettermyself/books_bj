>
> 整理者：**惠特尼·提尔逊**

## 编者前言

沃伦·巴菲特和查理·芒格毫无疑问是有史以来最伟大的投资二人组。向他们学习的真正价值，不仅在于了解如何让金钱以高复利长期增长，更在于：

- 更深刻地理解人类本性与世界现状
- 学会如何理性思考
- 过上**正直、幸福、善良**的生活（这三者相辅相成）

查理比沃伦更为神秘——关于他的书只有两本，发表的演讲和文章也少得多。本章内容从过去五年伯克希尔和西科年会的记录中抽取，保留了查理最有洞察力、最发人深思、最好玩有趣的话，并依照话题加以组织。

### 一、我们成功的关键

#### 1.1 两条核心原则

| 原则 | 核心内容 |
|------|----------|
| **避免愚蠢，而非追求聪明** | 我们从来不试图成为非常聪明的人，而是持续试图别变成蠢货——乌龟吸取前辈的洞见，有时也能跑赢追求独创性的兔子 |
| **道德高于法律底线** | 在"应该做的事情"和"不受法律制裁的事情"之间，应有巨大的鸿沟。做正确的事，往往能赚到更多的钱 |

> 💡 **路易斯·文森狄的规则**：说真话，你将无须记住你的谎言。就是这么简单的一个概念。

### 二、论伯克希尔·哈撒韦

#### 2.1 商业模式：刺猬的大道理

伯克希尔的核心逻辑可以用一个公式概括：

```
以 3% 利率获取浮存金  →  投资年回报率 13% 的企业  =  极好的生意
```

- **浮存金**：理赔之前可用于投资的现金保费收入（资本成本仅 3%）
- **投资回报**：收购企业税前回报率约为 13% 或更高
- 两者之差形成持续的复利优势

#### 2.2 历史业绩与未来预期

| 维度 | 评估 |
|------|------|
| 历史业绩 | 好到几近荒谬；若举债经营至默多克水平一半，规模应是现在的 5 倍 |
| 未来展望 | 增长率将低于过去，但仍是极好的企业 |
| 不乐观的两个原因 | ①规模过大，只能涉足竞争更激烈的领域；②未来 15～20 年股市大气候不如过去景气 |
| 确定性 | 现金每年增加，结构灵活，收购整体出售企业具有优势 |

> ⚠️ **大数定理——沉重的铁锚**：所有经济发展都会在规模越来越大的过程中锻造出自己的数学铁锚。——巴菲特

#### 2.3 伯克希尔的文化

- 非常**老派**，类似本杰明·富兰克林或安德鲁·卡内基的文化
- **保守主义**：不盲目扩张，比绝大多数地方更能抵御灾难
- **诚实披露**：股价值多少就说多少，不试图拉抬股价
- **股东至上**：对于把大部分净资产投在伯克希尔的股东，高度负责

#### 2.4 收购策略

| 策略要点 | 说明 |
|----------|------|
| 不为收购而收购 | 等待不用多想也知道会成功的机会（三分之二的行业收购是失败的） |
| 主动寻找 | 不坐等上门，每年收购一至两家，20 年如此 |
| 看重激情 | 认为激情比头脑能力更重要 |
| 敬佩创办人 | 收购后管理层通常留任，且从未让人失望 |
| 极度放权 | 附属公司企业文化由其自决，权力分散到几乎全面退位 |

> 💡 **芒格论"合力"**：我们并不回避合力，只是回避那些对合力的宣称。

#### 2.5 保险业务

- 再保险并非纯粹的价格竞争型商品——**支付意愿和支付能力**的信誉形成护城河
- 愿意在市场不景气时少签保单，不迎合华尔街——这是重要的竞争优势
- 总体评价：位于行业前 10%，对保险业务持**中等乐观**态度

#### 2.6 伯克希尔的接班人问题

沃伦离开后的影响评估：

| 领域 | 预期影响 |
|------|----------|
| 资本配置 | 继任者难以达到沃伦的水准 |
| 旗下企业运营 | 将继续正常运转 |
| 整体规模 | 预计将持续变大、变强 |
| 增长速度 | 肯定低于过去，这是诚实的预期 |

### 三、投资建议

#### 3.1 集中投资

**核心观点**：投资 10 家公司，而非 100 家或 400 家。

- 好项目不会经常出现，**机会只眷顾有准备的人**
- 98% 的大型投资机构不这么做——这正是我们的优势
- 投资规矩：**等待好球的出现**，不受逼迫全部投出

#### 3.2 对分散投资的批评

> 认为投资应该越分散越好，是一种发疯的观念。

- 几乎所有好投资的分散程度都是相对较低的
- 如果剔除伯克希尔最好的 15 个决策，业绩将非常平庸
- 需要的不是大量行动，而是**极大的耐心**

#### 3.3 坐等投资法

- 购买价值被低估的股票，待其回归合理价格再卖——这很难
- 更好的方式：**购买几个伟大的公司，安坐下来**
- 我们偏向于把大量的钱投在不用再另作决策的地方

#### 3.4 优秀企业的定义

> 有这么两类企业：

| 类型 | 特征 | 评价 |
|------|------|------|
| **第一类** | 每年赚 12%，利润可以拿走 | ✅ 好企业 |
| **第二类** | 每年赚 12%，但所有多余现金必须再投资，从不分红 | ❌ 我们讨厌这种 |

**喜诗糖果的教训**：伊拉·马歇尔说我们低估了优质的价值。我们听进了批评，改变了想法。能够建设性地接受批评，是非常重要的品质。伯克希尔在很大程度上是**建立在建设性的批评之上的**。

#### 3.5 错误的分类

| 错误类型 | 描述 |
|----------|------|
| **吮吸大拇指** | 看到好机会，什么也不做 |
| **只买一点** | 本应大量买入，却只买了一点点 |

这些坐失良机的错误不出现在财务报表上，却可能让我们失去几十亿美元。

#### 3.6 投资的关键性格特质

成功投资者需要的不只是智商，更需要：

1. **耐心**——毫不焦躁地持有股票的性情
2. **求知欲**——在很长时间内保持大量求知欲望
3. **自律与自控**——无论多大压力，不改变原则
4. **能力圈边界意识**——清楚地知道自己的边界在哪里

> 💡 **能力圈判断法**：如果你在问自己是否过了能力圈的范围，那这个问题本身就是答案。

#### 3.7 对其他投资理论的批评

| 理论/工具 | 芒格评价 |
|-----------|----------|
| Beta 系数 | 没什么道理 |
| 现代组合投资理论 | 没什么道理 |
| 资本成本计算 | 用机会成本思考才是正确方式 |
| 市场完全有效理论 | 98% 的人信奉这种胡言乱语 |
| 布莱克-舒尔斯模型 | 适用于短期期权；用于长期期权则是"很神经的做法" |
| IPO 炒新 | 普通人很容易遭受重挫 |
| 宏观统计预测 | 几乎没有用，密切关注旗下企业更有效 |

### 四、思维模型

#### 4.1 多元思维模型的重要性

> 你必须知道重要学科的重要理论，并经常使用它们——**要全部都用上，而不是只用几种。**

常见的错误模式：

- 只掌握一个学科的思维模型，试图用一种方法解决所有问题
- 典型比喻：**"在手里拿着铁锤的人看来，世界就像一颗钉子。"**
- 错误的学习方法：学完之后"放掉浴缸里的水"，用时再无从提取

#### 4.2 不自欺的精神

> 不自欺的精神是你能拥有的最好的精神。它非常强大，因为它太少见了。

凯恩斯说：介绍新观念倒不是很难，难的是**清除那些旧观念**。

#### 4.3 常识（非常识）

- 得到系统的常识是一种威力巨大的工具
- 拥有常识意味着：有能力辨认智慧，也有能力**拒绝愚蠢**
- **电脑带来的危险**：人们计算得太多，思考得太少
- 你拥有的基本知识越多，你需要吸取的新知识就越少

### 六、怎样变得幸福、富裕

#### 6.1 如何获得幸福和成功

| 建议 | 说明 |
|------|------|
| 生活不只是积累财富 | 如果唯一的成功就是买股票发财，那是失败的生活 |
| 知道该避免什么 | 大多数成功来自于知道要避免什么：过早死亡、糟糕的婚姻等 |
| 养成良好习惯 | 避免艾滋病、危险驾驶、吸毒；培养良好的心理习惯 |
| 远离邪恶之人 | 尤其是那些性感诱人的异性 |

#### 6.2 如何致富

> 每天起床的时候，争取变得比你从前更聪明一点。认真地、出色地完成你的任务。慢慢地，你会有所进步……到最后，大多数人得到了他们应得的东西。

#### 6.3 如何找到好配偶

> 唯一的最佳方法是你首先必须**值得拥有好配偶**，因为从定义上来说，好配偶可绝不是傻瓜。

#### 6.4 提防妒忌

- 妒忌是**仅有的一种你不可能得到任何乐趣的罪行**
- 斯坦利·德鲁肯米勒（索罗斯基金）因无法忍受别人赚钱而亏得一塌糊涂
- 伯克希尔根本不在意别人在科技产业赚了钱

#### 6.5 阅读的重要性

> 我这辈子遇到的聪明人没有不每天阅读的——没有，一个都没有。

- 芒格偏爱**传记**——将伟大概念与提出它们的伟人生活联系起来，学得更好
- 与"已逝的伟人"交朋友，能过上更好的生活，得到更好的教育

#### 6.6 其他建议

- **减少物质需求**：对抗通货膨胀最好的手段之一
- **避免欠债**：一旦走进负债怪圈很难走出；支付 18% 利息无法取得进展
- **慈善**：非常幸运的人有责任反馈社会

### 八、对基金管理行业的批评

#### 8.1 行业问题总结

| 问题 | 描述 |
|------|------|
| 有缺陷的激励机制 | 要求人们假装做他们做不了的事情，假装喜欢不喜欢的事情 |
| 没有增加价值 | 整个投资管理行业加起来，并没有对全部客户的资产提供净附加值 |
| 高额费用 | 开放式基金收取 2% 年费，经纪商再收 3%～4%，最终伤害普通基民 |
| 共同基金丑闻 | 部分基金管理人接受贿赂，出卖股东利益 |

#### 8.2 对指数基金的看法

> 对于一般基金来说，投资指数是比无借贷股票投资更为聪明的策略——尤其是在年管理费超过 1% 的现状下。

### 九、对华尔街的批评

#### 9.1 道德水准

- 华尔街的平均道德水准**永远至多只能说是中等**
- 过去几十年，投资银行业的道德风气逐渐败坏
- 现在的风气：只要能赚钱，什么都可以卖；能卖掉就道德高尚——**这个标准不够**

#### 9.2 所罗门个案

- 所罗门竟然争抢"跳来跳去的捷克人"罗伯特·麦克斯韦尔的业务
- 教训：**你得防止人们为了挣钱将不三不四的人带入**

### 十、对会计的批评

#### 10.1 大型会计师事务所的道德沦丧

- 年轻时的大型事务所是非常正派的地方
- 过去 25 年逐渐沦落，明目张胆做假账、帮助客户逃税

#### 10.2 核心会计问题

| 问题 | 芒格观点 |
|------|----------|
| 创造性会计 | **绝对是对文明的诅咒**；民主国家往往需要丑闻才能撬动改革 |
| EBITDA 误用 | 每次看到 EBITDA，都应该用"**狗屁利润**"来代替它 |
| 养老基金假设 | IBM 预期 10% 回报率，实际 6% 更现实；林肯的狗腿比喻：说尾巴是腿，不能让它变成腿 |
| 激进会计法 | 伯克希尔始终采用保守会计法，拒绝有悖道德准则的做法 |

#### 10.3 安达信教训

- 没有失败的资本主义，就像没有地狱的宗教
- 合伙制企业在采取举动和选择客户方面必须**额外谨慎**

### 十一、对股票期权的批评

#### 11.1 核心问题

| 问题 | 说明 |
|------|------|
| 激励机制失效 | 给已六十几岁的创始人 CEO 大量期权以刺激忠诚，是精神错乱的想法 |
| 不公平分配 | 可能使什么都没做的人获得大量回报，而真正贡献者却什么都没有 |
| 会计错误 | 认为期权没有成本的理论，导致大量公司滥用期权 |
| 股权稀释 | 期权不但增加成本，还稀释股权——**任何反对这种看法的人都是神经病** |

> ⚠️ **芒格对布莱克-舒尔斯的评价**：该模型对短期期权有效；用于长期期权则是"一无所知"的系统。举例：为何 30 美元期权比 60 美元期权价值更低，布莱克-舒尔斯反而认为后者更高——这简直是疯了。

### 十二、对金融机构和衍生品的警告

#### 12.1 金融机构的天然风险

> 金融机构的本质决定了它很容易阴沟里翻船：放贷太多、愚蠢的收购、过度借贷……

- 伯克希尔对大量举债的金融机构**尤其警惕**
- 当机构开始宣传风险管理有多好时，我们就感到紧张

#### 12.2 衍生品的系统性问题

| 问题维度 | 描述 |
|----------|------|
| **复杂性** | 涉及金额达几万亿美元，复杂到无法相信 |
| **会计虚假** | 所谓固定资产并非真实固定资产；GAAP 应用于衍生品导致大量虚假利润 |
| **长尾风险** | 可能要经过好几年才能测算某项交易的真实亏损或收益 |
| **信用连锁** | 信用调低需增加抵押金，类似股票保证金，可能引发连锁破产 |
| **能源案例** | 能源衍生品全部完蛋——想动用账面资产时，钱并不在那里 |

> ⚠️ **芒格的警告**：在未来五到十年里，如果美国没有遇到与衍生品相关的大问题，我将会非常吃惊。

> 💡 **测试管理层的方法**：问他们"你真的能理解你的衍生品账目吗？"——如果有人说"是"，那这个人要么疯掉了，要么是在说谎。

### 十三、对律师、法律制度的批评

#### 13.1 玛莎·斯图亚特案的教训

- 她是**在聘请了著名大律师之后**，因编造虚假故事欺骗检察官而入狱的
- 如果一开始说出真相，本可以没事
- **教训**：说真话永远是最简单、最有效的策略

#### 13.2 侵权赔偿制度的问题

- 原告方律师协会权力越来越大，影响法官判决
- 导致优秀企业不愿进入某些行业（如新型警察头盔研发公司）
- 制度本身不利于最好的企业的正常发展

#### 13.3 石棉诉讼乱象

- 真正严重受伤的人因为钱被分流而得不到足够赔偿
- 大量无资格的人通过伪证（由律师教唆医生）获得赔偿
- 只有 25% 的钱给到索赔者手里，其余被律师、医生等拿走

> ⚠️ **重要教训**：坏人一旦变得有钱，将会获得巨大政治力量，无法阻止他们干坏事——关键是把这类事情**扼杀在萌芽状态**。

### 十五、各方评价芒格

#### 15.1 路易斯·辛普森（美国政府职员保险公司总裁兼CEO）

> 查理身上某些性格特点组合，我从未在其他人身上看到过：聪明绝顶、兴趣广泛、几乎从不遗忘任何事情。他最大的优点是对**诚实、道德和正直的绝对坚持**——从来不为自己攫取非分之物，值得毫无保留地信任。此外，他还拥有投资的理想性格：**毫不妥协的耐心、自律、自控**——无论多大压力，从不动摇原则。

#### 15.2 吉姆·塞内加尔（好市多CEO）

> 他敏锐地指出好市多会员制非常有价值；他的洞见、质询和支持使好市多的管理和运营都得到了改善。最重要的是他的**直率和基于常识的敏锐商业触觉**。

#### 15.3 芒格评价吉姆·塞内加尔

> 吉姆·塞内加尔是传奇式的企业经营者——就像卡内基、洛克菲勒。他是 20 世纪最出色的五名零售商之一。他每周工作 80 个小时，在职业操守、正直、忠诚和无私方面为整个企业树立杰出榜样。**他既是行动上的领袖，也是道德上的领袖。** 我们在好市多拥有属于自己的、活着的、呼吸着的山姆·沃尔顿。

#### 15.4 查克·瑞克斯豪瑟（芒格多年友人）

> 人们通常认为查理的价值在于识别风险和说"不"，但其实查理最有价值的地方，在于他能够**识别那些可以参股的时机**。

#### 15.5 奥蒂斯·布思（大股东、多年友人）

> 我做过的最好的投资决定就是，这些年来把我的双手放进口袋里，让巴菲特和芒格去施展拳脚。我只是认识到他们比我更出色。

### 十六、"说不大师"的故事

查理以"说不"著称，但他真正的价值在于：

- **识别该说"不"的情况**：帮助沃伦规避风险，两人仔细考量每一个风险
- **识别该说"是"的情况**：当沃伦表示仍想做某件事时，查理有时会说"我能不能参股"——这才是真正宝贵的信号
- **终极标准**（奥蒂斯·布思的总结）：查理明白要找到真正好的东西很难，所以就算你 90% 的时间都在说"不"，你也不会错失太多的东西
