# 第22章 上海机场研究纲要

> 📅 **发表时间**：2020 年 11 月 11 日

> **推荐人李政乾**：本文以上海机场为基础，针对怎么理解一家企业提供了非常全面的研究纲要。其中既有对阅读财报时面临"提不出有价值的问题"困境的建议，又展示了对企业的特性进行细致概括的思路。

---

### 一、如何抓住一家企业的基本特点

很多朋友都遇到过这样的难题：阅读财报时，提不出有价值的问题。正好，本章基本都是在提问题。老唐认为，通过阅读上海机场的财报，**如果把本文的问题都回答了，估值和买卖点自然就出来了**。当然，回答这些问题不是那么简单的。

拿到一家企业，老唐的习惯是先做两张表。

#### 1.1 第一张表：简化资产负债表

| 要点 | 说明 |
| ---- | ---- |
| **怎么做** | 合并同类项，并将数字改成方便阅读的量级（比如以亿元为单位） |
| **为什么** | 避免让自己迷失在数字的细节里 |
| **看什么** | 通过观察简化资产负债表，可以看出一家企业的基本特点 |
| **动手建议** | 自己也做一个，数据参考 2019 年年报或 2020 年中报都行 |

⚠️ 所谓"**特**"点，就是**不同点**。如果你总共就看过一家企业，那就可能很难迅速看出特点——很显然，一家没法"不同"，只有看过多家后，你才可能迅速发现不同。

#### 1.2 第二张表：百分比利润表

| 要点 | 说明 |
| ---- | ---- |
| **怎么做** | 以合并利润表的营业收入为 100，将各个分项所占比例标出来 |
| **看什么** | 便于观察企业从营业收入到净利润的变化过程中，主要影响因素是哪些，各自的权重有多大 |
| **动手建议** | 鉴于 2020 年受新冠肺炎疫情冲击，不是正常态，建议使用 **2018 年和 2019 年**合并利润表数据制作 |

### 二、上海机场的核心特征

通过阅读年报，我们可以发现上海机场有以下三个核心特点。

| 序号 | 核心特点 | 一句话概括 |
| ---- | -------- | ---------- |
| 第一 | 具有区位和定位优势 | 机场可以对**单人单机**收取更高费用 |
| 第二 | 以非航收入为主 | 航空收入、油料销售及广告业务为辅 |
| 第三 | 新增非航收入**有保底** | 有合同保证的兜底收入，有明确数据 |

#### 2.1 特点一：区位和定位带来更高单价

上市公司上海机场主要运营**上海浦东机场**，其定位是：**国际航空枢纽，航班以国际航班为主**。这条定位带来一串连锁效应：

| 环节 | 内容 |
| ---- | ---- |
| 机型 | 国际航班的飞行距离决定了航班**以大飞机为主** |
| 替代品竞争 | 受高铁、客车和自驾等其他交通方式的影响**很小** |
| 收费标准 | 航空收入里涉及的飞机起降费、旅客服务费、安检费等各项收费，民航局制定的标准就是**国际航班高于国内航班，大飞机高于小飞机** |

💡 这意味着：**与其他机场相近的资源投入，浦东机场能够带来更高的航空收入。**

#### 2.2 特点二：利润与增长主要来自非航收入

虽然航空相关收入可观，但上海机场的**利润及增长主要来源却是非航收入**。

| 收入类别 | 具体构成 | 地位 |
| -------- | -------- | ---- |
| **非航收入** | 免税店销售提成；机场各种零售和餐饮店租金 | **主要**来源 |
| 航空收入 | 飞机起降费、旅客服务费、安检费等 | 次要来源 |
| 油料销售 | — | 次要来源 |
| 广告业务 | — | 次要来源 |

#### 2.3 特点三：新增非航收入有合同保底

| 部分 | 收入依据 |
| ---- | -------- |
| **原有**非航收入 | 既有**合同数据**，也有**历史记录** |
| **新增**非航收入（卫星厅于 2019 年 9 月投入使用） | 新增免税分成**有保底**；场地出租（国际零售、国内零售、餐饮）**也有保底** |

其中**免税品销售分成是大头**。

💡 在这三个前提下，如果没有不可抗力，**上海机场未来五年的收入和利润都不难预测**，这是研究上海机场的优势。

### 三、动态跟踪和观察

基于对以上基本特点的认知，针对上海机场的**重大分歧**在于：**国际航线受疫情和国际冲突影响较大。**

#### 3.1 两类外部风险的现状

| 风险类型 | 当前状况 | 直接结果 |
| -------- | -------- | -------- |
| 国际关系 | 目前暂时**看不到**国际关系剧烈变化到影响人员往来的情况 | — |
| 疫情 | 国内受控、**欧美严重** | 今年以国际航班为主的机场**受挫更为严重** |

⚠️ 疫情究竟什么时候可控，**没人知道**。也许一年，也许两年，也许更久。

#### 3.2 我们相对于市场主流机构的优势

相对于市场主流机构而言，我们的优势在于：**我们可以直接跳过 2021 年和 2022 年，一眼看到 2023 年去。**

这里的"我们"，指同时具备以下三大条件的人：

| 条件 |
| ---- |
| ① 自有闲余资金 |
| ② 没有业绩评比压力 |
| ③ 能够承受股价波动 |

#### 3.3 一个只能靠信念的概率问题

2023 年疫情影响是否会消除，国际人员和货物往来是否能恢复正常？**这依然是个概率问题，没有 100% 确定的证据，只能靠信念。**

老唐主观认为大概率用不了那么久。两种判断对应两种截然不同的结论：

| 你的判断 | 对应结论 | 理由 |
| -------- | -------- | ---- |
| 认为 2023 年**依然无法**恢复正常（2022 年前无法控制疫情） | 上海机场**并不适宜下注** | 在疫情的不可抗力下，**即便有非航保底收入合同，依然可以不执行**，这是商业惯例 |
| 反之 | **则可以试试** | — |

⚠️ 昨天传出的**疫苗利好**是一把双刃剑：它降低了疫情相关问题的不确定性，但同时也**使我们获得理想价格的可能性降低了**。

### 四、投资者需要解决的五个问题

在"**利润及增长主要观察非航收入，尤其是免税品销售分账**"这一前提下，老唐认为投资者需要解决的问题主要有 5 个。

| 序号 | 议题 | 具体追问 |
| ---- | ---- | -------- |
| 第一 | **免税牌照政策走向** | 免税品销售作为一个有牌照控制的管制行业，在政策上，是趋向于批出更多牌照，还是维持现有状态不变？<br>如果是批出更多，能多到什么程度？对机场免税品销售会产生多大影响？ |
| 第二 | **免税市场整体容量** | 你认为我国免税品的整体市场会是增长、维持还是缩水？ |
| 第三 | **替代渠道的竞争** | 跨境电商能不能抢走免税店的市场？<br>市内及岛内免税店对机场免税店会产生多大程度的竞争？<br>它们是否会导致机场免税店丧失竞争优势？ |
| 第四 | **关联交易与失血风险** | 国内各大机场的土地基本都租自大股东，为什么？<br>对于上海机场，巨额关联交易（**场地租赁**和**委托建设**）是否隐藏着失血通道或其他风险？ |
| 第五 | **持续的资本投入** | 你如何看待机场这种持续的资本投入？<br>它是否影响你的投资决策？为什么？ |

> 💡 上述每一个问题，老唐都追加了同一句拷问：**你作出上述判断的依据是什么？** 这正是研究工作与主观猜测的分界线。

#### 4.1 关于第五个问题的背景：机场扩建的内在驱动力

第五个问题背后有一条清晰的利益链条，值得单独说明：

| 环节 | 内容 |
| ---- | ---- |
| **成本承担方** | 机场建设的成本由**上市公司**承担 |
| **收益分享方** | 带来的人流和物流却可能让**当地各行各业**都分到一杯羹 |
| **必然结果** | 地方政府始终会有要求机场**扩大吞吐能力**的强烈愿望 |
| **传导机制** | 一旦各大上市机场客货流量接近饱和，**甚至不等接近饱和**，政府就会启动新的基建，需要持续投入大笔资金 |

⚠️ **现实案例**：目前上海机场仍在进行**三期扩建工程**，但市政府已经规划了浦东机场 **T3 航站楼**（2025 年前建成）的建设。

### 五、从问题到估值：只剩一道数学题

老唐认为，能够清楚回答上述几个问题后，估算工作就变得相当机械了。

#### 5.1 2023 年利润的估算三步法

| 步骤 | 动作 |
| ---- | ---- |
| ① | 考虑 **2023 年相对于 2019 年**至少会增加多少**非航收入** |
| ② | 同时考虑因 **2019 年新增固定资产**带来的**年度折旧成本** |
| ③ | 然后依照 **2019 年的财报数据结构**，即可大致估算上海机场 **2023 年可能的利润数据** |

#### 5.2 可选项：航空及其他收入的增长

至于因**第五跑道及卫星厅**投入使用，带来的机场吞吐能力增加，从而拉动的**航空收入、油料销售收入和广告业务收入**的增长：

- **愿意估的**，可以做做估算；
- **不愿意估的**，直接**按照安全边际**看待也不是什么大事。

#### 5.3 唯一的未知数

想清楚上述问题，并作出 2023 年可能的利润估算后，**合理估值及买卖点其实就是一个极简单的数学题。**

| 要点 | 说明 |
| ---- | ---- |
| 老唐估值法的性质 | 是个**死公式** |
| 全部未知数 | 只有一个 —— **三年后的预计利润** |
| 结论 | 唯一的未知数解决了，**任何具备小学三年级数学水平的朋友**，都有能力计算出三年后合理估值及当下的买卖点 |
