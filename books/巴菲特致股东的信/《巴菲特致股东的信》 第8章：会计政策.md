## A.并购

### 一、背景概述

并购的会计应用是当前极具争议的话题，相关讨论甚至可能引发国会介入。争议的核心在于：**GAAP（一般公认会计原则）允许两种截然不同的会计处理方法**，而两者在实际操作中的差异显著。

---

### 二、两种会计处理方法对比

| 对比维度         | 购买法                             | 权益合并法                 |
| ---------------- | ---------------------------------- | -------------------------- |
| **支付方式**     | 现金或股票均可                     | 仅限股票交易               |
| **商誉处理**     | 产生商誉，需分年摊销               | 无商誉科目，无摊销         |
| **对损益影响**   | 每年提列大额摊销费用，减少账面利润 | 无摊销负担，账面损益更好看 |
| **管理层偏好**   | ❌ 通常排斥                         | ✅ 普遍偏好                 |
| **反映交易实质** | 更接近真实交易                     | 存在掩盖买卖关系之嫌       |

---

### 三、商誉摊销的争议

#### 3.1 强制摊销的问题

大多数会计费用与实际状况相关联，虽不完全精确，但方向一致：

- **折旧**：反映实体资产价值的逐渐减损
- **存货跌价损失**：反映库存价值下降
- **应收账款呆账**：反映潜在坏账风险
- **保修准备**：反映潜在售后成本

然而，**经济商誉与上述资产有本质区别**——它在许多情况下不仅不会减损，反而会随时间增加。

#### 3.2 经济商誉的特殊性

> 💡 经济商誉类似土地，价值会上下波动，但整体趋势往往向上。

以**禧诗糖果**为例：过去78年间，其品牌价值以不规则但快速的速度持续增长。只要经营得当，这种增长态势有望再延续78年。

⚠️ **强制摊销经济商誉，往往导致会计数字与现实严重脱节。**

---

### 四、权益合并法的本质问题

权益合并法的理论基础是"两条河流汇流后不再分彼此"——被购并公司不算被"买下"，因此无商誉产生，也无需摊销。

然而，这与并购的真实情况大相径庭：

1. **交易必然存在买卖双方**，不管交易结构如何设计
2. **员工最清楚谁是征服者、谁是被征服者**，绝不会混淆
3. 真正意义上"对等合并"的案例极为罕见

**FASB坚持认为大多数并购案具有买卖性质，这一立场是正确的。**

---

### 五、改进方案建议

芒格与巴菲特认为，应存在一种**兼顾真实性与合理性**的会计处理方法，具体建议如下：

#### 5.1 核心原则

| 步骤         | 处理方式                                         |
| ------------ | ------------------------------------------------ |
| **初始确认** | 以公平市价列出投资成本（无论支付现金还是股票）   |
| **商誉处理** | 将经济商誉保留在账上，**不做分年摊销**           |
| **减值测试** | 若商誉确有减损，按资产减值的一般判断方式进行计减 |

#### 5.2 预期效果

- **统一标准**：追溯适用，消除当前并购会计处理的乱象
- **决策优化**：管理层将更审慎评估并购，基于真实股东利益决定使用现金还是股票
- **回归本质**：不再以合并后的账面损益为导向，而是关注实际经济价值

---

### 六、总结

| 核心观点         | 说明                                       |
| ---------------- | ------------------------------------------ |
| 购买法更真实     | 反映了并购的买卖本质，但商誉强制摊销不合理 |
| 权益合并法有缺陷 | 规避了商誉问题，但掩盖了交易实质           |
| 理想方案         | 保留商誉不摊销，仅在真实减损时计减         |

> ⚠️ 在FASB推动取消权益合并法的背景下，建立一套**既符合交易实质、又避免不当摊销**的会计准则，是当前并购会计改革的关键所在。



## B. 分部数据与会计合并

#### 1.1 会计准则重大变化（1988年）

1988年，**一般公认会计原则（GAAP）** 发生重大转变：伯克希尔被要求将**所有子公司**的资产负债表与损益表进行全面合并。

#### 1.2 新旧准则对比

| 维度               | 旧准则（权益法）                               | 新准则（全面合并法）                         |
| ------------------ | ---------------------------------------------- | -------------------------------------------- |
| **资产负债表呈现** | 仅按投资比例列示被投资公司净值（投资权益）     | 须将被投资公司**全部资产与负债**并入合并报表 |
| **损益表呈现**     | 仅按投资比例列示被投资公司年度损益（投资损益） | 须将被投资公司**全部营收与费用**并入合并报表 |
| **适用范围示例**   | 互助储贷、斯科特·费泽金融¹                     | 所有受控子公司                               |

> ¹ 斯科特·费泽金融主要从事世界百科全书与 Kirby 吸尘器分期付款的信用业务。

#### 1.3 管理层的立场

> ⚠️ 伯克希尔编制合并数字的**唯一原因**是满足外部监管要求；芒格与巴菲特实际参考的是另一套内部信息。

企业形态越复杂，传统合并报表加总出的数字越难以回答以下核心投资问题：

1. 企业盈利能力如何？
2. 管理层表现如何？
3. 企业将责任转移给债权人的能力如何？

💡 第三个问题（偿债能力）通常无论何种报表均可直接判断，无需额外说明。

#### 1.4 伯克希尔的应对：补充信息披露

面对更多数字须合并入表的新要求，管理层决定**主动公布更多补充信息**，以协助投资者评估企业价值与管理表现。

补充信息的编制原则如下：

| 原则               | 说明                               |
| ------------------ | ---------------------------------- |
| **不拘泥于 GAAP**  | 不一定按照一般公认会计原则         |
| **不以公司为单位** | 不按单一法律主体区分               |
| **同质业务归并**   | 将性质相近的业务汇总呈现，便于分析 |
| **信息适度原则**   | 避免用海量数据淹没读者             |

> 💡 管理层的目标：**换位思考**——以投资者希望获取的视角，呈现真正重要的信息。



## C.递延税项

### 一、会计规则变动背景

1990年起，一项与**递延税务计算**相关的重大会计规则正式实施（原定1989年，因规则复杂且争议较大，延后一年执行）。

------

### 二、核心影响：未实现股票资本利得的税率统一

#### 2.1 规则变动前：分层税率结构

| 未实现收益归属时段 | 未实现收益金额  | 适用税率 | 备注         |
| ------------------ | --------------- | -------- | ------------ |
| 1986年以前         | 约 **12亿美元** | 28%      | 旧税率       |
| 1986年以后         | 约 **6亿美元**  | 34%      | 1987年起调整 |

#### 2.2 规则变动后：统一税率

新规则要求自1990年起，**所有未实现收益一律按34%税率**计提递延所得税负债。

> ⚠️ **财务影响**：此单项调整将使年度盈余及财报净值减少约 **7,100万美元**。

------

### 三、1993年规则进一步完善

1993年新颁会计规则正式取消二分法，要求以**现行税率统一估算所有递延税项**。

#### 3.1 调整时的资产规模（以1992年底为基准）

| 类别                     | 金额         | 适用税率 |
| ------------------------ | ------------ | -------- |
| 未实现收益（旧税率部分） | 12亿美元     | 28%      |
| 未实现收益（新税率部分） | 64亿美元     | 34%      |
| **合计未实现收益**       | **76亿美元** | —        |

#### 3.2 调整效果

- 自1993年第一季起，全部未实现股票收益统一按 **34%** 计税
- 所得税负债增加，净值相应减少约 **7,000万美元**
- 未来若税率发生变动，递延所得税负债及净值须**即时同步调整**

> 💡 **核心原则**：真正重要的，是证券最终出售、资本利得由"未实现"转为"已实现"时，**实际适用的税率**。

------

### 四、递延税项的经济学本质

递延所得税负债在经济上等同于**美国财政部给予的无息贷款**，具有以下独特特性：

| 特性         | 说明                             |
| ------------ | -------------------------------- |
| 利息         | 零利息                           |
| 到期日       | 由借款方（企业）自行决定         |
| 资金用途限制 | 只能用于购买特定的、升值的股票   |
| 额度变动机制 | 随市场价格波动，亦随税率变动调整 |

> ⚠️ **例外风险**：若国会修法，将课税时点提前至未实现资本利得阶段，上述"无息"优势将不复存在。

------

### 五、伯克希尔的立场与投资哲学

#### 5.1 对新规则的态度

伯克希尔认为，无论28%还是34%，均**无法真实反映公司实质**——因为公司从未考虑出售具有庞大未实现收益的持股。

#### 5.2 长期持有的税务逻辑

税法结构为长期投资者提供了显著的复利优势：

- **"瑞普·范·温克尔"式投资**（长期持有、极少交易）相较频繁短线操作，具有**重要的绝对税务优势**
- 1989年仅出售少量持股，即产生 **2.24亿美元**资本利得，须缴纳 **7,600万美元**交易税

> 💡 **投资原则**：选择长期持有，并非单纯因税务算术，更因已与优秀的商业伙伴建立了深厚、可信赖的合作关系——这种关系本身即可带来令人满意的投资回报。

#### 5.3 对递延税项负债的定性判断

| 观点                         | 结论                               |
| ---------------------------- | ---------------------------------- |
| 等同于15天内应付的贸易账款？ | ❌ 否，性质截然不同                 |
| 因无出售意愿而可忽略不计？   | ❌ 否，负债客观存在且重大           |
| 经济实质                     | ✅ 无息、自主决定到期日的"政府贷款" |

> ⚠️ **账面提示**：若年底按市价出售所有持有证券，应缴税款将超过 **11亿美元**——此为真实存在的或有负债，尽管在账面净值上与普通应付账款具有相同的扣减效果。



## D. 退休福利

#### 1. 会计规则重大变更（1993年起）

1993年1月1日起，新会计准则正式生效，**强制要求所有企业确认员工退休后健康福利负债的现值**。

| 对比维度           | 旧准则（GAAP） | 新准则（1993年起） |
| ------------------ | -------------- | ------------------ |
| 退休金负债         | ✅ 须确认       | ✅ 须确认           |
| 退休后健康保险成本 | ❌ 忽略         | ✅ 须确认           |
| 会计方法           | 现金发生制     | 负债现值法         |

**新准则的影响：**

1. 资产负债表须确认一大笔新增负债，净值相应减少
2. 往后年度利润因须确认此类成本而缩水

------

#### 2. 伯克希尔的收购原则

芒格与巴菲特在并购决策中，**主动回避背负高额退休金负债的企业**。

> 尽管伯克希尔目前拥有数万名员工，退休金负债及退休后健康福利成本仍控制在合理范围内。

**1982年的险失案例：**

- 巴菲特曾几乎买入一家背负沉重退休福利负债的公司
- 交易因不可控因素告吹，事后形容："两大页空白的跨页插图，最足以代表当年度告吹的交易"
- ⚠️ 后来另一买主接手，公司不久倒闭，数千名员工的健康福利承诺**全部化为乌有**

------

#### 3. 管理层失职的根源分析

**问题本质：**

| 失职表现                              | 后果                   |
| ------------------------------------- | ---------------------- |
| CEO未向董事会揭示无上限福利计划的风险 | 负债失控               |
| 采用现金发生制掩盖累计负债            | 严重低估实际义务       |
| 管理层与会计师"眼不见为净"            | 股东承担血本无归的损失 |

💡 无需专业医学知识亦能判断：**预期寿命延长 + 医疗成本上升 = 无上限承诺即无上限负债**

⚠️ 这种短视行为已危及部分美国大企业的**全球竞争力**。

**制度性讽刺：**

> 同样是这批批评国会"现金发生制思维不顾未来负债"的管理层，自身却对企业退休健康成本采取完全相同的处理方式。

------

#### 4. 管理层的会计思维警示

**林肯总统的谜语：**

> "如果一只狗连尾巴也算在内的话，总共有几条腿？" **答案是四条腿——不论你是否把尾巴当作一条腿，尾巴永远都是尾巴。**

**核心启示：**

就算会计师愿意证明"尾巴也是一条腿"，企业也不会因此多出一条腿。**会计处理方式改变不了经济现实**，管理层必须透过会计表象，直面真实的负债本质。
