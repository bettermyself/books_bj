## A.交易的祸害：交易成本

### 一、投资者的整体回报：一个基本事实

除极少数例外（如债权人追索导致破产），**股东作为一个整体，从公司获得的长期回报，等于该公司在其存续期内创造的全部收益**。

💡 关键洞察：  
- 无论股价如何波动，所有上市公司股东作为一个整体，其财富增量不可能超过公司本身的盈利总和。  
- 由于“摩擦成本”（交易费用、管理费、激励费等）的存在，投资者的实际回报会低于公司盈利。



### 二、摩擦成本的来源：四个“帮手”

巴菲特以“G家族”比喻所有上市公司股东的整体，描述了四类逐渐增加的“帮手”如何侵蚀投资者的收益。

#### 表1：摩擦成本的主要来源

| 帮手类型        | 角色说明                    | 对投资者回报的影响                   |
| --------------- | --------------------------- | ------------------------------------ |
| 经纪人          | 提供买卖服务，赚取手续费    | 增加交易成本，鼓励频繁交易           |
| 职业经理人      | 管理投资组合，频繁调整持仓  | 进一步放大交易费用                   |
| 财务规划师/顾问 | 帮助选择经理人，收取咨询费  | 增加间接成本，无助于整体回报         |
| 对冲/私募基金   | 收取固定费用 + 高额业绩奖励 | 盈利时分走大部分，亏损时由投资者承担 |

> ⚠️ 重要结论：  
> 上述“帮手”的摩擦成本已占美国全部公司盈利的 **20%**。  
> 也就是说，投资者最终只能拿到本应属于他们的 **80%** 的收益。



### 三、牛顿的第四定律（巴菲特调侃版）

> 💡 **“投资者的整体回报，随着交易频率的上升而减少。”**

#### 市场验证（以道琼斯指数为例）

| 时间段             | 指数点位变化               | 年化复合回报率（含分红） |
| ------------------ | -------------------------- | ------------------------ |
| 1899年12月31日     | 65.73 → 11497.12（1999年） | 5.3%                     |
| 2000年（预测起点） | 为达同样回报，需升至       | 2,011,011.23 点          |

> 注意：21世纪最初六年，道指几乎原地未动。



### 四、伯克希尔在纽交所挂牌的意义

  - 股价极高，10 股已远超多数公司 100 股的市值

✅ 伯克希尔顺利满足新标准，得以在纽交所挂牌。

## C.分红政策与股票回购

### 一、 收益的两种属性：受限定 vs. 非限定

在进行分红决策前，首先需理解并非所有收益都具有同等性质。我们必须区分会被通胀侵蚀的“受限定收益”和可自由支配的“非限定收益”。

| 属性           | 定义                                                         | 特征与影响                                                   | 处理原则                                                     |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **受限定收益** | 因通货膨胀侵蚀，导致财报显示的部分甚至全部无法用于分红的收益。 | - 常见于**高资产/利润比**的公司。<br>- 若用于分红，将损害公司维持销量、长期竞争力与财务实力的根基。<br>- ⚠️ **风险**：持续派发此部分收益，若无新资本注入，企业注定衰落。 | **必须留存**，以保持企业经济竞争地位。无论其再投资回报多低，都不能用于分红。 |
| **非限定收益** | 超出维持公司竞争地位所需资本之外的、可自由支配的利润。       | - 具有可选择性，可留存也可分红。<br>- 管理层应基于股东利益最大化做出选择。 | **择优处理**：是留存再投资，还是向股东分红。                 |

> **案例**：联合爱迪生公司曾因政策原因，股价跌至账面值的1/4。即便留存1美元的收益只能转化为0.25美元市值（“黄金变铅”的过程），大部分收益依然被用于再投资，而非分派给股东。



### 二、 非限定收益的配置法则：一美元原则

对于非限定收益的处置，我们遵循一个核心原则：管理层应选择对股东最有利的方式。尽管管理层常因“建立帝国”、“财务宽裕”等动机而倾向于留存收益，但**唯一有效的留存理由是：**

> 💡 **每一美元的留存利润，必须至少为股东创造一美元的市值。**

当留存收益作为再投资资本，其产生的**增量收益**，等于或高于投资者通常可以自行在其他地方获得的收益时，留存才是合理的。

#### 类比分析：一种特殊永续债的启示

为清晰说明，假设持有一只 \(10%\) 票息的无风险永续债，每年可选择领取现金或按原利率 \(10%\) 再投资。其决策逻辑如下：

| 外部市场利率        | 投资者最佳选择                             | 决策逻辑                                                     |
| :------------------ | :----------------------------------------- | :----------------------------------------------------------- |
| **低利率（如5%）**  | **选择再投资，或将再投资所得债券卖出变现** | 对比市场利率，该债券\(10%\)的回报率极具吸引力。即使需要现金，通过再投资后卖出债券也比直接收取现金更划算。 |
| **高利率（如15%）** | **选择收取现金**                           | 市场上有更好的投资机会。若想增加投资，直接用收到的现金在市场上折价买入债券，比滚存再投资成本更低。 |

**结论：** 公司收益的决定与此类似。如果再投资的预期回报率高，就应留存；如果回报低下，就应分红。在充分信息推测之后，分析变得非常简单。



### 三、 管理层思维的分裂与常见误区

一个令人费解的现象是，管理层在子公司和母公司层面的决策逻辑常常不一致，陷入“当局者迷”的困境。

#### 3.1 精神分裂式决策

-   **子公司层面**：CEO会毫不犹豫地指令一个预期回报率仅 \(5%\) 的子公司A，将所有收益上缴，以投资于预期回报率 \(15%\) 的子公司B。
-   **母公司层面**：当该CEO自身的长期增量资本回报率仅为 \(5%\)（低于\(10%\)的市场利率）时，他可能仍会遵循惯例，向母公司股东分红。

#### 3.2 核心业务光环的误导

-   公司整体的**净资产回报率和增量资本回报率**可能看起来不错，但这可能掩盖了资产配置的失败。
-   **现象**：具有超级盈利能力的核心业务，仅需少量资本便能产生超额回报和大量富余现金。管理层常将这些现金投入回报平平甚至很差的项目（如高价并购平庸企业）。
-   **类比**：就像职业与业余选手组合的高尔夫球队，整体得分不错，但主要靠职业选手贡献，而业余选手的糟糕表现被掩盖了。

> ⚠️ **警示**：核心业务的辉煌会掩盖其他领域资产配置的失败。管理层应持续将现金从低回报业务转移至高回报业务（包括分红或回购），而不应“生来就是为了寻找下一个失败”。



### 四、 股份回购：提升股东价值的利器

当股价远低于内在价值时，回购是比很多并购都更优的资本配置方式。

| 好处                      | 描述                                                         |
| :------------------------ | :----------------------------------------------------------- |
| **1. 即刻提升每股价值**   | 以低于内在价值的价格回购（如用1美元换2美元），数学上直接增加了继续持有股东的每股价值。在并购中很难做到这一点。 |
| **2. 信号效应与信心提升** | 回购向市场明确证明管理层**关心提升股东财富**，而非盲目扩张。这会提升投资者对企业未来回报的信心，推动股价更趋近于内在价值。 |



### 五、 回购的执行原则与伯克希尔的做法

#### 5.1 实施回购的两个前提

1.  **资金充足**：公司拥有满足日常运营与流动性需求之外的富余现金。
2.  **价格低估**：公司股价远低于保守计算的内在价值。

#### 5.2 伯克希尔·哈撒韦的具体策略

-   **价格约束**：仅在股价**远低于保守计算的内在价值**时才会考虑。例如，过去曾以账面值 \(110%\) 的价格进行回购。
-   **信息对称**：提供充足信息给公众股东，帮助他们估算真实价值，避免内部人士利用信息优势。
-   **不为托市**：**永远不会为了阻止股价下跌而进行回购**。只有认为回购是资金最有效的去处时才行动。
-   **操作方式**：通过场外直接询价方式进行，并且对小额交易和B股折价有具体规则。

#### 5.3 驳斥错误动机

-   **为抵消期权稀释而回购**：期权授予与股票回购均有其独立逻辑，不应混为一谈。不能因为要抵消期权稀释，就以高于内在价值的价格回购股票。
-   **为推高或支撑股价而回购**：这种做法让卖出股票的人受益，但让继续持有的股东受损（以1.1美元换取1美元价值），并非明智之举。



### 六、 股东的思维实验：期望股价低迷的理由

对于一家正在持续回购股票的公司的长期股东而言，其利益与股价的短期表现并不总是一致。

**思考题：当一家你投资的优秀公司打算长期大规模回购股票时，你作为长期股东应该希望股价如何变化？**

**答案：你应该希望股价在回购期间保持低迷。**

#### 6.1 数学证明：以IBM为例

假设伯克希尔持有IBM 5.5%的股份（约0.639亿股），IBM计划用500亿美元回购股票。让我们对比两种股价情景下，股东能获得的长期收益。

| 情景               | 假设回购均价 | 可回购股数 | 回购后总股本 | 伯克希尔持股比例 | 若第五年盈利200亿，伯克希尔的利润份额 |
| :----------------- | :----------- | :--------- | :----------- | :--------------- | :------------------------------------ |
| **情景一：低股价** | 200美元/股   | 2.5亿股    | 9.1亿股      | **7.0%**         | **14.0亿美元**                        |
| **情景二：高股价** | 300美元/股   | 1.67亿股   | 9.9亿股      | 6.5%             | 13.0亿美元                            |
| **差异**           | -            | -          | -            | **+0.5%**        | **+1亿美元**                          |

> **结论**：股价越低，同样的资金能回购并注销更多股份，继续留下的股东能拥有的公司权益比例就越高，未来享有的利润份额也越大。之后，我们的持股价值将额外多出15亿美元。

#### 6.2 情感与理性的冲突

-   **非理性反应**：大多数计划只买不卖的人，仍然会为股价上涨而感到开心。这如同一个日常通勤的人，为刚刚加满油后油价上涨而感到喜悦一样不合逻辑。
-   **理性视角**：对于长期净买入者，股价平平甚至是下跌才是对自身最有利的。伯克希尔视这种股价低迷为朋友，并希望所有股东理解这一运算思路。





## D.拆股与交易活动

### 一、为什么伯克希尔不进行股票分拆？

#### 1.1 核心目标：理性定价与高质量股东

伯克希尔的股价策略建立在两个相互支撑的基础之上：

| 目标           | 具体含义                                                     |
| -------------- | ------------------------------------------------------------ |
| **理性定价**   | 股价与内在商业价值相关联，在合理范围内波动（"理性相关"≠"完全一致"） |
| **高质量股东** | 吸引以企业主人心态长期持股、关注企业价值而非股价波动的投资者 |

> 💡 **核心逻辑**：股东质量决定估值质量。躁郁症式的投资者群体，只会带来躁郁症式的股价波动。

#### 1.2 如何吸引高质量股东？

股东筛选无法像阿斯特夫人管理精英圈子那样直接设门槛，但可以通过**持续、一致的理念传播**实现"自我选择效应"：

1. **明确宣传**商业哲学与股东理念，不发送矛盾信号
2. **政策与沟通**作为"广告"，吸引理解伯克希尔运营风格与期望的投资者
3. **同样重要**：主动阻止不适合的投资者进入

> 💡 **类比**：音乐会被包装为歌剧还是摇滚，自然吸引不同人群——即便任何人都可以买票入场。

**伯克希尔股东质量的实证：**

- 约 **90%~95%** 的股票由五年前就持股的长期投资者持有
- 这些投资者持有伯克希尔的市值，至少是其第二大持仓的 **2倍以上**
- 在市值超过10亿美元的上市公司中，伯克希尔在"让持股者像主人一样思考和行动"方面**几乎首屈一指**

#### 1.3 分拆的危害：稀释股东质量

⚠️ **分拆股份会引来逊于现有股东的新晋买家，稀释现有股东群体的质量。**

| 对比维度   | 分拆前                   | 分拆后                     |
| ---------- | ------------------------ | -------------------------- |
| 股东构成   | 思维清晰的长期价值投资者 | 混入大量短线、情绪化投资者 |
| 持股动机   | 关注企业价值             | 受分拆预期或低单价吸引     |
| 卖出行为   | 基于价值判断             | 基于非价值因素（加剧波动） |
| 股价稳定性 | 相对理性                 | 与企业基本面脱节的动荡     |

> ⚠️ **关键问题**：持有9张10元钞票，真的比持有1张100元钞票更富有吗？



### 二、过度活跃的股市：企业的扒手

#### 2.1 摩擦成本是一种隐性税

经纪商将高换手率美化为"市场性"与"流动性"，但投资者须清醒认识：

> **对赌场管理员有利的事，未必对赌客也有利。**

**量化示例：**

| 指标                     | 数值                             |
| ------------------------ | -------------------------------- |
| 典型公司净资产收益率     | 12%                              |
| 年换手率（假设）         | 100%                             |
| 交易摩擦成本（占净资产） | ~2%                              |
| 利润损耗比例             | **1/6**（相当于额外征税 16.66%） |

> ⚠️ 若政府新增 16.66% 的税种，必然引发强烈抗议——然而投资者通过市场"活跃"，正在**自我施加**同等税负。

#### 2.2 活跃度能优化资本配置吗？

部分观点认为高活跃度有助于资本配置理性化（"做大馅饼"论），巴菲特对此明确反驳：

| 观点                   | 立场                                     |
| ---------------------- | ---------------------------------------- |
| 活跃度提升资本配置效率 | ❌ 似是而非                               |
| 过度活跃市场的实际效果 | ✅ **破坏**理性资本配置，是**馅饼缩小机** |

#### 2.3 无形之脚 vs. 无形之手

| 概念         | 来源      | 含义                                                   |
| ------------ | --------- | ------------------------------------------------------ |
| **无形之手** | 亚当·斯密 | 自由市场中非合谋行为引导经济最优化                     |
| **无形之脚** | 巴菲特    | 赌场化市场中沉不住气的投资管理层，不断给经济进步使绊子 |





## E.股东策略与资本重构

### 一、股东策略（1992年）

#### 1.1 背景

伯克希尔股价突破 **10,000 美元/股** 后，部分股东在年度捐赠中遭遇税务困境：

| 捐赠金额  | 税务处理                                                     |
| --------- | ------------------------------------------------------------ |
| ≤ $10,000 | 完全免税                                                     |
| > $10,000 | 占用捐赠者**终身赠予税与遗产税免税额度**；额度耗尽后须缴纳赠予税 |

#### 1.2 股票捐赠避税的三种方式

**方式一：已婚夫妻联合捐赠**

- 适用对象：**已婚股东**
- 操作方法：夫妻双方每年可向单一受赠人合计捐赠 **$20,000**
- 前提条件：报税时须有配偶签字，同意当年的捐赠行为

------

**方式二：部分出售 + 部分捐赠（有条件交易）**

- 适用对象：已婚或未婚均可
- 示例（假设伯克希尔股价为 $12,000）：

```
目标捐赠金额：$10,000
操作方式：  将股票以 $2,000 出售给受赠人（差价部分作为捐赠）
免税效果：  捐赠部分 $10,000 仍在免税范围内
```

> ⚠️ **注意**：若出售价格超过你的税基，超出部分仍需纳税。

------

**方式三：成立合伙企业，逐年让渡权益**

- 适用对象：已婚或未婚均可
- 操作方法：与受赠人共同成立合伙企业，以伯克希尔股票出资，每年让渡不超过 **$10,000** 价值的合伙权益
- 优势：灵活控制每年让渡比例，长期免税捐赠

------

#### 1.3 三种方式对比

| 方式          | 适用人群 | 每年免税上限 | 操作复杂度 |
| ------------- | -------- | ------------ | ---------- |
| 夫妻联合捐赠  | 已婚股东 | $20,000      | 低         |
| 部分出售+捐赠 | 所有股东 | $10,000      | 中         |
| 合伙企业让渡  | 所有股东 | $10,000      | 高         |

> 💡 **提示**：涉及复杂捐赠结构时，请务必咨询**税务顾问**。

------

#### 1.4 关于股票分拆的立场

巴菲特与伯克希尔坚持**不分拆股份**的一贯政策，核心逻辑如下：

- 高股价筛选出了**理性、长期、具有企业主思维**的优质股东群体
- 股票换手率低，交易摩擦成本几乎为零
- 分拆引入的新股东**质量可能不及现有股东**，存在一定程度的"股东质量退化"风险
- 优质股东基础使伯克希尔股价能**长期贴近内在价值**运行

------

### 二、伯克希尔资本重构与B类股票（1995—1996年）

#### 2.1 资本重构方案

经股东年会批准，伯克希尔设立**两类股票结构**：

| 项目         | A类普通股（A股）            | B类普通股（B股）          |
| ------------ | --------------------------- | ------------------------- |
| 来源         | 现有股票重新指定            | 新发行                    |
| 经济权益     | 1股 = 1股                   | 1股 = **1/30** A股        |
| 投票权       | 1股 = 1票                   | 1股 = **1/200** A股投票权 |
| 慈善捐赠计划 | ✅ 可参与                    | ❌ 不可参与                |
| 转换权       | A → B：可随时转换为 30股B股 | B → A：**不可**反向转换   |
| 流通性预期   | **更高**（大多数股东持有）  | 相对较低                  |

#### 2.2 B股IPO关键信息

- **上市交易所**：纽约证券交易所（NYSE），与A股并列交易
- **募资规模**：至少 **1亿美元**（以招股说明书形式进行）
- **市场定价**：由市场决定，预计约为A股价格的 **1/30**
- **套利机制**：若B股价格高于A股的1/30，将触发A→B的套利转换，自动校正价格

> ⚠️ **巴菲特的估值表态**：写作本文时A股价格约为 $36,000，**芒格和巴菲特均认为此价格并无低估**，不在考虑买入价格范围内。本次发行不会稀释现有股份的内在价值。

------

#### 2.3 创立B股的核心动机

**直接动机：阻止"克隆伯克希尔"信托产品**

市场上出现了一种收取管理费的单位信托产品，声称能"低成本复制伯克希尔"。巴菲特认为此类产品存在严重问题：

1. **误导性营销**：利用伯克希尔过去无法复制的历史业绩吸引散户
2. **高额费用**：经纪人从中收取高佣金，成本转嫁投资者
3. **泡沫风险**：大量资金不加区分地涌入买入有限供给的伯克希尔股票，极易推高股价形成投机泡沫
4. **伤害品牌**：可能导致大量失望的间接股东，损害伯克希尔的声誉

**B股的优势对比**

| 对比维度         | 克隆信托产品         | 伯克希尔B股                     |
| ---------------- | -------------------- | ------------------------------- |
| 费用结构         | 高佣金、高管理费     | 发行佣金仅 **1.5%**（行业最低） |
| 发行机制         | 限量炒作，制造短缺   | **开放端口**，压制短期炒作      |
| 目标投资者       | 追逐历史业绩的散户   | 眼光长远的长期投资者            |
| 与伯克希尔的关系 | 间接持有，隔离管理层 | 直接持股，与管理层目标一致      |

------

#### 2.4 1996年两次重大股票发行

**第一次：B类股票IPO（1996年5月）**

- 承销方：**所罗门证券公司**
- 发行股数：**517,500股** B类股票
- 净集资金额：**5.65亿美元**
- 发行佣金：**1.5%**（普通股发行中有史以来最低）
- 最终结果：新增约 **40,000名股东**，大多数理解公司并认同长期愿景

**第二次：所罗门股票可转换票据（1996年下半年）**

- 承销方：所罗门证券公司
- 票据总面值：**5亿美元**（5年期）
- 实际募集：**4.471亿美元**
- 转换条件：每$1,000票据可转换为 **17.65股** 所罗门股票
- 赎回条款：可在3年期时连同孳息赎回
- 到期持有收益率：约 **3%**
- 若转换为股票，期间利息成本约 **1.1%**

------

#### 2.5 B股发行的成本与收益权衡

| 维度  | 影响                                         |
| ----- | -------------------------------------------- |
| 成本  | 股东人数增加带来更多行政处理成本             |
| 收益① | 为有捐赠需求的股东提供更便捷的低面额操作工具 |
| 收益② | 为希望"自行分拆"的股东提供解决方案           |
| 收益③ | 有效抑制克隆信托产品的商业化营销             |

------

### 三、核心投资理念总结

#### 3.1 关于股东质量

> 巴菲特认为，**股东政策比股东数量更重要**。伯克希尔的目标是聚集一批"像主人一样思考、像主人一样行动"的长期理性股东，而非追求广泛持有和高换手率。

#### 3.2 关于增长预期

巴菲特坦承伯克希尔的增长局限：

- **理想目标**：平均每五年使每股内在价值翻一番
- **现实约束**：庞大的资本基础（写作时市值约 **430亿美元**）构成增长的天花板
- **不切实际的目标**：从430亿美元增长至1,290亿美元（相当于GE的体量），短期内无法实现

#### 3.3 关于与所罗门的合作

巴菲特特别肯定了所罗门证券公司在两次发行中的表现——其投资银行团队完全理解并支持伯克希尔的目标，**主动放弃了按惯例可多赚约10倍的佣金收入**，将客户利益置于自身利益之上。
