### 第2章　财务与投资

#### 本章主线

本章讨论伯克希尔的投资与财务原则：把股票当作企业的一部分，估算内在价值，等待价格显著低于价值的机会；只在理解企业、信任管理层并拥有安全边际时出手；让时间、低成本和稳健的资产负债表为复利服务。

| 核心原则 | 实际含义 |
| --- | --- |
| 企业价值优先 | 先看长期盈利能力、竞争优势和管理层，再看市场报价。 |
| 市场服务于投资者 | 市场先生每天给出价格，但不负责告诉你企业值多少钱。 |
| 长期持有 | 只要企业持续创造价值、管理层可靠且价格不过高，就可以永久持有。 |
| 安全边际 | 估值只略高于价格时不买；价格必须给判断错误留下余地。 |
| 能力圈 | 只投资能够理解、能够判断长期经济特征的企业。 |
| 低杠杆、高流动性 | 不为多赚几个百分点，拿股东、客户和保险人的安全去冒险。 |

### 一、把股票当作企业：市场先生与永久持有

#### 1.1 价格低于价值时买入

1973年年中，伯克希尔以每股不到企业内在价值四分之一的价格买入《华盛顿邮报》（WPC）。当时市场市值约1亿美元，而合理估值约4亿～5亿美元。机会并不神秘：大多数分析师、经纪人和媒体管理者都能看见事实，差别在于是否愿意按价值而非市场情绪行动。

20世纪70年代初，许多机构投资者相信“市场完全有效”，认为公开信息已经充分反映在价格中，计算企业价值没有意义。巴菲特认为，市场通常有效与市场永远有效是两回事；把后者当成教条，反而会给坚持独立分析的人留下优势。

每次购买普通股时，芒格和巴菲特只问三件事：

1. 企业的长期经济前景如何？
2. 管理层是否有能力且诚实？
3. 买入价格是否合理？

他们把自己当作企业分析师，而不是短期行情、宏观经济或证券价格分析师。即使股票停止交易，只要企业继续创造价值，也不会影响投资判断；最终结果取决于企业本身的经营，而不是报价屏幕。

#### 1.2 “市场先生”寓言

格雷厄姆把市场报价比作一位名叫“市场先生”的合伙人：他每天都来报价，既愿意买你的股份，也愿意卖给你他的股份，但情绪极不稳定。

- 乐观时，他只看见好消息，报价高得离谱，生怕你抢走他的利润。
- 悲观时，他只看见坏消息，报价低得荒谬，担心你把股份甩给他。
- 他不介意被忽略；今天不交易，明天还会给出新报价。

市场先生的作用是提供价格和机会，不是提供智慧。价格越受情绪摆布，理性投资者越可能买到便宜资产；但前提是投资者比市场先生更了解企业。如果分不清谁是牌桌上的“倒霉蛋”，往往自己就是。

**核心启示：** 短期市场像投票机，反映资金和情绪；长期市场像称重机，最终会衡量企业真实经营成果。企业价值增长的速度比市场何时承认它更重要。

#### 1.3 永久持有的条件

伯克希尔通常不会因为股价上涨、持有时间过长或出现账面利润就卖出。出售的理由主要有三类：

| 情形 | 处理方式 |
| --- | --- |
| 市场价格明显高于企业价值 | 考虑卖出。 |
| 出现更便宜、自己更了解的机会 | 即使按价值或略低于价值卖出，也可调配资金。 |
| 企业回报前景良好、管理层优秀诚实、价格未高估 | 继续持有，期限可以是永久。 |

保险子公司持有的三只可流通股票被视为伯克希尔永久资产的一部分，即使价格高估也不轻易出售；只有在异常保险损失、确有必要补充资金时才可能减持。伯克希尔宁愿与信任和尊重的人合作，获得100%的回报，也不愿与不喜欢的人合作，换取110%的回报。

#### 1.4 买家应欢迎下跌

如果未来五年仍会净买入股票，股价下跌反而有利；只有准备近期卖出的人才应盼望上涨。伯克希尔股东大多通过公司留存利润间接储蓄：公司越便宜地买入企业和证券，股东的储蓄效率越高。

低股价还会提高被投企业回购的效果。同样的回购资金，在价格低时能买回更多股份，伯克希尔的所有权比例也会提高。可口可乐、《华盛顿邮报》和富国银行在低迷时期的回购，长期价值高于高价回购。

因此，看到“股市大跌，投资者亏损”的新闻时，应先区分撤资者和仍在积累资产的投资者：一个人的损失可能正是另一个人的低价机会。

### 二、套利：只在概率明显有利时下注

#### 2.1 套利的用途和边界

保险子公司偶尔用套利替代短期现金等价物。它保持流动性，又可能取得高于国债的回报，并能避免在长期投资标准不足时勉强出手。1988年，伯克希尔平均投入1.47亿美元，税前获利0.78亿美元。

传统套利是在不同市场同时买卖同一资产，赚取换算后的价差；现代“风险套利”则围绕已宣布的出售、合并、重组、清算或自我收购等事件获利。主要风险不是市场涨跌，而是事件未能按预期发生。

#### 2.2 四个必答问题

| 问题 | 要判断的内容 |
| --- | --- |
| 1. 事件发生的概率有多大？ | 承诺能否兑现，交易能否完成。 |
| 2. 资金会被占用多久？ | 持有期越长，年化回报越低，机会成本越高。 |
| 3. 是否可能出现更好的结果？ | 例如竞争性报价抬高收购价。 |
| 4. 预期落空会怎样？ | 反垄断、融资、财务错误、诉讼等失败情形的损失。 |

#### 2.3 案例：洛克伍德——买股票、卖可可豆

**问题是什么？** 1941年洛克伍德以LIFO（后进先出）计价持有可可库存。1954年可可价格从每磅5美分升至60美分以上，直接出售将产生接近收益50%的税负。

**分析过程。** 1954年税法允许企业在缩减业务时把库存分配给股东，免除LIFO利润税。洛克伍德终止可可奶油业务，宣布向股东分配1300万磅可可豆，并按80磅可可豆换1股的方式回购股份。巴菲特买入股票、换取仓单，再出售可可豆，成本只有几张地铁票。

**结论是什么？** 公司股价在公告前后从15美元升至100美元，尽管经营亏损严重，重组仍为股东创造了价值。

**启示是什么？** 资产处置、税制和资本结构有时比市盈率更能决定投资回报；套利必须理解交易条款和法律细节，而不是只看价格走势。该方案由当时32岁的杰伊·普利兹克设计，后来事实证明其后续股东也获益良多。

#### 2.4 案例：阿克塔——诉讼索赔带来的额外收益

**问题是什么？** 1981年9月28日，阿克塔董事会原则同意以37.50美元/股加美国政府红杉林索赔额的三分之二出售给KKR。阿克塔主营印刷和林业；政府1978年以分期方式购买1.7万英亩红杉林，已付0.979亿美元，但双方对6%单利还是更高复利存在争议。KKR的融资条件、房地产衰退和诉讼结果都可能导致交易失败。

**分析过程。** 伯克希尔依次评估：

- KKR过去的交易记录和融资能力；
- 即使KKR退出，阿克塔管理层是否仍会寻找买家；
- 红杉林索赔价值可能从零到全部之间变化。

伯克希尔以约33.50美元买入，八周买入40万股（约5%）；交易延期后又以约38美元买入，持股增至65万股（超过7%）。最终阿克塔接受另一家公司37.50美元/股并分享一半索赔额，股东于1982年6月4日收款。

**结论是什么？** 伯克希尔投入2290万美元，收到2460万美元，平均持有6个月，初步年化回报约15%。1987年两个委员会分别评估红杉林价值2.757亿美元、利率约14%的复利方案；1988年政府上诉前以5.19亿美元和解，伯克希尔又取得每股29.48美元、合计约1930万美元的额外收益，1989年还将收到80万美元。

**启示是什么？** 套利不是无风险交易。必须把事件概率、融资、替代买家、诉讼尾部价值和持有期限放在同一张概率表里。伯克希尔每年只做少数大额套利，只依据公开信息，不听谣言、不猜测潜在收购方。

#### 2.5 套利与市场有效理论

市场有效理论认为公开信息已反映在股价中，随机投掷飞镖选出的组合也能胜过专业分析师。伯克希尔认为，“市场通常有效”不能推出“市场永远有效”。格雷厄姆—纽曼公司1926～1956年套利去杠杆后平均年化约20%；1956～1988年，巴菲特合伙公司和伯克希尔的套利平均回报也超过20%。63年间市场含分红的年化回报略低于10%，1000美元复利后约40.5万美元；若年化20%，则约9700万美元。

要公平评价这段记录，必须满足四点：交易过数百种证券；结果没有被少数幸运事件扭曲；只使用公开事件信息；套利范围在事前就明确，不靠事后挑选样本。

**警告：** 套利不保证每年20%的收益。超额回报来自认真评估事实和持续纪律，而不是某个投资风格的标签。很多看似容易的机会，价格已充分反映预期；只有胜券在握时才值得出手。

### 2.6 RJR·纳贝斯克：公开信息与身份约束

伯克希尔曾持有334.2万股RJR·纳贝斯克，成本281.80美元/股，年末市值约3.045亿美元；次年1月增持至约400万股，2月全部出售。KKR接受其中约300万股，其余股份在市场上迅速卖出，伯克希尔税前获利6400万美元。

这笔交易还说明了信息边界的重要性。芒格和巴菲特是所罗门公司的董事，通常会因董事身份被隔离于收购信息之外；在RJR交易中，所罗门允许所有董事获得完整信息并参与，伯克希尔因此只能在管理层公布收购计划后、以及RJR董事会接受KKR方案后两个时点买入。董事身份没有带来内幕优势，反而限制了交易时机和规模。

1989年伯克希尔几乎没有开展套利。并购和杠杆收购过度繁荣，融资方和买家表现出的乐观可能不可持续。别人越不谨慎，伯克希尔越要谨慎；只有交易本身有清晰经济意义，而不是“谁是更傻的傻瓜”游戏时，才会出手。

### 三、风险不是波动：理解、集中与分散

#### 3.1 不要把贝塔当成风险

学术定义常把风险等同于相对波动率（贝塔）。但对企业所有者而言，真正的风险是：在预期持有期内，税后现金流和出售所得无法维持初始购买力并获得合理回报。

风险评估应关注：

1. 企业长期经济特征能否保持；
2. 管理层能否实现企业潜力并合理配置现金；
3. 管理层是否把股东利益置于个人利益之上；
4. 买入价格；
5. 通胀和税收对购买力的侵蚀。

股票下跌可能意味着风险下降：1973年《华盛顿邮报》跌得越多，以巨大折扣买入整家公司的人越安全。相反，在评估风险的时候，一个追求贝塔的纯粹主义者会不屑于调查公司的产品、竞争力如何或公司的负债情况，他所重视的不过是该公司股票的历史价格，股价越低时买入，按照贝塔理论"风险"竟变得更大。

可口可乐约占全球软饮料市场44%，吉列按价值计占刀片市场超过60%；品牌、产品、分销构成护城河。它们的贝塔可能与普通公司相近，却不代表商业风险相同。

#### 3.2 何时集中，何时分散

| 投资者情况 | 更合适的做法 | 原因 |
| --- | --- | --- |
| 不懂企业，只想获得市场平均回报 | 低成本指数基金，分期、广泛分散 | 承认局限，降低单一企业风险。 |
| 能理解5～10家具有长期优势且价格合理的公司 | 集中持有最有把握的标的 | 把资本放在最了解、风险最低、回报潜力最大的企业。 |
| 单笔事件风险很大，但各事件相互独立 | 广泛分散套利 | 用概率论降低组合风险，类似赌场偏好大量小注而非单次巨注。 |

集中投资并不等于鲁莽；前提是投资者真正了解企业。传统多元化若把资金分配给第20名而非最了解的前5名，可能同时降低收益、增加判断错误。伯克希尔希望永久持有大都会/ABC、盖可保险和《华盛顿邮报》，如同全资持有禧诗糖果和《水牛城新闻报》一样。

约翰·梅纳德·凯恩斯在1934年给商业合伙人的信中写道：随着经验增加，他越来越确信，正确的投资方式是把相当分量的资金投向自己了解、并充分信任管理层的公司。广泛投资于知之甚少的企业，并不会自动降低风险；在任何时点，真正值得高度信任的公司可能只有两三家。

集中持股会使少数明星资产贡献大部分收益，这并不是问题。若拥有一支大学篮球队20%的权益，少数球员进入NBA后自然会贡献大部分收入；因为明星得分多就把他们卖掉，等同于让公牛队卖掉迈克尔·乔丹。

### 四、价值、成长与现金流

#### 4.1 “价值投资”并不是特殊类别

购买控制权公司和购买上市公司少数股权，本质相同：都要寻找经济前景好、管理层可靠、价格合理的企业。目标是“合理价格的杰出公司”，而不是“便宜价格的平庸公司”。巴菲特早期买入纺织厂、三流百货和短线农具厂，因贪图便宜而受到教训。

“价值”和“成长”不是互斥风格。成长只有在新增投资每投入1美元，长期创造超过1美元市场价值时才有利；低回报企业越成长，越会吞噬股东资本。国内航空业就是反例：行业规模扩大，并未保证股东获利。

#### 4.2 价值方程式

> 任何股票、债券或公司的价值，都取决于其预期存续期内的现金流入和流出，并按合适利率折现到今天。

债券的票息和到期日较明确；股票的“票息”需要分析师估计，管理层能力、诚信和资本配置会直接改变未来现金流。因此，投资者应买入折现现金流最便宜的资产，不必拘泥于是否成长、盈利是否平稳、股价相对市盈率或账面值是否高低。若债券更便宜，就应买债券。

最值得拥有的企业，是能在很长时期用新增资本获得高回报的企业；最差的企业则持续吞噬大量资本却只能获得低回报。伯克希尔用两道防线应对估值误差：只研究经济特征简单、稳定的企业；买入时保留足够安全边际，估值只略高于价格时不买。

#### 4.3 二级市场比IPO更可能出现便宜货

二级市场会被恐慌或强制卖出主导，偶尔把价值X的股票打到半价；IPO由控股股东和公司选择时机，卖方通常不会主动折价，市场高估时反而更愿意发行。伯克希尔曾以172.50美元/股认购300万股大都会/ABC，帮助其筹集35亿美元收购ABC。虽然ABC短期经济表现不激动人心，伯克希尔仍相信管理层并愿意等待。

伯克希尔还允许汤姆·墨菲或丹·伯克代行投票权，并限制未经管理层同意向大买家出售股份。看似牺牲控制权溢价，实际换来管理层专注长期经营、减少“旋转门式”资本的干扰。1985年以172.50美元重新买入，也提醒投资者：企业质量和管理层可信度有时比过去的买卖价格更重要。

### 五、长期持有：变化中的不变因素

#### 5.1 寻找可预测的竞争优势

伯克希尔偏好未来10～20年仍能保持优势的企业。它欢迎科技、产品和社会变化，但不会投资自己无法预测长期经济特征的快速变化行业。

禧诗糖果自1920年创立后，品种、机器和渠道都变了，但人们为何购买盒装巧克力、为何选择禧诗的原因基本不变。可口可乐同样如此：1896年销售额14.8万美元、销量116,492加仑，1996年销量约3.2亿加仑；品牌热爱、分销能力和产品优势跨越百年。

可口可乐1938年售出2.07亿箱，1993年107亿箱，实体销量增长约50倍。1919年投入40美元，分红再投资到1938年约3277美元；即使1938年才投40美元，到1993年仍可增至约25,000美元。这说明优秀企业不必依靠频繁买卖就能复利。

#### 5.2 追高的代价与管理层失焦

好企业也可能因价格过高而需要很久才能产生相称价值；管理层若离开核心业务，收购平庸企业，损害会更持久。可口可乐曾养虾，吉列曾涉足石油，说明“伟大公司”不是免检标签。投资者应持续检查管理层是否保持专注、谦逊和股东导向。

大多数个人和机构投资者更适合低成本指数基金。若自行选股，只需掌握两门课：评估企业价值、正确对待市场价格。选定一家能看懂、未来5～20年盈利大概率增长的企业后，应在价格合理时大幅买入；如果不打算持有10年，就不必持有10分钟。

投资表现不佳通常来自三项：高交易和管理成本；听信股评与市场潮流而不分析企业；牛市追入、熊市退出。亢奋与成本都是敌人。若必须择时，应在别人贪婪时谨慎、在别人恐惧时寻找机会。

能力圈的边界比大小更重要。对高科技、专利、复杂制造或地质勘探没有判断力，就承认不知道；伯克希尔宁愿错过机会，也不愿用一厢情愿替代理性。

### 5.3 股市波动何时会伤害投资者

1987年道琼斯指数全年只上涨2.3%，但经历了先狂涨、后暴跌的过山车行情。许多职业投资者关注的不是企业未来几年如何经营，而是其他基金经理未来几天会做什么；股票被当成游戏筹码。

“投资组合保险”就是这种思维的极端例子。1986～1987年，许多顾问要求养老基金和大学基金在股价下跌时不断卖出股票或指数期货，跌得越多卖得越多，反弹后再买回。根据《布雷迪报告》，1987年10月中约有600亿～900亿美元股票处于这种自动卖出状态。它把小投机者的止损单包装成复杂术语，却让巨量卖单在同一时点集中出现。

市场波动不会天然伤害小投资者。只要投资者坚持自己的系统，机构被迫交易反而提供更多低价机会。真正受伤的是因财务压力或心理压力而被迫卖出的人，就像理性农场主不会因为邻近农场降价，就在不看自身价值的情况下出售自己的农场。

### 5.4 等待落在“最佳格子”的球

棒球名将泰德·威廉姆斯把击球区划成77个格子，只有击打落在最佳格子的球，才有机会取得0.400的成绩；对最差位置的球挥棒，成绩可能降至0.230。投资者也不必对每个机会挥棒：错过三次坏球不会被罚下场，但在没有好价格时强行投资，会把回报锁在低水平。

伯克希尔不会预测下个月或下一年的市场。理想机会可能暂时不存在，等待也许令人无聊，但投资者拥有棒球运动员没有的优势：可以一直站在本垒，直到真正值得出手的价格出现。

### 六、从“捡烟蒂”到优秀企业：避免机构惯性

#### 6.1 “捡烟蒂”为什么会失败

“捡烟蒂”是以极低价格买入糟糕企业，期待清算或反弹带来最后一口利润。它的问题有二：

1. 所谓便宜可能是错觉。困难企业往往一个问题接着一个问题，如厨房里有一只蟑螂，通常不会只有一只。
2. 时间会侵蚀初始折扣。800万美元买入、立即以1000万美元清算可能是好交易；若十年后才以1000万美元退出，即使期间有少量分红，回报也很差。

巴菲特收购霍克希尔德·科恩百货时，账面资产折价、员工优秀、还有未入账地产和LIFO存货，看似安全，三年后却只能按买入价卖出。**时间是优秀企业的朋友，是平庸企业的敌人。** 优秀骑手只有在良马上才能取得好成绩；再能干的管理层，也很难让经济特征糟糕的企业脱离流沙。

#### 6.2 解决困难企业不如避开困难企业

25年的收购和管理经验只教会伯克希尔一件事：不要幻想自己能解决所有困难企业。寻找能跨过1英尺栏杆的机会，比证明自己能跨过7英尺栏杆更有价值。只有在一次性、可解决的问题压低优秀企业价格时，才值得例外出手；总体原则是避开怪兽，而不是试图杀死它。

#### 6.3 “机构强迫症”的四种表现

企业误入歧途往往不是因为腐败或愚蠢，而是惯性驱使：

1. 机构像受牛顿第一定律支配一样，抗拒改变既有方向；
2. 项目和收购不断扩张，耗尽全部现金和管理注意力；
3. 领导人想做的项目，无论多愚蠢，都会得到下属精心编写的回报论证；
4. 同行扩张、并购、设计薪酬，企业便不加思考地照抄。

伯克希尔努力降低惯性影响，并选择对它保持警惕的管理层。管理层值得尊敬是必要条件，但不是充分条件：二流纺织厂不会因老板讨人喜欢就变成好企业；真正理想的组合是可靠的人与优秀的经济特征。与不值得尊敬的人做成一笔好生意，伯克希尔从未成功。

#### 6.4 错过机会与拒绝高杠杆

最昂贵的错误有时不是买错，而是看懂了却没有买。错过能力圈外的机会并不可耻，但错过眼前、自己完全理解的重大机会，代价极大。

伯克希尔长期保守的财务政策，可能少赚一些钱，但避免了99%概率获得更高回报、同时承担1%概率走向违约的赌局。芒格和巴菲特不接受这种99∶1的风险，因为一次小概率灾难足以抹去长期复利。

### 七、生命、负债与信用

#### 7.1 债务的有限用途

伯克希尔只在三类情形使用少量债务：

| 用途 | 限制 |
| --- | --- |
| 参与美国政府或其代理机构的回购 | 作为短期投资策略。 |
| 对冲投资组合中的付息应收账款 | 必须充分了解风险特征。 |
| 子公司自然产生的债务 | 如中美能源公司，伯克希尔不为其提供担保。 |

多元化公用事业组合即使利息覆盖率为2∶1，也比单一公用事业安全；中美能源收入来源分散，区域灾害难以同时摧毁全部盈利，因此其负债可以服务于稳定增长。伯克希尔母公司则不愿用重大负债收购或经营企业。

#### 7.2 杠杆会放大归零风险

债务到期时能否再融资，往往取决于市场是否仍提供信用。一旦市场资金短缺，延期失败，只有现金能救企业。信用像氧气：充足时不被注意，消失时才发现不可替代。2008年9月，信用在一夜之间冻结，许多行业濒临崩溃。

杠杆既放大收益，也放大损失，并且容易让人上瘾。2008年再次证明：任何多大的正数，只要乘以零，结果仍是零。高负债公司假设债务到期后自然能续借，一旦假设失效，资本结构会迅速从“安全”变成违约。

#### 7.3 流动性是对股东和客户的承诺

伯克希尔股东、董事、管理层、慈善机构和保险客户都把重大责任交给公司。保险赔偿可能持续50年甚至更久；公司还承保高额单次灾难风险。因此，为多赚几个百分点而危及整体安全是不负责任的。

伯克希尔通常至少持有100亿美元现金，使命需要时保持约200亿美元；现金主要投资美国政府国债，而不是为多几个百分点去承担不透明的短期证券风险。公司不依赖银行信用额度，不签署需要担保的合同，除非金额相对于流动资产极小。

过去40年，伯克希尔没有分红或回购股票，而是留存全部盈利，净资产从4800万美元增至1570亿美元，内在价值增长更多。稳健流动性让公司在别人被迫出售时拥有出击能力：2008年雷曼破产恐慌25天后，伯克希尔投资156亿美元。

**核心启示：** 财务安全不是闲置资本，而是长期选择权。只有不被债务和流动性危机逼到墙角，投资者才能在真正便宜的机会出现时行动。
