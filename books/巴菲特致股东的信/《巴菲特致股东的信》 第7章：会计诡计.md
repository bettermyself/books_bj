### 三、六大技巧详解

#### 3.1 固定资产记减至负10亿美元

```markdown
操作逻辑：
- 传统做法：厂房设备减值至$1 → 降低折旧费用
- "创新"做法：减值至 -$10亿 → 折旧变"增值"

计算示例：
- 原折旧费用：$4,700万/年
- 新"增值"收益：5% × $10亿 = $5,000万/年
- 净提升：$4,700万 + $5,000万 = **$9,700万/年**
```

> ⚠️ **逻辑漏洞**：资产为负值违背会计基本准则，"增值"实为账面游戏。

#### 3.2 普通股面值减少到$0.01

- **目的**：为股票期权薪酬方案提供操作空间
- **法律备注**：因在弗吉尼亚州重新注册，"声明价值"≠"面值"

#### 3.3 用股票期权支付所有薪酬 💡

| 优势维度       | 具体效果                                               |
| -------------- | ------------------------------------------------------ |
| **成本消除**   | 工资账单归零，年节省 **$2.5亿**                        |
| **员工激励**   | 每股盈利"提升"→股价>行权价$50→期权价值远超现金薪酬     |
| **账面利润**   | 行权时每股产生$49.99所得，计入**资本盈余**（非损益表） |
| **现金流逆转** | 从年流出$2.5亿工资 → 年流入$2.5亿行权资金              |

```python
# 期权行权现金流模拟（伪代码）
def cash_flow_impact(shares_exercised, exercise_price, par_value):
    cash_inflow = shares_exercised * exercise_price
    capital_surplus = shares_exercised * (exercise_price - par_value)
    return {
        "现金流入": cash_inflow,
        "资本盈余增加": capital_surplus,
        "损益表影响": "无"  # ⚠️ 关键：利润不体现在当期收益
    }
```

> 💡 **讽刺点**：通过会计分类将真实现金流包装为"额外利润"。

#### 3.4 将存货记为$1

```markdown
操作流程：
1. 期初存货估值：$1（无论实际价值）
2. 年内销售：按市场价确认收入 → 产生"超高毛利"
3. 年末调整：从应急储备金中提取资金"补平"存货减值

声称效果：
- 规避存货跌价损失
- 年度盈利提升 ≥ $1.5亿
- 储备金支出 ≈ 盈利提升额 → 账面"自洽"
```

> ⚠️ **审计备注**：应收账款与现金未同步"象征化"，因审计规则要求回收款计入资本盈余而非当期收益。

#### 3.5 零息债券置换优先股

| 置换要素      | 原方案（优先股） | 新方案（零息债券）            |
| ------------- | ---------------- | ----------------------------- |
| 面值          | 每股优先股       | $300/张债券                   |
| 赎回方式      | -                | 抽签+50%面值+10年期等额赎回   |
| 年度赎回额    | -                | $1.08亿面值 → 实际支付$0.54亿 |
| 年度"利润"    | -                | **$0.54亿**（赎回差价）       |
| 股息/利息支出 | $2,500万/年      | $0（零息）                    |
| 净收益提升    | -                | **$7,900万/年**               |

#### 3.6 建立$10亿应急储备金

```markdown
功能定位：
✅ 吸收存货$1入账产生的年度减值
✅ "覆盖"任何潜在经营亏损
✅ 维持方案表面可持续性

补充机制：
- 来源：股票期权行权产生的资本盈余（≥$2.5亿/年）
- 流向：应急储备金
- 效果：储备金"永不枯竭"的账面幻觉
```

> ⚠️ **本质**：用资产负债表科目间的转移掩盖真实盈利能力。

## B. 标准的设定

#### 1.1 安达信的立场转变

**安达信会计事务所**（Arthur Andersen）曾是审计行业的权威标杆。其内部由行业精英组成的**专业标准小组（PSG）** 长期坚持财务报表必须如实编制。

**1992年 PSG 的核心立场：**

- 坚持将**股票期权成本列为费用**
- 不向客户压力妥协

然而，受另一批"呼风唤雨"合伙人的推动，PSG 立场发生 **180° 大转弯**——这些合伙人深知客户真正想要的是更高的账面盈利。

> 众多 CEO 同样反对期权费用化，原因在于：一旦落实，他们渴望已久的大额期权授予将大幅缩水。

---

#### 1.2 FASB 的抗争与妥协

| 事件                                    | 结果                        |
| --------------------------------------- | --------------------------- |
| FASB 以 **7:0** 投票通过期权费用化      | 独立标准确立                |
| 大型会计事务所与众多 CEO 涌入华盛顿游说 | 向参议院施压，试图废除 FASB |
| 参议院以 **88:9** 投票反对期权费用化    | ⚠️ 标准独立性严重受损        |
| 证监会主席阿瑟·莱维特迫于压力妥协       | 事后坦承为任内最大遗憾      |

💡 相关细节可参考莱维特著作《**挑战华尔街**》。

游说资金本属于被欺诈公司的股东，却被用于政治献金——**这不应是文明社会应有的现象**。

---

#### 1.3 "荣誉系统"的败局

面对参议院威胁，FASB 最终退缩，转而推行**"荣誉系统"**：

- 声明期权费用化为**优先建议**
- 但允许公司依自身情况**选择忽略**此成本

**结果：**

| 标普500大公司 | 选择                             |
| ------------- | -------------------------------- |
| **498家**     | 采用较不理想的方法，美化账面盈余 |
| **2家**       | 遵循费用化原则                   |

> FASB 得到了"荣誉"，而 CEO 们赢得了整个系统。

---

#### 1.4 影响与后果

参议院被收买、证监会失守之后，美国企业界意识到：**在会计处理上可以为所欲为**。

- 一个以**"盈利报告至上"**为核心的新时代由此开启
- 部分著名审计师在背后推波助澜
- 放肆的财务行为迅速成为**大泡沫时代**的助燃剂



## C. 股票期权

#### 1.1 核心争议：期权是否应计为成本？

在公司管理层和会计师的种种失真行为中，**股票期权的会计处理**是最令人震惊的问题。数十年来，众多企业持续与会计规则制定者博弈，试图避免将期权成本反映在公司账面上。

管理层的常见借口如下：

| 借口                                 | 反驳                                           |
| ------------------------------------ | ---------------------------------------------- |
| 期权难以估值，成本应忽略             | 不精确不等于不存在，折旧、坏账同样无法精确量化 |
| 费用化会伤害初创公司                 | 成本客观存在，不记录只是转嫁给股东             |
| "价外"期权发行时没有价值             | 巴菲特表示愿意收购任何管理层的"无价值"期权     |
| 期权"不来自公司金库"，非现金即非成本 | 以期权支付广告费，难道广告成本就消失了？       |

> 💡 巴菲特的反驳：若"无现金即无成本"成立，盖可保险可用伯克希尔期权支付1.9亿美元广告费——没有人会认为这笔广告成本不存在。

---

#### 1.2 通用再保险收购案：会计缺陷的实证

伯克希尔收购**通用再保险**一案，清晰暴露了现行会计准则的缺陷。

**关键数据（见股东委托书第60页）：**

- 收入预测表中，报酬成本一项上升 **6300万美元**
- 原因：将原有**期权激励计划**改为**现金激励计划**

| 对比维度     | 期权激励计划   | 现金激励计划 |
| ------------ | -------------- | ------------ |
| 激励基础     | 公司股票价格   | 个人工作业绩 |
| 经济效果     | 相同           | 相同         |
| 会计处理     | **不计入成本** | **计入成本** |
| 账面盈利影响 | 虚高           | 真实反映     |

⚠️ 两种计划经济效果完全相同，却产生截然不同的会计结果——这正是"爱丽丝漫游仙境"式的会计失真。

---

#### 1.3 期权成本的估值逻辑

**期权并非难以估值**，巴菲特的核心论点：

1. 不精确不等于不应确认——折旧率、坏账准备同样不精确，但从未被忽略
2. 带限制条件的期权增加了估值难度，但**不消除估值的可能性**
3. 相比估算747飞机折旧率，给期权定价的把握**更大**

> 如果某位 CEO 声称新发期权"几乎没有价值"，巴菲特的回应是：**请把它们发给伯克希尔。**

---

#### 1.4 员工期权 vs. 公开市场期权

针对"员工期权价值低于市场期权"的说法，巴菲特的分析：

| 论点                           | 事实                                        |
| ------------------------------ | ------------------------------------------- |
| 员工期权可能失效，损害较小     | 员工期权经常被**重新定价**，实际成本更高    |
| 公司可获得员工行权时的免税额度 | 重新定价的对冲使整体成本不减反增            |
| 不可转让期权对员工价值更低     | 对员工价值低 ≠ 对公司成本低（如专用公务车） |

**巴菲特的调整实践：**

- 近年来，期权盈利调整常将每股盈利减少 **5%～10%**
- 调整幅度有时大到影响投资决策，进而调整买卖价格

---

>
> "如果这种报酬不是一种**费用**，那么它是什么？"
>
> "如果公司在计算盈利时不包括这种费用，那么它应该放在**什么地方**？"

#### 1.6 政治博弈与监管历程

| 时间          | 事件                                            |
| ------------- | ----------------------------------------------- |
| 1993年        | CEO 们首次向国会施压，推动期权会计豁免立法      |
| 2003～2005年  | SEC 主席比尔·唐纳森顶住政治压力，坚持投资者立场 |
| 2005年6月15日 | **期权计入成本强制生效**                        |

⚠️ 国会中的帮凶蔑视四大会计师事务所、FASB 全体成员及所有投资专业人士的质疑，游说所用资金本质上属于股东。

---

#### 1.7 合理的期权设计原则

巴菲特与芒格并不反对使用期权，而是主张**合理设计**：

1. 具有**合理的行权价格**
2. 行权价格应随公司**留存利润**进行相应调整
3. **禁止**获得期权后立刻抛售股票

> 💡 对于能够激励经理人的奖励措施，无论现金还是期权，均举双手赞成。关键在于：**如实记录成本，而非掩盖成本。**

---

#### 1.8 结论

将股票期权处理为无成本，是 CEO 们夸大盈利最重要的会计手法。其本质是：

- **会计原则给了管理层选择权**：支付报酬且计成本，或支付报酬但忽略成本
- CEO 们深知，一旦如实记录，其薪酬将被理性压缩，行权套现价格也将下降
- 用于游说的资金，**按理说属于股东，而非管理层**



## D. "重组"费用

> 正如媒体人迈克尔·金斯利（Michael Kinsley）所言：**"所谓丑闻，并不在于非法的勾当，而是在于合法的勾当。"**

### 二、会计诚信的历史演变

#### 2.1 过去与现在的对比

| 时期                | 特征                                       | 结果                                               |
| ------------------- | ------------------------------------------ | -------------------------------------------------- |
| 20 世纪 60 年代后期 | 流行"大胆、想象丰富的会计"风潮             | 投资者能识别谁在玩游戏；最受尊敬的公司普遍回避欺骗 |

#### 2.2 高管行为的根本动机

- 核心前提：**将股票价格在任何时候维持在尽可能高的水平**
- 路径一（可接受）：努力取得杰出运营结果以提升股价
- 路径二（不可接受）：当运营无法达标，转而使用**会计诡计**制造理想"盈利"或为将来造假创造条件

#### 2.3 常见的自我合理化逻辑

1. "股票未被充分定价，股东利益受损"
2. "使用会计手段没有不对，因为**每个人都这么做**"

⚠️ 一旦"每个人都这么做"成为心安理得的事实，道德疑虑便会消失殆尽。

> **格雷欣法则的子规则（Son of Gresham）：劣会计驱逐良会计。**

### 三、"重组费用"的运作机制

#### 3.1 基本定义

**重组费用**是一个合法的会计条目，但经常被用作操纵盈利的工具：将本应合理分配到数年期间的大额成本，**集中倾泻到单一季度**——通常是那些已注定令投资者失望的季度。

#### 3.2 两种典型用途

| 用途             | 说明                                   |
| ---------------- | -------------------------------------- |
| 清理过去的错误   | 将历史亏损一次性出清，为未来"轻装上阵" |
| 为未来错误留余地 | 提前计提，日后释放准备金充当"利润"     |

💡 无论哪种情形，费用发生的**规模与时间**背后，都有令人质疑的支配力量。

### 四、高尔夫比喻：两种造假策略

#### 策略一：先"大洗澡"，后持续超预期

| 轮次    | 实际得分 | 造假得分                      |
| ------- | -------- | ----------------------------- |
| 第 1 轮 | 91       | **140**（集中倾泻所有"坏洞"） |
| 第 2 轮 | 94       | 80                            |
| 第 3 轮 | 89       | 80                            |
| 第 4 轮 | 94       | 80                            |
| 第 5 轮 | 92       | 80                            |

华尔街的反应：忽视开头的 140 杆（"不持续"），将其归类为**永远不会令人失望的"80 分稳定型球手"**。

#### 策略二：先虚报佳绩，后集中"纠错"

先连续四场报告 80 杆的好成绩，赢得掌声后，再亮出第五场 140 杆的"大洗澡"记分卡——之前舞弊所得的不义之财，绝不退还。

> 正如伏尔泰（Voltaire）所言：**"一次是哲学家，两次是变态。"**

⚠️ 现实中，喜欢篡改记分卡的 CEO 往往会上瘾——毕竟，**篡改记分卡比苦练容易得多**。

### 五、并购领域的"重组艺术"

#### 5.1 常见手法

管理层利用合并机会，对资产和负债进行不诚实的包装，目的是**平滑并增厚未来利润**。

**财险公司收购案例：**

1. 收购完成后，买家立即大幅提高损失准备金
2. 声称是"反映之前准备金不足"
3. 待收购完成一段时间后，将准备金**释放为"利润"**流入利润表

> 在收购合约墨迹未干时就出现如此精准的精算"启示"，多少令人不可思议。

#### 5.2 真实对话实录

> 两位大型银行 CEO 讨论一项并购案，其中一位问："你不认为这项并购会发生巨额费用吗？也许会达到 10 亿美元？"
>
> 经验丰富的老手答道：**"我们可以将费用做得更大，这就是我们要做这种并购生意的原因。"**

## E. 退休福利估计

### 一、问题的核心：回报假设虚高

在计算退休金费用时，**回报假设**是最关键的变量。标普 500 成分股中有退休金计划的公司，普遍选择了脱离现实的高假设回报率。

| 统计项目                            | 数据   |
| ----------------------------------- | ------ |
| 标普 500 中拥有退休金计划的公司数量 | 363 家 |
| 2006 年平均假设回报率               | **8%** |

---

### 二、8% 假设回报率的可行性分析

#### 2.1 资产配置现状

| 资产类别                     | 占比 | 预期回报率      |
| ---------------------------- | ---- | --------------- |
| 债券与现金                   | 28%  | ≤ 5%            |
| 股票（含对冲基金、私募基金） | 72%  | 需达到 **9.2%** |

> 要使整体达到 8% 的假设回报，权益类资产必须取得 **9.2% 的净回报**（扣除所有费用后）。

⚠️ 9.2% 的要求远超这些资产过去的历史成绩。

---

#### 2.2 历史数据的现实检验

**20 世纪道琼斯指数表现：**

| 指标            | 数值      |
| --------------- | --------- |
| 起点（1900 年） | 66 点     |
| 终点（1999 年） | 11,497 点 |
| 折合年化回报率  | **5.3%**  |
| 末期股息率      | 约 2%     |

**21 世纪若要复制 5.3% 年化回报，道琼斯指数需达到：**

| 时间节点                  | 所需点位                        |
| ------------------------- | ------------------------------- |
| 2099 年 12 月 31 日       | **2,000,000 点**                |
| 当前（已入 21 世纪 8 年） | 约 13,000 点，涨幅不足 2,000 点 |

💡 若有人预测 21 世纪年化回报达 10%（2% 分红 + 8% 股价上涨），则意味着道琼斯指数到 2100 年需达到 **2,400 万点**。

---

#### 2.3 权益资产的实际回报上限估算

即便维持 20 世纪的历史水平，退休基金中权益资产部分的回报也难以达标：

| 收益来源                 | 贡献率   |
| ------------------------ | -------- |
| 股价年化上涨（历史水平） | 5.3%     |
| 股息率                   | ~2.0%    |
| 合计毛回报               | ~7.3%    |
| 减：成本费用（保守估计） | -0.5%    |
| **净回报上限**           | **≈ 7%** |

⚠️ 0.5% 的成本已属保守估计，实际顾问与投资经理费用往往更高。

---

### 三、"帮忙的人"的数学悖论

所有投资者都希望获得超出平均的回报，而"帮忙的人"（顾问、投资经理）也乐于鼓励这种期望。但逻辑上，这是不可能的：

1. **投资者整体** 只能获得市场平均回报，减去总成本
2. **被动/指数投资者** 获得平均回报，减去极低成本 → **净回报较高**
3. **积极投资者** 承担高额交易费、管理费、顾问费 → **净回报必然低于被动投资者**

> 结论：**"什么都不知道"的被动投资者，一定会胜出。**

---

### 四、对投资顾问的警示

> 正如《绿野仙踪》中皇后的台词：**"为什么，有时在早饭之前，我已经相信了六件不可能的事情？"**

⚠️ 警惕那些承诺两位数回报的顾问——他们在往你脑子里灌输幻象的同时，也在往自己口袋里装佣金。

**检验方法：** 若投资顾问声称可取得年化 10% 回报，请告知他道琼斯指数届时需达到 **2,400 万点**，观察其反应。

### 五、美国与非美国退休金假设的矛盾

部分公司在欧洲等地区同样设有退休金计划，但其回报假设却与美国存在明显差异：

| 地区       | 假设回报率 |
| ---------- | ---------- |
| 美国计划   | 普遍较高   |
| 非美国计划 | 普遍较低   |

这种不一致从未得到合理解释，而负责审核这些假设的**审计师与精算师**，也从未对此提出异议。

## F.账面盈利的实现问题

### 一、核心观点：净利润指标的局限性

**净利润**是媒体最为关注的财务指标，但在伯克希尔，这一指标**几乎毫无意义**。

#### 1.1 为何净利润可被"操控"？

巴菲特与芒格拥有合法调节净利润的灵活度，原因在于：

| 类型                                | 处理方式         | 是否进入损益表 |
| ----------------------------------- | ---------------- | -------------- |
| **已实现**账面盈亏（买卖变现）      | 主动选择变现时机 | ✅ 计入净利润   |
| **未实现**账面盈亏（持仓浮盈/浮亏） | 大多数情况为亏损 | ❌ 不计入净利润 |

#### 1.2 典型场景举例

> 假设某年度伯克希尔同时存在以下两项：
>
> - 未变现账面所得：**100亿美元**
> - 已实现亏损：**100亿美元**

**结果**：净利润仅反映亏损，低于运营利润，但企业真实状况可能已大幅改善。

💡 若同时在上一年度变现所得，媒体标题可能是：**"利润下降了X%"**——而这与企业实际经营毫无关联。

---

### 二、伯克希尔的原则立场

#### 2.1 从不"数字游戏"

尽管伯克希尔账面上存在**巨大的未变现所得**可供利用，巴菲特与芒格明确承诺：

- ⚠️ **从不**因临近财报公布期而大幅出售证券以美化账面
- 对"数字游戏"行为极其厌恶
- 此类行为在20世纪90年代极为猖獗，现虽减少但依然存在

---

### 三、推荐关注指标：运营利润

| 指标         | 推荐程度   | 说明                                          |
| ------------ | ---------- | --------------------------------------------- |
| **运营利润** | ⭐ 强烈推荐 | 整体而言较合理地反映企业运营状况              |
| 净利润       | ❌ 可忽略   | 受实现/未实现盈亏影响，易被误导；监管要求披露 |

#### 3.1 账面价值的完整性

> 无论是**已实现**还是**未实现**的账面盈亏，均会**完整反映**在伯克希尔的**账面价值**计算中。

💡 **正确的分析路径**：持续关注**运营利润的构成与变化**，而非净利润数字本身。

---

### 四、总结

| 关键结论             | 说明                             |
| -------------------- | -------------------------------- |
| 净利润可被合法调节   | 通过控制买卖时机影响已实现盈亏   |
| 伯克希尔不玩数字游戏 | 芒格与巴菲特的明确承诺           |
| 运营利润更具参考价值 | 更真实反映企业经营状况           |
| 媒体关注净利润是误导 | 更多说明媒体的局限，而非企业表现 |

> ⚠️ 如果你发现记者们非常关注净利润这个指标，**这更多说明的是他们的表现，而非我们的表现。**
> —— 沃伦·巴菲特
